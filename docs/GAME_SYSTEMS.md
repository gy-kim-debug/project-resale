# 게임 시스템 현황

현재 세부 규칙의 원본은 [주제별 설계](design/README.md)와 [v1 적용 정책](design/implementation/V1_RULES.md)이다. 사용자의 후속 결정이 과거 기획보다 우선한다.

- 진행: 주당 주요 행동 30회. 전부 소진하면 하단 정산으로 이동하며 홈에서 조기 정산도 가능하다. 이자 납부 후 다음 주를 시작한다. 읽기·오프라인·이동·흥정은 진행하지 않는다.
- 생존 수치와 회복 행동은 삭제했다. 주간 행동 예산만 사용한다.
- 수익: 아르바이트·무료나눔·물건 수집. 무료나눔 게시글 등장은 무작위이며 수집은 저렴한 물품 위주로 반드시 발견한다.
- 거래: 구매 전 가격·설명만 공개. 상태는 구매 후, 실제 가치·결함은 가치 확인 후 공개. 구매·판매 채팅은 무료, 실제 교환은 행동 1회다.
- 즉시 판매: 모든 보유 품목의 실제 가치 60%, 원 단위 내림. 진입·가격 확인은 무료, 판매 완료는 행동 1회. 협상·대출 없음.
- 보관함: 매입가·확인한 현재 가치·차액 비교. 고정 12칸.
- 채무·종료: 현금 0원은 진행 가능하고 주간 이자 미납이면 게임 오버. 주 0.001%부터 매주 0.002%p 증가하며 납부 시 남은 원금으로 계산한다. 마지막 완납은 클리어 우선. 상단에 주간 이자·이율·납부 기한 표시. 원금 10,000,000,000원, 별도 이자·일부 상환·전액 상환 시 클리어. 자세한 밸런스는 v1 정책을 따른다.
- 탐색: 내 정보 | 채무 | 활동 | 보관함 | 상점. 활동이 홈이며 상점은 현재 판매 상품이 없다.
- 저장: IndexedDB 자동 저장·JSON 백업·오프라인 실행. 구 저장의 음식 필드는 제거하고 나머지 진행은 보존한다.

미정·후속 조정은 [남은 설계 과제](design/OPEN_QUESTIONS.md)를 따른다. 정식 제목·상점 상품·추가 사건·최종 밸런스는 확정하지 않는다.

시작 현금은 사용자 확정값인 500,000원이다. 원금 상환과 주간 이자 납부는 분리한다. 기한에는 납부를 마쳐야 진행하며 돈이 부족하면 끝난다.

카테고리별 기준 가치와 매입가·성장 단계는 [매물 카테고리·가격대](design/items/CATEGORIES_AND_PRICES.md)에 기록한다. 새 게임의 주력 거래 규모를 올리되 저렴한 매입 선택지를 남긴다.

사용자 후속 확정: 가치 확인·수리는 행동을 소모하지 않는다. 비용과 결과 판정은 유지하고 시간·기한·주간 납부 시점은 진행하지 않는다.

매물 해시태그는 [태그 정책](design/items/LISTING_TAGS.md)을 따른다. 새 매물의 주장성 태그는 초기 설정 85%로 사실이며 실제 속성에 따라 가치·급처 가격/기한·흥정이 달라진다. 구매 후 가치 확인에서 진위·특징을 공개하고 기존 물품은 소급 변경하지 않는다.

후속 확정: [6개 시장](design/markets/OVERVIEW.md)으로 게시판을 나누고 시장별 가격대·품목을 적용했다. 시장 이동은 무료, 선택한 시장의 매물 탐색만 행동 1회다. 원래 출처 시장을 보유 자산과 판매 글에 유지하며 구매 후 검증은 계속 행동 소모 없음이다.

고가 경매는 [경매 정책](design/markets/AUCTION.md)을 따른다. `domain/auction.ts`의 순수 입찰 로직과 `content/auction.ts`의 설정을 분리하고, 현재가·경쟁 한도·진행 대화를 물품에 저장한다. 입찰·포기는 무료, 낙찰 결제만 행동 1회다.

시장 진입은 활동 화면의 시장별 독립 버튼을 사용한다. 일반 5개 시장은 장터형 매물·흥정·구매를 공유하고 고가 경매만 입찰한다. 즉시 판매는 보유품을 실제 가치의 60%에 파는 별도 경로다.

일반 5개 시장의 구매 흥정은 같은 엔진을 사용하며 시장별 최초 제안·가격 양보·인내심·접근 방식만 콘텐츠 설정으로 구분한다. 자세한 초기 공략은 [시장별 흥정 문서](design/trading/bargaining/MARKET_STRATEGIES.md)에 기록한다. 판매 문의의 역제안/거절도 공통 순수 함수로 처리하되 기존 규칙을 유지한다.

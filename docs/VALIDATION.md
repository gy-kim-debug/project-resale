# 초기 검증 기록

2026-10-15 재검증 완료. Node 24.19.0, npm 11.9.0, Vite 7.3.7.

## 초기 실패 원인과 해결

기본 명령 실행 샌드박스에서 지정 프록시 `proxy:8080`으로의 TCP 연결이 `EPERM`으로 차단되었다. DNS는 정상 해석됐고 npm registry 설정과 허용 호스트도 정상이었다. curl과 npm 모두 실패했으며 오프라인 캐시와 대체 로컬 도구가 없어 설치 없이 진행할 수 없었다.

명령 실행에 네트워크 권한을 명시하자 동일한 프록시와 registry로 npm ping이 성공했고 의존성 설치가 완료됐다. 프록시 우회나 TLS 검증 해제는 하지 않았다. 미리보기 서버의 listen도 기본 샌드박스에서 EPERM이 발생했으나 같은 권한으로 실행에 성공했다. 이전의 단순 프록시 장애 설명은 불충분했고 명령 실행 권한 문제로 원인을 좁혔다. 추가로 기본 샌드박스의 오프라인 npm ci에서도 esbuild 설치 검증의 spawnSync EPERM이 발생했으며, 동일하게 네트워크 권한을 명시한 실행에서는 오프라인 재설치와 빌드가 통과했다.

## 브라우저 확인 범위

- 매물 5개 노출, 카테고리 필터, 목록과 상세 이동.
- 관심 매물 저장, IndexedDB 쓰기 완료, 새로고침 후 보관함 복원, 해제.
- 상세 복귀 시 존재하는 원래 매물 버튼으로 포커스 이동.
- 생활·채무 메뉴 이동과 준비 중 버튼 비활성화.
- 각 화면 가로 넘침 없음, 마지막 매물까지 스크롤 시 하단 메뉴에 가려지지 않음.

임시 Playwright 검증 스크립트와 스크린샷은 work/에 보관했다. 실제 모바일 기기, WebKit/Safari, 네이티브 Safe Area, 가상 키보드와 화면 읽기 도구는 검증하지 않았다. 초기 로드 이후의 탐색만 제공하며 PWA 오프라인 캐시는 아직 없다.

## 활동 중심 5개 탭 재구성 (2026-10-16 KST)

회차·직업 표시를 제거하고 활동 / 내 정보 / 보관함 / 상점 / 채무 순서로 변경했다. 장터·식사·수면·숙박은 활동 내부 화면으로 이동한다. 사망하면 게임이 종료되는 기획으로 문서를 정리했으며 사망 판정 엔진은 아직 구현하지 않았다.

Chromium 320x844, 375x667, 390x844, 430x932에서 5개 메뉴 순서, 하위 활동 진입·복귀 및 활동 탭 선택 유지, 내 정보→채무, 카테고리 필터, 관심 매물 저장·새로고침 복원과 보관함→활동 장터 상세 이동, 상점 준비 상태, 고정 생존 헤더, 화면 넘침·하단 메뉴 가림·콘솔 오류 없음을 확인했다. TypeScript·ESLint·포맷·프로덕션 빌드 통과.

## 문서 기반 화면 토대 (2026-10-19)

확정 문서와 화면 대응은 [화면 토대](SCREEN_FOUNDATION.md)에 정리했다. 기존 `src/styles.css`는 수정하지 않았다. TypeScript·ESLint·Prettier·프로덕션 빌드·diff 공백 검사를 통과했다.

`python3 scripts/verify-screens.py`로 프로덕션 preview를 Chromium 320x844, 375x667, 390x844, 430x932에서 검증했다.

- 하단 5개 메뉴, 공통 포만감·체력·피로도 표시, 각 활동 진입, 가로 넘침 없음.
- 무료나눔 글 있는/없는 상황, 수령 후 보관함 이동, 가치 별도 확인.
- 안전 정수 범위를 벗어나는 판매 가격 거부, 등록 후 가격 입력 제거.
- 장터 등록 물품의 매각 차단, 복수 구매 문의 표시, 응답 전 모든 메뉴·홈 이동 차단.
- 파토 시 판매 글·문의 전체 종료, 새 가격 재등록, 거절 후 예시 재제안, 수락 후 목업 물품/대금 교환.
- 매물 카테고리, 관심 저장, 구매 전 확인 실행 보류, 선택형 네고·구매·중복 수령 방지, 목업 현금 차감.
- 매각처 방문 전 견적 비노출, 방문 후 고정 가격 판매.
- 수집 반복·보관 용량 초과 획득 차단, 물품 버리기 확인 후 공간 확보.
- 아르바이트·무료 급식·수면의 확인/결과 화면, 치료·상점 미정 안내, 채무 입력 확인.
- 새로고침 시 목업 진행 초기화, 기존 관심 매물은 IndexedDB에서 복원.
- 모든 크기에서 pageerror·console error 없음. 320px 스크린샷도 직접 확인했다.

이 검증은 화면·메모리 목업 상태 전이 대상이다. 시간·생존·확률·경제 밸런스·이자 계산 검증이 아니다. 실제 폰·Safari/WebKit·가상 키보드·화면 읽기 도구 검증은 남아 있다. 스크립트는 Python Playwright와 시스템 Chromium이 설치된 환경에서 재실행할 수 있다.

## 메뉴의 규칙 설명 제거

사용자 요청에 따라 첫 실행 설명창·플레이 안내 메뉴·각 행동의 튜토리얼과 선행 결과 설명을 제거했다. 비용·시간·현재 상태와 확인 결과는 유지하고, 행동 후 메시지도 실제 발생한 결과로 축약했다. 게임 계산·밸런스·저장 형식은 변경하지 않았다. 기존 브라우저 검증의 시작 절차와 짧아진 버튼 이름을 갱신했다.

타입·린트·포맷·빌드와 기존 엔진 테스트 22개 통과. Chromium 320/375/390/430px에서 전체 플레이·오프라인 흐름, 저장 오류·백업 복구 검증 통과. 첫 실행에 바로 활동 홈이 열리며 플레이 안내 메뉴가 없음을 확인했다.

## 행동 실행 연출

750ms 진행 레이어, 전후 날짜·시간, 상단 시계 보간, 완료 후 실제 변경 수치 강조를 구현했다. 게임 엔진 계산과 저장 스키마는 유지했다.

- 엔진·액션 테스트 26개 통과. 실제 행동 단일 실행·저장, 중복 입력 및 초기화/가져오기 차단, 실패·메뉴/관심의 무연출, 시간 비용 0 처리, 날짜/금액 차이 계산을 검증했다.
- `scripts/verify-actions.py`: Chromium 320/375/390/430px에서 연출·전후 시각·키보드 이탈 방지·코드로 발생시킨 중복 클릭 방지·변경 강조·연출 중 새로고침 복원·수면 날짜 변경·동작 줄이기 환경을 확인했다.
- 게임 규칙을 사전에 설명하는 문구는 추가하지 않았다. 가격·시간·현재 상태·이미 발생한 결과만 전달한다.

기존 전체 거래·생존·채무·사망·완납·백업·오프라인 시나리오도 4개 화면 크기에서 통과했다. 저장 손상 보존·구버전 보관·정상 백업 복구·저장소 차단 처리도 통과했다. 타입·ESLint·포맷·프로덕션 빌드 검사를 통과했으며 실제 폰과 Safari 검증은 별도다.

## 물품 도트 그림

현재 공개 물품명 48개와 수집 잡화 2종의 도트 그림을 구성했다. 50개 이름의 전체 갤러리를 만들고 직접 시각적으로 확인했다. 타입·린트·포맷·프로덕션 빌드·기존 테스트 26개 통과.

Chromium 320/375/390/430px에서 목록 그림·상세 확대·구매 후 보관 그림·가치 확인 전후 동일 그림·매각처·구매 문의 그림을 확인했다. 가로 넘침·pageerror 없음. 기존 저장 스냅샷과 오프라인 재실행에서도 그림이 유지된다. 이미지는 공개 이름과 카테고리만 참조하며 실제 가치나 결함을 노출하지 않는다.

## 상단 시간·현금 가독성 조정

날짜/시간과 현금 라벨/금액을 분리하고 시간 28px·현금 20–25px로 확대했다. 10억 원 이상은 금액이 별도 전체 너비 행을 사용한다. 게임 계산과 저장 형식은 변경하지 않았다. 타입·린트·프로덕션 빌드 검사 통과. Chromium 320/375/390/430px에서 기본 금액·최대 1,000조 원·긴 날짜·하단 창 시작 위치·가로 넘침을 검증하고 스크린샷을 확인했다. 행동 연출·시계 변화·변경 강조·진행 중 새로고침 검증도 4개 크기에서 통과했다.

## 시간 단위 행동과 소요 시간 표시

사용자 요청에 따라 행동 비용을 정수 시간으로 변경했다. 1시간 미만 행동은 1시간으로 환산하고 아르바이트 1·2·3시간, 다음 날 09:00 수면, 시간 소모 없는 폐기는 유지했다. 모든 실행 버튼에 소요 시간을 붙였다. 등록 완료 후 최초 1시간부터 문의를 판정하며 화면의 남은 기한과 진행 연출도 시간 단위를 사용한다.

타입·ESLint·포맷·프로덕션 빌드 통과. 테스트 28개 통과: 각 행동의 실제 경과 시간, 등록 완료 시점/문의 지연/48시간 만료, 자정 이자 중복 방지, 과거 분 단위 저장의 순수·멱등 변환과 자원/상대 기한 보존을 포함한다. 3개 시드의 무일푼 시작부터 채무 완납까지 실제 행동 시뮬레이션도 통과했다.

Chromium 320/375/390/430px에서 아르바이트별 시간 표시, 거래·문의·매각·상환·사망·완납·백업·오프라인 흐름을 통과했다. 750ms 행동 연출·입력 잠금·중복 실행 방지·연출 중 새로고침·수면 날짜 변경·동작 줄이기 검증도 통과했다. 손상 저장 보존·백업 복구·v1 보관·저장소 차단 검증 통과. 320px 물품 화면 스크린샷을 확인했다. 실제 기기·Safari 검증은 별도다.

## 채팅 흥정과 종료 시 시간 정산

구매 전 판매자 채팅과 판매 문의에 공통 `TradeChat`을 적용했다. 가격 제안·재제안은 0시간·생존 소모 없음·시간 경과 레이어 없음이다. 거래 수락/매입·플레이어 파토·구매자 이탈·매입 흥정 명시적 종료 시 1시간을 한 번 반영한다. 거래가 성사되면 물품·대금 교환까지 포함한다. 대화 이력은 선택 필드로 저장해 기존 v2 데이터도 유지한다.

## 흥정 무료화·구매 전 상태 확인 제거

후속 사용자 결정으로 흥정 종료 시 1시간 정산을 제거했다. 제안·재제안·거절·대화 종료·플레이어 파토·구매자 이탈 모두 시간/생존 소모와 시간 경과 연출이 없다. 실제 구매·판매 성사에만 기존 거래 시간 1시간을 적용한다. 구매 전 상태 확인 UI·명령·비용을 제거하고, 보유 물품 상세에 상태를 즉시 표시한다. 실제 가치·숨겨진 결함의 별도 확인은 유지한다.

타입·ESLint·포맷·프로덕션 빌드 통과. 테스트 32개 통과: 무료 흥정/종료와 거래 시간, 제거된 과거 확인 명령의 원자적 거부, 과거 확인 플래그가 있는 저장의 호환, 별도 가치 확인 유지. 장기 플레이 봇은 구매 전 상태를 읽지 않고 공개 가격·협상 답변만으로 구매하도록 변경했으며 3개 시드 모두 완납했다. 게임 경제 수치는 변경하지 않았다.

Chromium 320/375/390/430px에서 무료 종료·양쪽 파토, 대화 복원, 실제 구매/판매 1시간, 과거 구매 전 확인 이력의 상태 비공개를 검증했다. 전체 거래·생존·채무·사망·완납·백업·오프라인 흐름도 네 크기에서 통과했다. 320px에서 구매 직후 상태 공개·가치 미확인 화면을 시각적으로 확인했다. 실제 기기·Safari 검증은 별도다.

## 보관함 금액 비교·상단 우편함/설정

보관함 목록과 상세에서 공통 `ItemComparison`으로 실제 매입가·현재 시장 가치·매입가 대비 차액을 표시한다. 미감정 물품은 현재 가치와 차액을 숨긴다. 실제 지불액을 획득 시 기록하고 과거 저장은 남아 있는 합의/구매 가격으로 읽는다. 무료 획득은 0원이다. 매입가 대비 차액이며 감정·수리 비용을 차감한 순이익으로 표시하지 않는다.

오른쪽 상단에 44px 우편함·설정 버튼을 추가했다. 최근 알림·현재 특별 제안, 저장/백업 관리로 각각 연결한다. 시간·현금 크기는 유지한다. 행동 연출·필수 문의·종료 중 버튼은 비활성화한다.

타입·ESLint·포맷·프로덕션 빌드 통과. 테스트 34개 통과: 실제 지불 금액 기록, 무료 획득 0원, 감정 후 매입가 보존, 시장 변화 반영, 미확인 값 비공개, 구버전 매입가 읽기, 잘못된 추가 금액 필드 거부, 기존 플레이 완납 포함.

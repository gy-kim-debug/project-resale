# UI 전면 개편 — 2026-10-28

> 최신 입력 정책: 문자열 검색과 직접 금액 입력은 [선택지 전용 UI](CHOICE_INPUTS.md)로 대체한다.

## 사용자 요청과 우선순위

- 전체 UI의 디자인과 형태를 개편한다.
- 가장 불편한 부분은 이동·뒤로가기다.
- 진행 중이던 랜덤 닉네임도 함께 반영한다.

## 이번 적용

### 화면과 이동

- 주요 화면을 상단 상태 영역 아래에서 하단 메뉴 위까지 채우는 페이지로 구성한다. 기존 반쪽 상세 창과 배경 화면 겹침을 제거한다.
- 채무 / 내 정보 / 활동 / 보관함 / 사업 순서, 활동만 큰 원형 아이콘인 기존 확정 메뉴는 유지한다. 상세에서도 하단 탭을 바로 사용할 수 있다.
- 화면의 이전/닫기, Escape, 브라우저·모바일 뒤로가기/앞으로가기를 세션 내 동일한 페이지 기록에 연결한다. 오른쪽 홈 아이콘으로 활동에 바로 돌아간다.
- 목록으로 돌아올 때 스크롤 위치를 복원한다. 장터별 검색·정렬·카테고리·관심 필터를 임시 UI 저장소에 유지한다. 게임 저장/회차 성장에는 포함하지 않는다.
- 구매 문의와 필수 정산은 기존 진행 차단 규칙을 유지한다. 뒤로가기·탭 이동으로 필수 응답을 우회할 수 없다. 로딩 중 입력 차단도 유지한다.

### 배치와 시각 체계

- 짙은 남색 배경, 단계별 표면, 민트색 주 행동/현금, 주황색 채무로 구분한다. 글꼴·간격·모서리·보조색·포커스·선택 상태를 공통 CSS 변수와 컴포넌트로 관리한다.
- 상태 헤더를 약 160px로 압축한다. 주차/남은 행동, 큰 현금, 의무 원금/이자, 정확한 남은 채무를 항상 보여준다.
- 활동 홈은 시장 → 돈 벌기 → 자산 순서로 정리한다. 시장은 아이콘과 진입 가격이 있는 2열 카드, 돈 벌기는 3열 빠른 메뉴다.
- 장터에 검색과 가격순 정렬을 추가한다. 목록에서 도트 이미지·상품명·가격·태그의 우선순위를 분명히 한다.
- 거래 상세는 넓은 상품 영역, 판매자 프로필, 채팅, 하단 고정 구매 영역으로 정리한다. 실제 구매 확정은 유지하고 제안 버튼은 짧은 선택지 형태로 배치한다.
- 채무 화면은 이번 정산에 필요한 금액을 먼저 표시하고 상세 회계 내역은 펼쳐 보게 한다. 내 정보의 능력치·보관함 비교·사업 카드·도감·우편·저장 관리도 같은 시각 체계를 사용한다.
- 새로운 규칙 설명/튜토리얼은 메뉴에 추가하지 않는다. 기존 행동 번개, 도트 이미지, 자동 종료 토스트, 접근 가능한 라벨과 모션 감소 설정을 유지한다.

## 범위

이번 개편은 UI와 이동 구조에 한정한다. 주당 행동 수·시세/수리/흥정 확률·사업 수익·채무 계산은 변경하지 않는다. UI의 브라우저 기록과 필터는 오프라인에서도 동작하며 네이티브 의존성이나 서버를 추가하지 않는다.

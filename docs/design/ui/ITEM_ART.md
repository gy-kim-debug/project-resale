# 물품 도트 그림

사용자의 “텍스트만으로 물건을 이해하기 어렵다”는 피드백에 따라 물품에 도트 그림을 붙였다.

- 32×32 정수 픽셀 격자로 직접 구성한 SVG 그림이다. 외부 이미지·아이콘 폰트·네트워크 요청을 사용하지 않는다.
- 현재 등록된 물품명 48개와 수집 잡화 2종을 지원한다. 조명·키보드·의자·라디오·카메라·렌즈·피규어·냄비·헤드폰·수납장·레코드·만년필·오디오·노트북·소파·시계·책·믹서·그림·장비·컬렉션 등 기본 형태를 공유하고 공개 이름에 맞는 형태와 색을 사용한다.
- 목록에서는 64px, 상세에서는 160px로 정수 배율 확대한다. 매물·보관함·상세·판매 등록·매각처·문의에 같은 물품 그림을 쓴다.
- 그림은 공개된 `title`과 `kind`만 읽는다. 실제 가치·희귀도·가품 여부·숨겨진 결함·수리 결과를 미리 표시하지 않는다. 확인 전후에도 동일 이름의 그림은 유지된다.
- 기존 저장 데이터에 그림 필드를 추가하지 않는다. 예전 물품도 이름으로 표시하고 알 수 없는 이름은 카테고리 기본 그림으로 처리한다.
- 코드는 `src/content/itemArt.ts`, 표시 컴포넌트는 `src/components/ItemArt.tsx`에 분리한다. 콘텐츠 확장 시 이름 연결과 도트 형태를 이곳에서 추가한다.
- 물품 이름 텍스트는 계속 제공한다. 그림은 중복 낭독을 막기 위해 접근성 트리에서 장식으로 처리한다.
- 게임 규칙 설명·희귀도 배지·가격 추정 표시는 새로 붙이지 않는다. 계산·확률·저장 형식은 유지한다.

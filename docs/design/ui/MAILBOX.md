# 우편 표시 정책과 전체 기록 목록

2026-10-28 코드 기준. 사용자 요청에 따라 현재 항목을 정리하고 이웃 이사 정리 일손 제안을 제거했다. 후속 사용자 요청에 따라 우편은 특별 제안·시작·시장 변화만 표시한다. 다른 기록은 게임 이력으로 보존하지만 우편과 안 읽은 개수에서 제외한다.

## 표시 방식

- `domain/engine.ts`의 `log`는 기록을 최신순 최대 80개 보관한다.
- `app/notifications.ts`의 `mailboxLogs`는 허용 분류(특별 제안·시작·시장)로 먼저 거른 뒤 최근 20개만 표시한다. 일반 행동이 우편 표시 자리를 차지하지 않는다.
- 안 읽은 개수도 필터링된 우편의 최근 20개 기준이다. 읽음/안 읽음은 별도 ID 목록으로 저장한다.
- 능력치 상승은 새 우편 한 통을 만들지 않고 해당 실행 중 최신 기록에 덧붙인다.

## 우편 허용 목록 — 사용자 확정

- 시작: 시작 자금·채무 안내.
- 시장: 시장 수요/시세 변화.
- 특별 제안: 수리 전문가의 연락, 정비 교육 수락, 제안 거절/만료, 소개받은 단골 감사금.

신규 기록은 category(start/market/special/activity)를 함께 저장한다. activity는 우편에서 제외하며, 분류가 없는 과거 저장은 알려진 허용 문구만 인식한다. 읽음 상태와 전체 읽음도 같은 필터를 사용한다. 거래·구매 문의·정산은 기존 게임 화면에서 계속 진행되며 진행 규칙은 바꾸지 않는다.

## 삭제한 항목: 이웃 이사 정리 일손 제안

- 신규 무작위 제안과 도착 우편을 생성하지 않는다.
- 해당 제안 수락으로 15,000원을 받는 경로를 제거했다.
- 기존 저장/백업의 진행 중 `deal` 제안과 도착 기록 `이웃에게 시간 제한이 있는 제안이 왔습니다.`를 정리한다. 시간/행동/현금/보유품/난수를 바꾸거나 새 우편을 만들지 않는다.
- 과거에 이미 받은 15,000원과 그 수령 기록은 보존한다. 수리 전문가 제안·후속 감사금과 일반 매물의 판매자 이름/급처·이사 정리 태그는 별개다.

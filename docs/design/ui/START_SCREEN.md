# 앱 시작 화면

앱을 열면 게임을 바로 생성하거나 활동 탭을 열지 않고 시작 화면을 표시한다. 게임 제목은 새로 정하지 않으며 화면 제목은 기능명인 시작하기를 사용한다.

- 이어하기: 최근 저장된 유효 슬롯의 캐릭터·주차·현금을 보여주고 해당 진행으로 들어간다. 저장이 없으면 비활성화한다.
- 새로 시작: 빈 슬롯을 찾아 새 캐릭터 설정으로 이동한다. 슬롯이 모두 차면 저장 슬롯 화면을 연다.
- 저장 슬롯: 3개 슬롯의 캐릭터·주차·현금·남은 채무·상태·저장 시각을 확인하고 골라서 이어간다. 비어 있는 슬롯에서는 새로 시작할 수 있다.

게임 중 설정과 저장/백업 화면에서 시작 화면으로 돌아올 수 있다. 현재 진행을 저장한 후 이동한다. 캐릭터 생성이나 슬롯 전환 뒤에는 활동 홈에서 시작하되, 미답변 문의/주간 정산/종료 상태 등 게임의 기존 진행 제약을 그대로 복원한다. 게임 화면을 다시 마운트해 이전 슬롯의 상세 페이지·브라우저 페이지 기록을 새 슬롯에 적용하지 않는다.

새 게임 생성은 캐릭터 설정 완료 후 저장 성공을 확인하고 게임으로 진입한다. 빈 슬롯에 대한 신규 생성만 허용하며 덮어쓰기와 원클릭 초기화 UI는 제거한다. 삭제는 별도 슬롯 확인 절차를 사용한다. 저장 데이터가 없는 첫 방문에는 자동으로 슬롯을 채우지 않는다.

모바일 Safe Area와 스크롤·터치 영역을 고려하고 이름 입력 글자 크기는 16px로 둔다. 선택지는 라디오 입력으로 키보드 조작과 선택 상태를 제공한다. 메뉴 화면 전환 때 상단으로 이동하고 제목에 포커스를 둔다.

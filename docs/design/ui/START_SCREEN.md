# 앱 시작 화면

앱을 열면 게임을 바로 생성하거나 활동 탭을 열지 않고 시작 화면을 표시한다. 게임 제목은 새로 정하지 않으며 화면 제목은 기능명인 시작하기를 사용한다.

- 이어하기: 진행 중인 유효 슬롯 중 최근 저장된 진행을 우선한다. 모두 종료 상태이면 최근 유효 슬롯을 연다. 메뉴에 슬롯·닉네임·주차를 표시한다. 저장이 없으면 비활성화한다.
- 새로 시작: 빈 슬롯을 찾아 새 캐릭터 설정으로 이동한다. 슬롯이 모두 차면 저장 슬롯 화면을 연다.
- 저장 데이터: 3개 슬롯의 캐릭터·주차·현금·남은 채무·상태·저장 시각을 확인하고 골라서 이어간다. 비어 있는 슬롯에서는 새로 시작할 수 있다.

게임 중 설정과 저장/백업 화면에서 시작 화면으로 돌아올 수 있다. 현재 진행을 저장한 후 이동한다. 캐릭터 생성이나 슬롯 전환 뒤에는 활동 홈에서 시작하되, 미답변 문의/주간 정산/종료 상태 등 게임의 기존 진행 제약을 그대로 복원한다. 게임 화면을 다시 마운트해 이전 슬롯의 상세 페이지·브라우저 페이지 기록을 새 슬롯에 적용하지 않는다.

새 게임 생성은 캐릭터 설정 완료 후 저장 성공을 확인하고 게임으로 진입한다. 빈 슬롯에 대한 신규 생성만 허용하며 덮어쓰기와 원클릭 초기화 UI는 제거한다. 삭제는 별도 슬롯 확인 절차를 사용한다. 저장 데이터가 없는 첫 방문에는 자동으로 슬롯을 채우지 않는다.

모바일 Safe Area와 스크롤·터치 영역을 고려하고 이름 입력 글자 크기는 16px로 둔다. 선택지는 라디오 입력으로 키보드 조작과 선택 상태를 제공한다. 메뉴 화면 전환 때 상단으로 이동하고 제목에 포커스를 둔다.

## 메인 화면 개편 — 2026-11-12

사용자 승인: 메인 화면·옵션·저장 데이터 등 기기 기능 외의 화면과 게임 처리는 웹에서 담당한다. 기존 3개 슬롯과 저장 형식을 재사용한다.

- 반지하 도트 장면 아래에 이어하기 / 새로 시작 / 저장 데이터 / 설정을 세로로 배치한다. 게임 제목은 미정이며 임의로 정하지 않는다.
- 빈 슬롯은 최대 3개 중 선택한다. 손상된 데이터가 있는 슬롯도 사용 중으로 취급한다. 빈 슬롯이 없으면 저장 데이터 화면을 열고 자동으로 덮어쓰지 않는다.
- 저장 데이터에서 캐릭터·닉네임·주차·현금·남은 채무·진행 상태·마지막 저장 시각을 확인한다. 시각은 한국 시간으로 표시한다.
- 슬롯 삭제는 게임 스타일의 확인 모달에서만 실행한다. 취소/Escape는 데이터를 보존한다. 삭제한 슬롯 외의 진행은 변경하지 않는다.
- 효과음과 모션 간소화는 메인/게임 내 설정에서 공유한다. 이 기기의 localStorage에 보관하며 슬롯과 별개다. 저장 불가 시 세션 내 설정은 동작한다. 효과음은 기본 꺼짐이며 사용자 조작 후에만 오디오를 시작한다. OS의 모션 감소 설정도 존중한다.
- 기본 캐릭터와 전체 꾸미기는 기존 24×32 도트를 유지한다. 이번 작업은 경제 규칙·저장 스키마를 변경하지 않는다.

웹/앱 역할과 후속 구현은 [내부 이동과 네이티브 기능](NAVIGATION.md#웹앱-역할-확정--2026-11-12)을 따른다.

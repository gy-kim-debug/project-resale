# 사용자 확정 UI 구성

사용자가 단계별 후보에서 직접 선택한 구성을 기록한다. 아래 구성은 개발자가 채운 밸런스 정책과 구분한다.

## 공통 상단

- 첫 줄: 날짜·남은 행동 횟수, 보유 현금.
- 둘째 줄: 주간 예상 이자·이율·납부까지 남은 일수를 정확한 원 단위로 표시한다. 생존 게이지는 사용하지 않는다.
- 셋째 줄: 남은 채무. 축약하지 않고 `10,000,000,000 원`처럼 쉼표와 정확한 원 단위로 표시한다.
- 펼치기 없이 항상 보인다. 제목·회차·직업을 헤더에 넣지 않는다.

## 하단 탐색

순서: **내 정보 | 채무 | 활동 | 보관함 | 상점**.

- 아이콘과 이름을 함께 표시한다.
- 가운데 활동은 홈이며 최초 실행 시 열린다.
- 활동만 큰 원형 버튼으로 표시하고 하단 바 위로 살짝 돌출한다.

## 활동 홈

설명 없이 이름만 있는 버튼을 두 칸 격자로 배치한다.

| 그룹    | 버튼                            |
| ------- | ------------------------------- |
| 돈 벌기 | 무료나눔, 아르바이트, 물건 수집 |
| 거래    | 장터, 매각처                    |

## 활동 하단 창

- 모든 활동은 아래쪽 창에서 연다. 장터 목록·상세·거래도 창 안에서 진행한다.
- 창은 항상 상단 상태 정보 바로 아래부터 화면 맨 아래까지 크게 열린다.
- 하단 5개 탭은 창이 덮는다. 상단 상태는 계속 보인다.
- 첫 화면에서는 `닫기`, 내부 상세에서는 `← 뒤로`만 표시한다. 상세의 별도 닫기 버튼은 없다.
- 구매 문의는 필수 응답 규칙 때문에 닫기·뒤로 대신 응답 필요를 표시한다.

## 내 정보

캐릭터 능력치만 표시한다. 진행 알림은 상단 우편함에서, 저장 관리는 상단 설정에서 확인한다.

## 위임받아 정한 나머지 UI 정책

사용자가 이후 “전부 알아서 정책을 정하고 게임을 진행할 수 있게” 만들도록 위임한 범위에서 아래를 선택했다.

- 보관함은 물품명·가치 확인 여부·판매 중 여부가 보이는 세로 목록이다. 누르면 하단 창에서 상세를 연다.
- 채무는 원금·이자·누적 상환·현금과 직접 금액 입력·가능 금액 상환을 제공한다.
- 상점 탭은 유지하며 식사 상품은 삭제한다. 현재 판매 상품이 없어 빈 목록을 표시한다. 중고 물품 매각은 활동의 매각처에서 한다.
- 행동 결과는 창 안 안내 또는 공통 결과 안내로 표시한다. 잘못된 행동은 이유를 알리고 자원·시간을 변경하지 않는다.
- 첫 실행 설명창 없이 활동 홈으로 진입한다. 주간 이자 미납 종료 화면과 완납 화면은 유지한다. 정식 제목은 확정하지 않는다. 브라우저 제목은 사용자가 처음 제시한 가제를 사용한다.

## 메뉴 설명 정책 — 사용자 후속 결정

- 게임 규칙·공략·예상 결과는 메뉴에서 설명하지 않는다. 플레이어가 직접 행동하며 발견한다.
- 첫 실행 튜토리얼과 ‘플레이 안내’ 메뉴를 제거한다.
- 수집 성공 보장, 네고 분기·이자 계산 방식·재등록 방법 등 선행 설명은 노출하지 않는다.
- 메뉴 이름·가격·소요 시간·보유 수량·현재 상태·실제 확인한 물품 정보·현재 제안·이미 발생한 결과는 표시한다.
- 저장/백업 오류와 진행 삭제 확인은 게임 공략이 아닌 기기 데이터 조작 안내로 유지한다.
- 내부 설계 문서와 게임 규칙 자체는 유지한다. 계산·밸런스·저장 형식은 바꾸지 않는다.

## 행동 실행 연출 — 사용자 확정

- 실행 가능한 행동에만 0.5–1초의 짧은 진행 레이어를 사용한다. 구현 기본값은 750ms다.
- 메뉴 이동·상세 읽기·관심 저장·백업·실행 불가 행동에는 연출을 넣지 않는다.
- 행동명과 전후 날짜·시간, 진행 막대를 표시한다. 상단 시계도 두 시점 사이로 흐르고 다른 수치는 완료 때 바뀐다. 시간 비용 0인 버리기는 시각 이동 없이 진행만 표시한다.
- 연출 중 모든 게임 입력·탭 이동·창 이탈·초기화·가져오기를 막고, 저장소 액션에서도 중복 명령을 거부한다.
- 완료 후 실제 변한 날짜·행동 횟수·현금·주간 예상 이자·이율·납부까지 남은 일수·채무만 약 1.4초 강조한다.
- 결과는 기존 순수 엔진으로 한 번 계산하고 즉시 저장한다. 화면에는 연출 전 상태를 잠시 유지한다. 연출 도중 재접속하면 이미 실행된 결과를 복원하며 재실행하지 않는다.
- 연출 정보와 강조 상태는 저장하지 않는다. 게임 시간·확률·밸런스를 바꾸지 않는다.
- 동작 줄이기 환경에서는 예산 전환/막대 애니메이션을 생략하고 전후 날짜·횟수와 완료 수치로 전달한다. 규칙·공략 설명은 넣지 않는다.

## 물품 그림

매물과 보관 물품에는 [물품 도트 그림](ITEM_ART.md)을 사용한다. 이름·가격 등 기존 정보와 함께 표시하며, 숨겨진 가치·결함을 그림으로 노출하지 않는다.

## 상단 날짜·현금 가독성

날짜는 26px로 크게 표시하고 그 아래 `남은 행동 3/3`을 13px로 표시한다. 현금은 라벨과 금액을 분리해 20–25px로 오른쪽에 강조한다. 10억 원 이상 현금은 별도 너비 전체 행으로 옮긴다. 주간 예상 이자·이율·납부까지 남은 일수·정확한 채무·날짜/행동 예산 전후 표시·변경 강조는 유지한다. 헤더 높이 변화에 맞춰 하단 창과 행동 레이어의 시작 위치를 자동 조정한다.

행동 비용은 횟수, 남은 기한은 일/행동 단위로 표시한다. 진행 중에는 날짜와 남은 행동의 전후 상태를 표시한다.

사용자 확정: 모든 주요 행동 실행 버튼에 소모 횟수를 표시한다. 예: `일하기 · 행동 1회`, `지불·수령 확정 · 행동 1회`. 폐기는 `행동 소모 없음`을 표시한다. 화면 이동·확인 창 열기에는 행동 비용을 붙이지 않는다.

## 채팅 흥정

구매 전 판매자 채팅과 판매 문의는 `TradeChat` 공통 컴포넌트를 사용한다. 상대는 왼쪽, 플레이어는 오른쪽 말풍선에 실제 대화만 표시한다. 제안 선택지는 버튼으로 제공하고 흥정 종료·거절·파토 버튼에는 행동 소모 없음, 실제 구매·판매 버튼에는 행동 1회를 표시한다. 진행 중인 답변에는 전체 화면 로딩·결과 토스트 대신 대화만 즉시 추가한다. 대화와 종료는 모두 행동 소모 없음이며 실제 거래 성사에만 행동 1회가 든다. 기존 저장에 대화 이력이 없으면 현재 제안을 시작 말풍선으로 표시한다.

구매 전 상태 확인 버튼은 제거한다. 매물에서는 과거 확인 여부와 무관하게 상태·결함을 공개하지 않으며, 받은 물품의 상세에서 상태를 추가 행동 없이 표시한다. 실제 가치·숨겨진 결함은 별도 가치 확인 후 공개한다.

보관함 목록과 물품 상세는 `ItemComparison`으로 매입가·현재 가치·매입가 대비 차액을 표시한다. 미감정 물품은 현재 가치·차액을 공개하지 않는다. [금액 비교 정책](../inventory/VALUE_COMPARISON.md)을 따른다.

## 상단 우편함·설정

사용자 요청으로 오른쪽 상단에 우편함과 설정 아이콘을 배치한다. 날짜·현금 가독성을 유지하고 별도의 빠른 메뉴 행에서 각 44px 터치 영역을 제공한다. 우편함은 최근 게임 알림 20개와 현재 특별 제안으로 연결하며, 안 읽은 최근 알림의 개수를 숫자 배지로 표시한다. 설정은 기존 저장·백업 관리(내보내기·가져오기·새 게임)로 연결한다. 단순 화면 이동은 시간 소모가 없다. 행동 연출·필수 문의 응답·게임 종료 중에는 상단 버튼도 비활성화한다.

사용자 후속 확정: 활동 하단의 `최근 소식`과 공통 하단의 `진행 기록·저장 관리·이 기기에 자동 저장` 영역을 제거한다. 우편함·설정으로 접근 경로를 통합한다. 자동 저장과 저장 실패 시 복구 안내는 유지한다.

판매 문의 카드마다 판매 가격 입력·가격 제안(행동 소모 없음)·거래 확정(행동 1회)·거절(행동 소모 없음)·해당 구매자와 파토(행동 소모 없음)를 제공한다. 파토해도 판매 글은 유지되며 다른 구매자의 카드에는 영향을 주지 않는다.

매각처 선택·장소 이동은 메뉴 탐색으로 처리한다. 방문 버튼에 행동 소요 시간을 붙이지 않고 행동 레이어·결과 토스트·진행 기록을 만들지 않는다. 실제 매각 버튼의 행동 1회 표시는 유지한다.

## 하루 3행동 UI

시계 대신 큰 날짜와 `남은 행동 3/3`을 표시한다. 유료 행동 버튼은 `행동 1회`, 무료 대화는 `행동 소모 없음`, 생존 회복 메뉴는 없다. 진행 레이어는 행동 전후의 날짜·남은 횟수를 표시한다. 기록과 알림은 시각 없이 날짜만 표시한다. 추가 규칙 설명창은 만들지 않는다.

사용자 후속 결정: 체력·피로도·수면·치료를 삭제했다. 활동은 무료나눔·아르바이트·물건 수집·장터·매각처의 5개다. 헤더는 날짜/행동·현금·주간 예상 이자·이율·납부까지 남은 일수·남은 채무다. 주간 이자 미납 시 파산 종료 화면을 표시한다.

주간 납부 시점에는 `이자 납부` 하단 창을 강제로 연다. 닫기·메뉴 이탈·거래 응답보다 우선하며 주간 전액 납부·원금 상환을 제공한다. 기한과 금액만 표시하며 추가 공략 설명은 넣지 않는다.

수리·가치 확인 버튼과 비용 표시는 `행동 소모 없음`이다. 실제 처리의 750ms 진행 연출과 결과 표시는 유지하되 날짜·남은 행동 횟수는 바뀌지 않는다.

## 우편 읽음 상태

사용자 요청: 알림별 읽음·안 읽음을 구분한다. 최근 알림 20개에 상태 라벨을 표시하고, 안 읽은 항목은 배경과 글자색으로 함께 구분한다. 우편함을 여는 것만으로 읽음 처리하지 않으며 알림을 누르면 해당 항목을 읽음 처리한다. `모두 읽음`은 현재 우편함에 표시된 알림을 한 번에 처리한다. 상단 배지는 같은 20개 중 안 읽은 수이며 0개이면 숨긴다. 새 알림은 안 읽음으로 시작한다.

읽음 정보는 게임 계산과 분리된 저장 메타데이터 `readNotificationIds`로 보관하며 자동 저장·재접속·JSON 백업/복원에 포함한다. 기존 저장에 정보가 없으면 안 읽음으로 표시한다. 새 게임에서는 초기화하고, 게임 기록에서 사라진 ID는 저장 시 제거한다. 읽음 처리는 날짜·행동·현금·난수·게임 기록에 영향을 주지 않으며 처리 연출도 없다. 기존 행동 처리 중 입력 잠금과 주간 납부/필수 문의 우선순위는 유지한다.

구매 흥정은 누적 채팅과 갱신된 가격 선택지로 여러 차례 이어진다. 판매자의 고수·양보·합의·최종 가격·파토는 실제 대사로 표시한다. 파토 시 해당 구매 버튼을 비활성화한다. 흥정 중에는 처리 레이어를 띄우지 않으며 현재 구매 확인 금액은 최신 역제안/합의 가격을 따른다.

장터 안의 시장 선택에서 장터·컴퓨터시장·악기시장·중고차시장·부동산 시장·비행기 시장을 고른다. 이름과 원 단위 가격 범위를 표시하며 이동에는 행동 비용을 붙이지 않는다. 선택한 시장과 품목 필터로 목록을 구분하고 새 매물 탐색만 행동 1회를 표시한다. 검증·가치 확인 버튼은 계속 `행동 소모 없음`을 표시한다.

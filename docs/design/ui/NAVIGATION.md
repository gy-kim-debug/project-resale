# 게임 내부 이동과 네이티브 뒤로가기

## 확정·이번 적용 — 2026-11-11

게임 내 이동은 게임 버튼으로 처리한다. `src/app/navigation.ts`의 React 상태가 현재 레이어 스택을 관리하고 탭은 기존 Zustand 저장소를 사용한다. 브라우저 History API와 연결하지 않는다.

- 뒤로: 내부 스택에서 현재 레이어 한 단계 제거.
- 루트 닫기: 레이어를 닫고 현재 탭 표시. 이전에 방문했던 다른 탭으로 돌아가지 않는다.
- 홈: 스택을 비우고 활동 탭으로 이동.
- 하단 탭: 스택을 비우고 선택한 탭 표시.
- 종료 채팅 나가기: 스택을 비우고 채팅 목록으로 이동. 기록은 보존.
- 중첩 화면의 Escape: 기존 뒤로/닫기 동작. 필수 정산·행동 연출 등의 기존 입력 잠금은 유지.
- 상세 복귀 시 목록 스크롤 위치와 기존 포커스 복원은 유지.

`history.pushState/replaceState/back` 호출과 `popstate` 처리를 제거했다. 화면 이동으로 브라우저 방문 기록이 늘어나지 않으며 브라우저의 뒤로가기를 가로채거나 무효화하지 않는다. 일반 웹의 브라우저 뒤로가기는 게임에 들어오기 전 페이지로 이동할 수 있다. 브라우저 버튼 자체를 숨기거나 비활성화하는 기능은 구현하지 않는다.

게임 저장·탭 재접속 복원은 유지한다. 레이어 스택은 이번 세션의 메모리에만 보관하고 새로고침 시 기본 탭 화면으로 돌아간다. 기존 버전이 이미 남긴 브라우저 기록을 임의로 지우거나 이전 페이지로 강제 이동시키지는 않는다.

## 후속 작업 메모 — 아직 구현하지 않음

| 작업                       | 검토·구현할 내용                                                                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Capacitor Android 뒤로가기 | App 플러그인의 시스템 뒤로가기 이벤트를 내부 뒤로/닫기에 연결. `window.history.back()`으로 되돌리지 않는다.                                                                                 |
| 루트 화면의 시스템 뒤로    | 활동 탭 이동·종료 확인·기본 종료 중 어떤 동작을 할지 제품 정책 결정 후 구현. 이번 작업에서는 미확정.                                                                                        |
| 입력 우선순위              | 확인 모달 → 일반 레이어 → 탭/루트 순서를 검토. 거래 처리 중·스토리·필수 정산에서 무엇을 닫을 수 있는지 정하고 웹/네이티브에 같은 정책 적용. 잠긴 진행을 시스템 뒤로로 우회하지 않도록 검증. |
| iOS 제스처                 | WKWebView의 뒤로 스와이프와 앱 내부 제스처 정책 검토. 커스텀 스와이프가 필요하면 Android와 별도 설계·실기기 검증.                                                                           |
| 생명주기·저장              | 백그라운드/종료 전에 저장 큐 처리, 복귀 시 저장 실패 안내와 중복 거래 방지 검증. 네이티브 저장소 교체는 별도 작업.                                                                          |
| 복원·딥링크                | 레이어 복원이나 외부 링크 진입이 필요해지면 명시적으로 설계. 거래 대상 만료·슬롯 변경·필수 정산을 검증한 뒤 화면을 열기. 현재 URL 경로를 새로 만들지 않는다.                                |
| 실기기 검증                | Android 물리/제스처 뒤로, iOS 스와이프, PWA·Safari·Chrome, 종료/복귀·새로고침·빠른 연속 입력·Safe Area 확인.                                                                                |

Capacitor 설치·네이티브 프로젝트 생성·시스템 버튼 차단·앱 종료 처리는 이번 범위에 포함하지 않는다. 위의 미정 동작을 현재 게임 규칙으로 취급하지 않는다.

## 검증

`scripts/verify-navigation.py`에서 탭·중첩 화면·루트 닫기·Escape·홈·스크롤 복원, History API/`popstate` 호출 없음과 방문 기록 길이 불변, 게임 저장 불변·재접속 탭, 실제 브라우저 뒤로/앞으로를 확인한다. 거래 이어하기와 종료 채팅 나가기는 `scripts/verify-chats.py`로 회귀 검증한다.

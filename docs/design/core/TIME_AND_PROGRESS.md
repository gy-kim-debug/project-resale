# 게임 진행의 공통 원칙

**확정: 날짜·시간·포만감·체력·피로도를 고려하여 진행한다.**

- 행동이나 진행을 하면 시간이 소모되는 것이 공통 원칙이다.
- 어떤 행동이 각 지표를 얼마나 변화시키는지와 구체적인 시간 비용은 별도로 정한다.

선택 근거: 사용자가 게임 진행 시 고려할 다섯 요소와 행동·진행의 시간 소모 원칙을 직접 지정했다.

명시적으로 결정된 예외: [물건 버리기](../inventory/DISPOSAL.md)는 시간이 소모되지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

정수 분 단위로 실행한 행동만 시간을 진행한다. 메뉴 탐색·앱 종료·오프라인 대기·백업은 소모 없음. 물품 버리기만 실제 행동 중 시간 비용 0이다. 나머지 행동별 시간은 v1 행동표에 지정했다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

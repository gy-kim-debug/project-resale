# 날짜와 하루 3행동

## 사용자 확정

시간 단위 진행을 하루 3행동으로 변경한다. 게임을 읽거나 앱을 꺼 두면 진행하지 않는다. 이동·흥정은 행동으로 세지 않는다.

- 하루에 주요 행동 3회를 할 수 있다. 헤더에 날짜와 `남은 행동 3/3`을 표시한다.
- 구매·나눔 수령·판매 확정·감정·수리·판매 등록/취소·아르바이트·물건 수집·매물 탐색·기다리기·식사·치료·채무 상환·특별 일거리 수락은 각각 행동 1회를 사용한다.
- 세 번째 행동을 마치면 그날이 끝나고 다음 날 행동 3회가 주어진다.
- 수면은 남은 행동을 포기하고 바로 다음 날로 간다. 피로도 0도 실행 중 행동을 마친 뒤 남은 행동을 포기하고 다음 날로 간다.
- 장소 이동·화면 탐색·관심 등록·구매/판매 흥정·거절·파토·물품 버리기·백업은 행동을 소모하지 않는다.
- 선택형 특별 제안 거절도 작업을 수행하지 않는 답변이므로 행동을 소모하지 않는다(개발자 적용 정책).
- 포만감·피로도는 시간 비례가 아닌 실제 행동별로 소모한다. 생존 수치가 물품 가치나 거래 확률을 보정하지 않는다.

## 하루 종료와 생존 — 개발자 적용 정책

일반 행동은 포만감 12·피로도 12를 기본 소모하고 작업별 추가 소모를 더한다. 일반 행동 중 포만감이 바닥나면 체력 8 감소. 회복 행동·거래 문의 응답에는 이 체력 손실을 적용하지 않는다. 포만감 0이면 소모 행동은 막되 식사·치료·수면·무료 대화/이동은 가능하다.

하루 종료는 원인이 세 번째 행동·자발적 수면·피로도 소진 중 무엇이든 한 번만 처리한다. 포만감 18 감소, 피로도 100 회복, 체력은 유지한다. 이자·시장 변화·새 매물·유효 기한도 하루 경계에 맞춰 갱신한다. 식사·치료는 행동 기본 소모 후 회복하고, 그 뒤 필요하면 하루 종료의 포만감 손실을 적용한다.

## 기한

게시판 1일, 판매 글 2일, 매각 견적 행동 2회. 판매 문의는 등록 완료 후 다음 주요 행동부터 판정한다. 실제 행동으로만 기한이 진행하고 이동·대화·오프라인 대기는 진행시키지 않는다. 문의 처리 중 판매 글 만료 보류와 필수 응답 정책은 유지한다.

## 기존 저장 전환

저장 버전 2는 유지하고 `timeMode: daily-actions`로 새 진행 모델을 구분한다. 이전 시간/분 저장은 같은 날짜에서 남은 행동 3회로 한 번 전환한다. 현금·채무·생존 수치·물품·매입가·판매 가격·채팅·능력치·난수는 유지한다. 기한은 남은 기간을 행동 단위로 올림하고 기존 유효 견적은 행동 2회로 이어 간다. 과거 기록의 날짜는 유지한다. 전환 자체로 이자·보상·시장 추첨은 발생하지 않는다. 새 모델 저장을 다시 읽을 때 행동을 리셋하지 않는다.

내부 `minute` 필드는 호환성을 위한 정수 눈금이며 480눈금이 행동 1회, 1,440눈금이 하루다. 실제 시각은 게임에서 표시하거나 진행 규칙으로 사용하지 않는다.

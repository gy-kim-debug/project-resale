> 기존 사용자 선택은 유지한다. 아래 원문에서 미정으로 기록했던 부분은 하단의 **플레이 가능 v1 적용 정책**에서 개발자 위임 결정으로 보완했다.

# 게임 진행의 공통 원칙

**확정: 날짜·시간·포만감·체력·피로도를 고려하여 진행한다.**

- 행동이나 진행을 하면 시간이 소모되는 것이 공통 원칙이다.
- 어떤 행동이 각 지표를 얼마나 변화시키는지와 구체적인 시간 비용은 별도로 정한다.

선택 근거: 사용자가 게임 진행 시 고려할 다섯 요소와 행동·진행의 시간 소모 원칙을 직접 지정했다.

명시적으로 결정된 예외: [물건 버리기](../inventory/DISPOSAL.md)는 시간이 소모되지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

정수 시간 단위로 실행한 행동만 시간을 진행한다. 메뉴 탐색·앱 종료·오프라인 대기·백업은 소모 없음. 물품 버리기와 진행 중 흥정 대화는 시간 비용 0이다. 나머지 행동별 시간은 v1 행동표에 지정했다. 흥정은 종료·파토까지 0시간이며 실제 구매·판매 거래가 성사될 때만 거래 시간 1시간을 적용한다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

## 사용자 확정 변경 — 시간 단위 행동

행동 시간은 분 단위가 아닌 정수 시간 단위로 진행한다. 기존 5·15·30분 행동은 1시간, 기존 1·2·3시간 행동은 유지하는 세부 환산을 개발자가 적용했다. 수면은 다음 날 09:00까지, 물건 버리기는 기존 확정 예외인 시간 소모 없음이다. 화면과 진행 연출도 시간 단위로 표시한다.

기존 v2 저장은 초기화하지 않는다. 분이 남은 저장은 불러올 때 같은 날짜의 직전 정시로 맞추고, 매물·판매 글·문의 판정·견적·사건의 기준 시각과 기록을 같은 차이만큼 이동한다. 현금·채무·생존 수치·소모 잔여치·난수는 유지하고 이자·보상은 추가 발생하지 않는다. 남은 기한은 시간 단위로 올림 표시한다.

## 사용자 확정 변경 — 흥정 시간 소모 없음

장터 흥정은 채팅 형식으로 진행하며 제안·재제안·거절·흥정 종료·플레이어 파토·구매자 이탈 모두 시간 소모가 없다. 이전의 ‘대화 종료 시 1시간 정산’ 결정을 대체한다. 실제 구매·나눔 수령·판매 성사에는 기존 1시간을 적용하고, 대화 종료 시간을 별도로 더하지 않는다. 아르바이트·식사·수리·수면 등 다른 행동의 시간은 유지한다.

흥정과 종료에는 생존 소모·이자·기한 만료·사건 판정·시간 경과 연출이 없으며 변경 내용은 즉시 저장한다.

## 사용자 확정 변경 — 장소 이동은 행동에서 제외

매각처 방문 같은 단순 장소 이동과 메뉴 탐색은 행동으로 세지 않는다. 시간·생존 수치를 소모하지 않고 행동 연출을 띄우지 않는다. 실제 구매·판매·식사·수리·일하기 등 작업을 실행할 때만 해당 행동 시간을 적용한다. 매물 새로 탐색하기는 이동이 아닌 탐색 작업이므로 기존 시간 소모를 유지한다.

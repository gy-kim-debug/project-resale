# 날짜와 하루 3행동

## 사용자 확정

- 하루 주요 행동 3회. 세 번째 행동 완료 후 다음 날에 새 행동 3회를 받는다.
- 구매·수령·판매·감정·수리·등록/취소·알바·수집·탐색·기다리기·상환·일거리 수락은 각각 행동 1회다.
- 이동·화면 탐색·관심 등록·흥정·거절·파토·물품 버리기·제안 거절·백업은 행동 소모 없음이다.
- 글을 읽거나 앱을 꺼 둬도 진행하지 않는다.
- 포만감·체력·피로도와 식사·수면·치료는 삭제했다. 모든 일거리는 생존 수치에 따른 조기 종료 없이 하루 예산으로만 제한한다.

## 구현 정책

날짜가 바뀔 때 시장·게시판·기한을 한 번만 갱신한다. 게시판 1일, 판매 글 2일, 매각 견적 행동 2회. 문의는 등록 완료 후 다음 행동부터 판정한다. 필수 응답과 문의 중 판매 글 만료 보류는 유지한다.

게임 종료와 주간 이자는 [채무·자본금](../debt/INTEREST_AND_BANKRUPTCY.md)을 따른다.

## 저장 전환

버전 2, `timeMode: daily-actions` 유지. 구 시간 저장은 같은 날짜의 행동 3회로 한 번 전환하고 금융·물품·채팅·난수·기한을 보존한다. 기존 하루 행동 저장은 남은 횟수를 초기화하지 않는다. `satiety`·`hungerRemainder`·`health`·`fatigue`·`fatigueRemainder`는 삭제한다. 과거 기록은 보존한다.

내부 `minute`는 호환용 정수 눈금이다. 480눈금은 행동 1회, 1,440눈금은 하루다. 실제 시각으로 표시하지 않는다.

7일을 마치면 해당 주의 이자 납부를 먼저 처리한다. 납부 전에는 다음 행동이 불가능하고, 현금이 부족하면 종료한다. 새 납부 명령은 행동을 소모하지 않는다.

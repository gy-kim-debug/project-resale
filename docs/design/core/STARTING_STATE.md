# 게임 시작 상황

**확정: 완전 무일푼으로 시작한다.**

- 시작 현금: 0원.
- 시작 보유 물품: 없음.
- 첫 돈을 만드는 과정부터 플레이한다.

선택 근거: 사용자가 시작 상황 후보 1번 ‘완전 무일푼’을 선택했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

1일째 · 남은 행동 3/3, 현금 0원·물품 없음·원금 100억 원·이자 0원, 포만감·체력·피로도 100으로 시작한다. 체력 0은 종료이며 새 게임은 계승 없는 별도 시작이다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

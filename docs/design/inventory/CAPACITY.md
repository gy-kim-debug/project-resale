# 보유 물품 수량 제한

**확정: 보유할 수 있는 물품 수는 고정된 수량으로 제한한다.**

선택 근거: 사용자가 구매·정보·보관 일괄 질문 E의 2번 ‘고정된 수량 제한’을 선택했다.

구체적인 한도, 한도를 계산하는 단위, 판매 등록 중인 물건의 포함 여부, 한도가 찼을 때의 처리는 아직 정하지 않았다.

[장터 판매 글 등록 한도](../trading/marketplace/LISTING_LIMITS.md)는 별개의 규칙이다. 판매 글 한도는 향후 확장이 가능하지만, 이를 보유 물품 수량 한도의 확장으로 자동 적용하지 않는다.

# 보유 물품 수량 제한

**확정: 보유할 수 있는 물품 수는 고정된 수량으로 제한한다.**

선택 근거: 사용자가 구매·정보·보관 일괄 질문 E의 2번 ‘고정된 수량 제한’을 선택했다.

**추가 확정**

- 장터에 판매 등록한 물건도 판매될 때까지 보관함 공간을 차지한다.
- 보관함이 가득 차면 공간을 비우기 전에는 새 물건을 획득할 수 없다.

선택 근거: 사용자가 후속 C의 1번 ‘판매될 때까지 공간을 차지함’, D의 1번 ‘공간을 비우기 전에는 획득 불가’를 선택했다.

구체적인 한도와 계산 단위, 공간 부족을 확인하는 시점과 이미 소모한 비용의 처리, 획득 수량이 여유 공간을 넘는 경우의 처리는 아직 정하지 않았다. 물건 버리기는 [처분 규칙](DISPOSAL.md)을 따른다.

[장터 판매 글 등록 한도](../trading/marketplace/LISTING_LIMITS.md)는 별개의 규칙이다. 판매 글 한도는 향후 확장이 가능하지만, 이를 보유 물품 수량 한도의 확장으로 자동 적용하지 않는다.

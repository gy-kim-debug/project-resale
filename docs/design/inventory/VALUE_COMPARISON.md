# 보관함 금액 비교

## 사용자 확정

보관함에서 물건을 얼마에 샀는지와 지금 가치를 비교할 수 있어야 한다.

## 구현 정책

- 보관함 목록과 물품 상세에 매입가·현재 가치·매입가 대비 차액을 함께 표시한다.
- 매입가는 흥정 후 실제 지불한 금액을 기록한다. 무료나눔·수집은 0원이다. 감정·수리로 매입가를 바꾸지 않는다.
- 현재 가치는 기존의 일별 시장 계수·카테고리 수요·현재 물품 가치를 반영한다. 실제 판매 완료 금액과는 구분한다.
- 별도 가치 확인 전에는 현재 가치와 차액을 `미확인`으로 표시해 숨겨진 정보를 노출하지 않는다.
- 차액은 현재 가치에서 매입가를 뺀 금액이다. 양수는 `+`, 음수는 `−`와 색상으로 함께 구분한다. 감정비·수리비를 뺀 순이익이 아니므로 `매입가 대비`로 표기한다.
- 구매·획득 시 선택 필드 `acquiredFor`로 기록한다. 과거 저장은 물품에 남은 합의 가격(`negotiatedPrice`) 또는 원래 구매 가격(`price`)으로 읽는다. 과거 무료 획득품은 가격이 0원으로 남아 있다. 저장 버전 2는 유지한다.

표시와 비교 계산은 공통 `ItemComparison`과 순수 함수 `domain/inventory.ts`로 분리한다.

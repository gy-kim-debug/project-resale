# 구매한 자산의 검증

## 사용자 확정

구매한 물건을 검증하는 데 행동을 소모하지 않는다. 이 규칙은 모든 시장에서 동일하다.

## 현재 적용

- 보관함의 가치 확인(`check`)으로 실제 가치·숨겨진 결함·진위 또는 서류/권리·표시 태그와 실제 특징의 차이를 확인한다.
- 날짜·남은 행동·매물 기한·판매 글·견적·사건·주간 이자 납부 시점을 진행하지 않는다. 새 구매 문의·사건도 생성하지 않는다.
- 기존 원화 감정 비용과 물품당 확인 완료 상태는 유지한다. 이미 확인한 자산은 재검증 비용을 청구하지 않는다.
- 실제 처리에는 기존 750ms 연출과 중복 입력 잠금을 적용하고 즉시 자동 저장한다.
- 주간 이자 납부·필수 문의 응답이 있으면 기존 우선순위를 유지한다.
- 수리도 기존처럼 행동 소모 없음이며 원화 비용·성공/실패·1회 제한을 유지한다.

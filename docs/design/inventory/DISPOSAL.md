# 필요 없는 물건 버리기

**확정: 물건을 버릴 수 있으며, 버리기에는 시간이 소모되지 않는다.**

선택 근거: 사용자가 후속 질문 E에 ‘가능. 시간은 소모하지 않음’이라고 직접 지정했다.

버리기는 [행동·진행의 시간 소모 원칙](../core/TIME_AND_PROGRESS.md)에 대해 사용자가 지정한 시간 비용 예외다.

금전 비용·상태 소모 여부, 판매 등록·네고 중 물건의 폐기 가능 여부, 복구 가능 여부는 아직 정하지 않았다. 시간이 들지 않는다는 결정으로 모든 비용이 없다고 확대하지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

물품 버리기는 시간·현금·생존 소모 없음, 복구 불가. 판매 등록 중이면 먼저 취소한다. 문의 처리 중에는 폐기를 비롯한 다른 행동은 불가하다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

# 즉시 판매

## 사용자 확정

- 여러 매각처를 하나의 `즉시 판매` 메뉴로 통합한다.
- 진입 화면에 `실제 가치의 60%로 판매합니다.`를 표시한다.
- 보유 물건을 판매하고 대금을 받는 방식이다. 전당포·담보 대출·상환·담보 만료는 사용하지 않는다.

## 기존 정책을 연결한 구현

- 모든 보유 품목과 출처 시장에 동일한 비율을 적용한다. 판매액은 `item.value × 60 / 100`을 100원 단위 반올림한다. 시세 계수·호가·매입가·이전 매각 견적과 무관하다.
- 화면 진입과 가격 확인은 행동 소모가 없다. 감정 전 보유 물품도 판매 가능하며, 감정 여부나 경험치를 변경하지 않는다.
- 물건 선택 후 품명과 대금을 확인하고 `판매 확정 · 행동 1회`를 누른다. 완료 시 물품 제거·현금 수령·판매 횟수 증가를 한 번만 처리한다.
- 시장 판매 등록 중이면 먼저 등록을 취소해야 한다. 행동 0회·필수 문의·주간 정산·게임 종료 시 기존 제한을 유지한다.
- 별도 매입처 선택·방문·견적 만료는 없다. 구 저장의 `quotes`는 호환 목적으로 읽되 실제 판매 금액의 근거로 사용하지 않는다.

기존 [매각처별 정책](outlets/ITEMS_AND_PRICES.md)은 과거 기록이다. 현재 판매 경로는 시장 판매와 이 즉시 판매 두 가지다.

# 장터 판매 중 다른 매각처에 매각

**확정: 장터 판매 중인 물건은 먼저 장터 판매를 취소해야 고물상·상점 등에 매각할 수 있다.**

- 장터 등록을 유지한 채 다른 매각처에 매각하지 않는다.
- 먼저 장터 판매를 취소한 뒤 다른 매각처에 매각한다.

선택 근거: 사용자가 일괄 질문 F의 2번 ‘먼저 장터 판매를 취소해야 매각 가능’을 선택했다.

장터 판매 취소에 필요한 비용·시간, 진행 중 문의·네고 처리, 다른 매각처 방문·가격 확인만 할 때에도 취소가 필요한지는 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

등록 취소 행동 1회 후 다른 매각처 판매 또는 새 가격 장터 재등록 가능. 물품은 보관함에 유지한다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

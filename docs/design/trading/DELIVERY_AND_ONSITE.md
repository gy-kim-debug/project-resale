# 거래 방식과 직거래 현장 대화

## 사용자 확정 요구사항 — 2026-11-16

1. 게시글에 직거래·택배거래 가능 여부를 표시한다. 둘 다 또는 한 가지만 가능하다.
2. 택배 가능 품목은 현실적인 물품 특성으로 미리 분류한다. 부동산 등에는 택배를 허용하지 않는다.
3. 둘 다 가능하면 채팅에서 거래 방식을 선택한다.
4. 직거래에서는 현장 상태 확인과 현장 네고를 할 수 있다.
5. 채팅은 주제·물품·판매자 특성에 맞추되 여러 문장 템플릿으로 표현한다. 직접 입력 대신 선택지를 유지한다.

## 이번 적용 정책 — 개발자 초깃값

사용자가 수치를 지정하지 않은 부분은 아래 초기 정책으로 구현했다. 경제 밸런스 확정값과 구분하며 조정 가능하다.

### 게시글과 품목 분류

- 거래 방식은 확률적인 해시태그와 분리된 **사실 정보**다. `직거래`, `택배거래`, `직거래 · 택배거래`로 표시한다.
- `content/delivery.ts`에서 36개 품목 카테고리의 일반 택배 가능 여부와 개별 대형 품목 예외를 관리한다. `domain/delivery.ts`의 `canParcel`을 생성·선택·판매 등록·저장 검증이 공통으로 사용한다.
- 자동차·부동산·가구 전체는 직접 인수한다. 회화·골동품은 고가/파손 위험에 따른 직접 인수 정책을 적용한다.
- 피아노·첼로·콘트라베이스·하프·대형 타악기·대형 TV·초광폭 모니터·아케이드 캐비닛·자전거·덤벨 세트·플로어 스피커 등은 일반 택배 대상에서 제외한다. 별도 용달이나 전문 운송은 이번에 구현하지 않는다.
- 소형 디지털 기기·도서·시계·보석·휴대 가능한 악기 등은 택배가 가능하다. 택배가 가능한 물품이라도 NPC 판매자는 직거래만 / 택배만 / 둘 다 중 한 조건을 제시한다.
- 판매자 조건은 물품 식별자와 판매자 식별자로 고정하고 새 매물에는 저장한다. 물건을 다시 열거나 새로고침해도 바뀌지 않는다. 경제 난수를 소비하지 않는다.
- 플레이어 판매 등록은 이전 판매자의 선호를 상속하지 않는다. 물건의 물리적 가능 범위 안에서 직접 거래 방식을 고른다.

### 채팅과 거래 완료

- 게시글 상세와 채팅에서 거래 방식을 고른다. 선택하면 플레이어 질문과 상대 답변을 같은 채팅방에 남긴다. 둘 다 가능한 새 화면에서는 방식을 고른 뒤 구매/판매 확정이 가능하다.
- 한 가지만 가능하면 해당 방식을 기본으로 사용한다. 두 방식 중 선택은 현장 확인 전까지 바꿀 수 있다. 현장에서 확인한 뒤에는 택배로 전환할 수 없다.
- 거래 방식 선택·현장 확인·현장 가격 제안은 행동/현금/주가/경험치를 소모하거나 생성하지 않는다. 최종 구매·판매만 기존과 동일하게 행동 1회를 쓴다.
- 별도 택배비·운반비·배송 대기·배송 사고는 추가하지 않는다. 현금과 물품은 최종 확정 시 동시에 교환한다.
- 경매는 낙찰 후 수령 방식을 선택한다. 경매 낙찰가의 재협상은 추가하지 않는다.
- 묶음 거래는 같은 방식으로 인수할 수 있는 물건만 제안한다. 저장된 묶음 제안도 확정 시 두 물품의 거래 방식이 일치하는지 다시 검증한다.

### 현장 상태 확인

- 직거래를 선택한 뒤 채팅의 `현장 확인`에서 `현장에서 상태 확인`을 고른다. 한 물품당 한 번만 확인한다.
- 외관·사용 흔적·기본 작동 등 현장에서 알 수 있는 내용만 설명한다. 실제 가치, 진품 여부, 숨겨진 결함 전체, 확정 상태 등급은 공개하지 않는다. 구매 후 가치 확인 상태(`checked`)도 바꾸지 않는다.
- 미개봉은 포장·봉인 상태만 확인하며 내부 작동을 보증하지 않는다. 부동산은 현장 설비와 권리 확인을 구분하고, 자동차는 간단한 확인과 정밀 진단을 구분한다.
- 현장 확인 뒤 채팅의 `가격 제안`에서 현재 합의 금액의 95% / 98%를 100원 단위로 제시할 수 있다. 반올림 후 동일하거나 기존 가격과 같아지는 후보는 제거한다.
- 현장 제안은 한 번만 가능하다. 수락하면 최종 가격에 반영하고, 가격 유지면 원래 합의 가격으로 구매할 수 있다. 거래 종료면 해당 판매자에게 구매할 수 없다. 기존 온라인 흥정으로 돌아가 무제한 재시도할 수 없다.
- 일반 판매자 초기 수락 45% / 파토 10% / 가격 유지 45%, 유연한 판매자 수락 70%, 빠른 판매자 수락 60%를 적용한다(파토는 각 10%, 나머지는 가격 유지).
- 가격 고정 성향은 기존 사용자 결정인 **수락 10% / 가격 유지 30% / 파토 60%**를 그대로 적용한다. 나이·성별은 확률에 영향을 주지 않는다. 현장 제안 시에만 경제 난수를 한 번 소비하고 결과를 저장한다.
- 플레이어 판매 문의에서도 방식 선택과 현장 물건 보여주기가 가능하다. 이후 기존 구매자 가격 제안을 `현장 가격 제안`으로 이어간다. 구매자의 한도·라운드가 초기화되지 않으며 다른 문의 비교도 유지한다.

### 대사·저장·호환

- `content/chatTemplates.ts`는 주제별 마무리, 플레이어 질문, 거래 방식/현장 흥정 대사를 관리한다. 인사·상태·구성품·특징·판매 사정 등을 섞어 무관한 답변을 만들지 않는다.
- 기존 물품 상태·미개봉·진품/한정판 주장에 대한 불확실성과 판매자 성격을 유지한다. 문장 변형은 물품/상대/상황에 고정하며 경제 난수와 독립적이다. 나이·성별로 정직함이나 가격 판단을 바꾸지 않는다.
- 기존 답장 간격, 입력 중 표시, 중복 실행 잠금을 새 대화 명령에도 적용한다. 채팅 탭에서 같은 방을 열어 선택과 현장 대화를 이어간다.
- 거래 방식·현장 확인 여부·현장 제안 여부는 IndexedDB/슬롯/내보내기에 포함한다. 새 필드는 선택적이므로 기존 저장 형식을 유지한다. 필드가 없는 구버전 매물은 같은 식별자로 조건을 복원하며, 구버전 직접 거래 명령에는 가능한 기본 방식을 사용한다.
- 불가능한 택배 조건, 미허용 방식 선택, 현장 확인 없는 현장 제안 기록 등은 저장 검증에서 거절한다. 유효하지 않은 명령은 현금·물품·시간·난수를 모두 원상 유지한다.
- 거래 방식 반복 변경으로 저장 제한을 초과하지 않도록 물품/문의 원본 대사는 최근 64개로 제한한다. 거래 기록은 기존 공통 채팅 보관 정책을 따른다.

## 추후 결정 가능 사항

- 배송료를 누가 부담하는지, 배송 지연/파손을 별도 이벤트로 넣을지.
- 전문 포장/운송을 별도 방식으로 제공할지. 현재 일반 택배와 직거래 두 가지만 제공한다.
- 현장 협상의 시장별 추가 차별화와 수락률 조정. 현재 온라인 흥정의 시장별 성격은 유지하고 현장에는 위 공통 초깃값을 사용한다.

# 매각처 제시 가격으로 판매

**확정: 고물상·상점 등 매각처에서는 협상할 수 없으며, 항상 매각처가 제시한 가격으로만 판매할 수 있다.**

- 플레이어는 매각처가 제시한 가격에 판매할지 결정한다.
- 가격 인상 요구, 역제안, 거절에 따른 상향 제안 등 가격 협상은 진행하지 않는다.
- 처음 협상과 재협상 모두 불가능하다.
- 앞서 선택했던 ‘매각처도 협상 가능, 가격 격차가 크면 파토 가능’ 규칙은 이 최신 결정으로 대체한다.

선택 근거: 사용자가 후속 확인에서 ‘매각처에서 협상 불가능, 항상 매각처가 제시한 가격으로만 판매 가능’이라고 직접 확정했다.

매각처마다 취급 물품과 가격이 다르다는 [매각처별 차이](ITEMS_AND_PRICES.md), 방문해 가격을 확인한다는 [가격 확인 방식](PRICE_CHECKS.md)은 유지한다.

제시 가격 산정·유효 기간·변동 여부, 판매를 거절한 뒤 재방문했을 때 가격 처리, 구체적인 소요 시간·상태 소모는 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

협상 없음. 유효한 제시 가격을 수락하면 1시간 한 행동으로 물품·대금 교환. 장터 등록품은 취소 전 판매 불가.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

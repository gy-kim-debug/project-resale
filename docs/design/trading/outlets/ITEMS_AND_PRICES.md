# 매각처별 취급 물품과 가격

**확정: 매각처마다 취급 물품과 제시 가격이 다르다.**

- 매각처별로 매입하는 물품이 다르다.
- 같은 물품을 취급하더라도 매각처마다 제시 가격이 다를 수 있다.

선택 근거: 사용자가 매각처별 차이 후보 2번 ‘취급 물품과 가격이 다름’을 선택했다.

매각처 목록, 구체적인 취급 품목, 가격 산정 방식과 가격 차이의 폭은 아직 정하지 않았다.

매각처에서는 협상 없이 [제시 가격으로만 판매](FIXED_PRICE_SALES.md)할 수 있다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

고물상 전 카테고리·시장 가치 45%, 중고 상점 디지털/가구·72%, 수집품 상점 수집품·85%. 정수 내림·최소 1원.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

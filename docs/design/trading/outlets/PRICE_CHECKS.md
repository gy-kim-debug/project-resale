# 매각 가격 확인 방식

**확정: 매각처마다 시간을 써서 직접 방문해야 제시 가격을 알 수 있다.**

- 여러 매각처의 가격을 알아보려면 각각 방문해야 한다.
- 방문에는 게임 시간이 소모된다.

선택 근거: 사용자가 매각 가격 확인 방식 후보 2번 ‘직접 방문해서 확인’을 선택했다.

구체적인 방문 소요 시간과 상태 소모, 확인한 가격의 기록·유효 기간, 방문 중 여러 물품의 가격을 함께 확인할 수 있는지는 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

각 매각처 1시간 방문 필요. 방문 시 현재 보유한 취급 물품을 함께 견적 내며 게임 시간 2시간 유효. 재방문은 다시 시간 소모. 확인 전 가격 비공개.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

# 매각 가격 확인 방식

## 사용자 확정 — 이동은 행동이 아님

- 매각처마다 들어가서 제시 가격을 확인한다.
- 매각처 방문·재방문·다른 매각처로 이동은 행동으로 세지 않는다. 행동을 소모하지 않는다.
- 단순 이동으로 다음 날 전환·이자·문의·사건·만료를 처리하지 않는다.
- 이동에는 행동 진행 레이어·결과 토스트를 띄우거나 진행 기록을 추가하지 않는다. 선택한 매각처와 견적은 저장한다.
- 물품을 실제로 매각할 때는 기존의 판매 시간 행동 1회과 행동 조건을 적용한다.

이 결정은 이전의 ‘매각처 방문에 게임 시간 소모’ 정책을 대체한다. 기존 v1의 방문 시 취급 물품 일괄 견적·현재 시세 기준 제시 가격·견적 유효 기간 행동 2회은 유지한다. 유효 기간은 이동이 아닌 실제 행동으로 흐른 게임 시간을 기준으로 한다.

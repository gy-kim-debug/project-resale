# 복수 구매 문의와 필수 응답

**확정: 같은 물건에 여러 구매자의 문의를 받아 비교·선택할 수 있으며, 문의에는 반드시 답변해야 다음 행동으로 넘어갈 수 있다.**

- 한 물건에 여러 구매자의 문의를 받을 수 있다.
- 플레이어가 문의를 비교하고 거래할 구매자를 선택할 수 있다.
- 구매 문의를 답변하지 않은 채 다음 행동으로 넘어갈 수 없다.
- 자동 판매가 아니라 플레이어가 직접 응답한다는 [판매 성사 규칙](SALE_ACCEPTANCE.md)을 유지한다.

선택 근거: 사용자가 첫 일괄 질문 B의 2번 ‘여러 구매자의 문의를 받아 비교·선택 가능’을 선택했고, 후속 질문 C에서 ‘반드시 답변을 해야만 다음 행동으로 넘어갈 수 있음’이라고 직접 지정했다.

이전에는 게임 시간이 지나면 구매 문의가 만료될 수 있는 안을 선택했다. 이후 필수 응답 규칙이 지정됐으므로, 만료 규칙이 여전히 필요한지와 적용 시점은 재확인이 필요하다. 필수 응답을 우회해 다른 행동을 할 수 있는 것으로 해석하지 않는다.

문의 수량 제한, 여러 문의의 응답 순서와 처리 단위, 답변·네고에 드는 시간, 응답 진행 중 만료 적용 여부, 판매 완료 시 나머지 문의 처리는 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

한 물품에 2명 문의를 비교한다. 응답 전 다른 행동·탐색·폐기·메뉴 이탈 불가. 문의 자동 만료 없음. 저장·재접속에도 응답 의무 유지. 판매 완료 시 해당 글의 다른 문의도 정리한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

# 가격 합의 후 실제 거래

**확정: 가격에 합의하면 거래 행동 한 번으로 물건과 대금을 교환하고 완료한다.**

- 직거래 약속·이동이나 배송을 별도 단계로 진행하지 않는다.
- 거래 행동의 구체적인 소요 시간과 상태 소모량은 아직 정하지 않았다.

선택 근거: 사용자가 가격 합의 후 실제 거래 방식 후보 1번 ‘거래 행동 한 번으로 완료’를 선택했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

수락 한 번으로 1시간·물품 이전·제안 금액 수령. 별도 운반·약속·배송 단계 없음. 같은 문의 중복 수락은 거부한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

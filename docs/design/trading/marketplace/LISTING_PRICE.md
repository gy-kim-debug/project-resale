# 장터 판매 가격 설정과 수정 제한

**확정: 판매 가격은 플레이어가 원하는 가격으로 설정하되, 등록 후 가격 수정은 금지한다.**

- 등록 시 플레이어가 판매 가격을 자유롭게 정한다.
- 판매 글이 등록된 뒤에는 해당 글의 가격을 수정할 수 없다.

선택 근거: 사용자가 일괄 질문 A에 ‘원하는 가격 선택’, E에 ‘가격 수정 금지’라고 직접 지정했다.

가격 입력의 구체적인 허용 형식과 경계값, 판매 취소 후 다른 가격으로 재등록할 수 있는지, 파토 후 재등록 시 가격을 바꿀 수 있는지는 아직 정하지 않았다. ‘가격 수정 금지’를 취소·재등록으로 우회할 수 있다고 임의로 가정하지 않는다.

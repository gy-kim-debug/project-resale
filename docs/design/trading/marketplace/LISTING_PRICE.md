> 후속 사용자 결정: 닉네임 외 키보드 입력을 없앤다. 아래 이전 입력 정책은 [선택지 전용 UI](../../ui/CHOICE_INPUTS.md)의 판매 가격 후보 방식으로 대체한다.

# 장터 판매 가격 설정과 수정 제한

**확정: 판매 가격은 원하는 가격으로 설정하되 등록 후에는 수정할 수 없다. 판매 취소·만료 후 재등록할 때는 새로운 가격을 설정할 수 있다.**

- 등록 시 플레이어가 판매 가격을 자유롭게 정한다.
- 등록된 판매 글의 가격을 직접 수정할 수 없다.
- 판매를 취소하거나 글이 만료된 뒤 재등록할 때는 새로운 가격으로 등록할 수 있다.

선택 근거: 사용자가 첫 일괄 질문 A에 ‘원하는 가격 선택’, E에 ‘가격 수정 금지’라고 지정한 뒤, 후속 B의 1번 ‘새로운 가격으로 등록 가능’을 선택했다.

가격 입력의 구체적인 허용 형식과 경계값, 판매 글 시간 만료 후 재등록할 때의 가격 변경 여부, 취소·재등록 비용과 소요 시간은 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

100원–1,000조 원 범위로 반올림되는 금액을 자유 입력. 100원 단위 적용 금액을 확인 후 등록. 등록 중 수정 불가. 취소·만료 후 새 가격 재등록 가능. 등록 행동 1회, 취소 행동 1회, 금전 등록료 없음.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

후속 사용자 확정: 파토는 글을 종료하지 않는다. 등록 가격을 유지하며 새 구매자와 거래를 이어간다.

## 가격 선택 버튼과 직접 입력 — 사용자 요청

판매 등록 시 금액 선택과 직접 입력을 함께 제공하며 현재 가치를 선택지에 포함한다. 초기 선택지는 현재 가치·현재 가치 80%·현재 가치 120%·매입가이며 80/120% 배치는 개발자 UI 기본안이다. 매입가 0원은 유료 판매 가격 선택지에서 제외한다. 미감정 물품의 현재 가치는 미확인으로 표시하고 해당 선택지는 비활성화한다. 감정하지 않은 실제 가치나 시세를 역으로 공개하지 않는다.

선택은 입력란만 채우며 행동/저장 상태를 바꾸지 않는다. 선택 후 직접 수정할 수 있고 직접 입력한 금액이 선택 금액과 같으면 해당 선택 상태를 표시한다. 가격은 공통 100원 반올림을 사용한다. 실제 등록은 기존 번개가 있는 확정 버튼으로만 실행하고 등록 후 가격 수정 금지 규칙은 유지한다.

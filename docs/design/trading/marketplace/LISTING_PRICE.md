# 장터 판매 가격 설정과 수정 제한

**확정: 판매 가격은 원하는 가격으로 설정하되 등록 후에는 수정할 수 없다. 판매 취소·파토 후 재등록할 때는 새로운 가격을 설정할 수 있다.**

- 등록 시 플레이어가 판매 가격을 자유롭게 정한다.
- 등록된 판매 글의 가격을 직접 수정할 수 없다.
- 판매를 취소하거나 네고가 파토난 뒤 재등록할 때는 새로운 가격으로 등록할 수 있다.

선택 근거: 사용자가 첫 일괄 질문 A에 ‘원하는 가격 선택’, E에 ‘가격 수정 금지’라고 지정한 뒤, 후속 B의 1번 ‘새로운 가격으로 등록 가능’을 선택했다.

가격 입력의 구체적인 허용 형식과 경계값, 판매 글 시간 만료 후 재등록할 때의 가격 변경 여부, 취소·재등록 비용과 소요 시간은 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

1원–1,000조 원의 정수 자유 입력. 등록 중 수정 불가. 취소·파토·만료 후 새 가격 재등록 가능. 등록 1시간, 취소 1시간, 금전 등록료 없음.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

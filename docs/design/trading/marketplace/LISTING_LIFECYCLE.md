# 판매 글 만료와 네고 파토 후 처리

**확정: 판매 글은 일정 게임 시간이 지나면 만료되며, 네고가 파토나도 판매 글과 다른 문의가 모두 종료된다.**

- 판매 글은 일정 게임 시간이 지나면 만료되어 재등록이 필요하다.
- 여러 구매자 중 한 명과 네고가 파토나면 해당 판매 글과 다른 구매 문의도 종료된다.
- 다른 문의만 남겨 계속 거래하는 방식은 사용하지 않는다.
- 다시 장터에서 판매하려면 판매 글을 재등록해야 한다.
- 취소·파토 후 재등록할 때는 [새로운 가격으로 등록할 수 있다](LISTING_PRICE.md).

선택 근거: 사용자가 처음 파토 후 재등록을 선택한 뒤, 후속 일괄 질문 A의 1번 ‘판매 글과 다른 문의도 종료, 재등록 필요’, D의 2번 ‘일정 게임 시간이 지나면 만료되어 재등록 필요’를 선택했다.

판매 글 유효 기간과 만료 시점, 네고 중 판매 글 만료 여부, 재등록 비용·시간, 만료 후 재등록 가격 변경 여부, 구매 문의 만료를 파토와 동일하게 취급할지는 아직 정하지 않았다. 구매 문의의 유효 기간과 판매 글의 유효 기간은 구분한다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

글 유효 48시간. 문의 응답 중 만료 보류. 한 명과 파토나도 글·다른 문의 모두 종료, 재등록 필요. 만료 후에도 새 가격으로 재등록 가능.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

# 네고 파토 후 판매 글 처리

**확정: 네고가 파토나면 판매 글을 다시 등록해야 한다.**

- 네고 파토 후 다른 구매자를 계속 기다리는 판매 글로 그대로 유지하는 방식을 선택하지 않았다.
- 다시 장터에서 판매하려면 판매 글을 재등록해야 한다.

선택 근거: 사용자가 일괄 질문 D의 2번 ‘판매 글을 다시 등록해야 함’을 선택했다.

[복수 구매 문의](INQUIRIES.md)가 가능한 상태에서 구매자 한 명의 파토가 다른 문의와 판매 글 전체에 미치는 영향, 문의 시간 만료도 같은 파토로 취급하는지, 재등록 비용·시간·가격 변경 여부는 아직 정하지 않았다. 여러 문의가 모두 실패한 경우에만 재등록하는 것으로 임의 축소하지 않는다.

# 장터 판매 성사 방식

**확정: 구매 문의가 오면 플레이어가 직접 확인하고 거래를 수락하거나 거절한다.**

- 장터에 등록한 물건에 구매 문의가 올 수 있다.
- 구매자가 나타났다는 이유만으로 자동 판매하지 않는다.
- 플레이어가 문의를 확인한 뒤 거래를 수락하거나 거절한다.

선택 근거: 사용자가 장터 판매 성사 방식 후보 2번 ‘직접 거래 확정’을 선택했다.

복수 문의와 다음 행동 전 필수 응답은 [구매 문의 처리](INQUIRIES.md), 등록 가격에 따른 문의 변화는 [가격과 수요](PRICE_AND_DEMAND.md)를 따른다. 구체적인 문의 발생 조건·시점, 제안 가격과 네고 조건, 문의 만료 적용 여부와 거래 소요 시간은 아직 정하지 않았다. 수락 후 물품·대금 교환은 [가격 합의 후 실제 거래](TRANSACTION.md)을 따른다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

문의 수락·거절은 직접 선택한다. 수락 1시간, 거절 1시간. 자동 판매 없음. 수락하면 물품·대금 교환과 해당 글 문의 정리를 한 번에 진행한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

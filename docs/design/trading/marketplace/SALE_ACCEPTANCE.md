# 장터 판매 성사 방식

**확정: 구매 문의가 오면 플레이어가 직접 확인하고 거래를 수락하거나 거절한다.**

- 장터에 등록한 물건에 구매 문의가 올 수 있다.
- 구매자가 나타났다는 이유만으로 자동 판매하지 않는다.
- 플레이어가 문의를 확인한 뒤 거래를 수락하거나 거절한다.

선택 근거: 사용자가 장터 판매 성사 방식 후보 2번 ‘직접 거래 확정’을 선택했다.

구매 문의 발생 조건·시점, 구체적인 제안 가격과 네고 조건, 문의의 유효 기간과 거래의 구체적인 소요 시간은 아직 정하지 않았다. 수락 후 물품·대금 교환은 [가격 합의 후 실제 거래](TRANSACTION.md)을 따른다.

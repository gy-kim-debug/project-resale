# 판매 네고 진행 방식

**확정: 플레이어는 가격을 역제안하지 않고, 구매자의 제안에 수락·거절하거나 거래를 파토낼 수 있다.**

- 구매자가 가격을 제시하면 플레이어가 수락하거나 거절한다.
- 거절하면 구매자가 더 높은 가격을 제시하며 네고를 이어갈 수 있다.
- 이후 제안에도 플레이어가 수락하거나 거절하는 흐름을 반복할 수 있다.
- 구매자가 네고를 마음에 들어 하지 않으면 거래를 파토낼 수 있다.
- 플레이어도 거래를 파토낼 수 있다.
- 거절이 항상 가격 상승이나 거래 성사를 보장하는 것은 아니다. 구매자의 이탈 가능성이 있다.

선택 근거: 사용자가 수락·거절 방식을 선택하고, 거절 후 구매자의 상향 제안과 양쪽의 파토가 가능한 네고 흐름을 직접 지정했다.

파토 후에는 [판매 글 재등록 규칙](LISTING_LIFECYCLE.md)을 따른다. 구매자의 가격 인상 폭·상한, 파토 판단 조건, 협상 횟수 제한 여부와 제안별 시간 소모는 아직 정하지 않았다. 수락 후 실제 거래는 [가격 합의 후 실제 거래](TRANSACTION.md)을 따른다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

가격 역제안 없음. 거절하면 30% 즉시 파토, 아니면 최대 지불액 이내 약 12%·최소 1원 상향. 재제안 2회 또는 최대액 도달 후 추가 거절이면 파토. 각 응답 5분.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

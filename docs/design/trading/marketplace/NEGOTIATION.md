# 판매 네고 진행 방식

## 사용자 확정 — 최신 변경

- 판매할 때도 구매자와 채팅으로 흥정할 수 있다.
- 구매자가 제시한 금액에 수락·거절하거나 플레이어가 다른 판매 가격을 제안할 수 있다.
- 구매자는 플레이어 제안에 동의하거나 다른 금액을 재제안하거나 거래를 파토낼 수 있다. 플레이어도 파토 가능하다.
- 제안·재제안·거절·파토는 모두 행동 소모 없음이며 실제 판매 확정과 물품·대금 교환에만 행동 1회가 든다.
- 파토 시 해당 구매자와의 대화만 종료한다. 판매 글과 다른 문의는 유지한다.

이 결정은 이전의 ‘플레이어는 가격을 역제안하지 않음’과 ‘한 명과 파토 시 판매 글·모든 문의 종료’를 대체한다.

## 구현 정책 — 개발자 적용

- 현재 구매자 제안보다 높고 등록 가격 이하인 정수 금액을 입력해 제안한다. 등록 글의 가격 자체를 수정하지 않는다.
- 구매자의 기존 최대 지불 의사 이내이면 동의한다. 초과 제안은 30% 확률로 해당 구매자가 이탈하고, 그 외에는 현재 제안과 최대 지불 의사 사이 금액으로 재제안한다. 이미 한도에 도달했으면 이탈한다. 최대 지불 의사는 화면에 공개하지 않는다.
- 기존 재제안 횟수 2회는 가격 거절 후 재제안과 플레이어의 가격 제안에 함께 적용한다. 한도 후에는 현재 제안 수락·거절·파토를 선택한다.
- 동의 답변을 받아도 자동 판매하지 않는다. 플레이어가 거래를 확정해야 물품·대금을 교환한다.
- 대화 내용과 제안 금액은 즉시 저장하며 기존 v2 저장 형식을 유지한다.

## 공통 처리

플레이어 가격 역제안과 거절 응답을 `domain/bargaining.ts`의 `saleReply`로 통합했다. 최대 재제안 횟수와 파토 확률은 `content/bargaining.ts`가 관리하며 UI도 같은 한도를 읽는다. 기존 2회 한도·가격 범위·현금/행동 비용·글 유지 규칙은 바꾸지 않는다. 시장별 공략 차이는 이번에는 [NPC 구매 흥정](../bargaining/MARKET_STRATEGIES.md)에 적용하며 판매 문의의 시장별 차이는 추후 조정 대상으로 둔다.

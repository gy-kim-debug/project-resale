# 거래 채팅과 이어하기

## 사용자 승인 범위

구매·판매 대화를 채팅 탭에 모으고, 기존 대화를 다시 열어 남은 거래를 이어간다. 대화 열람·선택형 답변·흥정은 행동을 소모하지 않는다. 실제 구매·판매의 기존 번개 비용은 유지한다. 키보드 입력은 추가하지 않는다.

- 하단 탭: **채무 | 보관함 | 활동 | 채팅 | 일상**. 활동이 홈이다.
- 내 정보는 활동 화면의 버튼으로 들어간다. 도감은 보관함에 유지한다.
- 채팅 목록에 상대 별명·물품·마지막 대사·구매/판매·진행 상태·안 읽음을 표시한다. 진행 중/구매/판매/종료 필터를 제공한다. 기본은 진행 중인 방이며 구매·판매 필터도 진행 중인 방만 표시한다. 완료·파토·만료된 방은 종료 필터에만 표시한다.
- 같은 매물의 구매 대화는 같은 방으로 이어진다. 판매 문의는 구매자 문의별로 방을 구분한다.
- 진행 중 방은 기존 선택지·제안 가격·거래 상대 프로필·금액 비교를 그대로 사용한다. 일반 시장의 판매자 대화와 구매자 흥정은 기존 공통 엔진을 사용하며 경매는 기존 입찰 화면을 연결한다.
- 거래 완료·파토·기간 종료 방은 대화 열람만 가능하다. 거래를 다시 실행할 수 없다. 판매 파토는 판매 등록을 유지하고 이후 다른 구매자는 별도 방으로 들어온다.
- 새 문의는 안 읽음으로 표시하고 방을 열면 읽음으로 저장한다. 읽음 처리는 현금·행동·주가·난수·게임 기록을 바꾸지 않는다.

## 미응답 문의와 이동

미응답 문의가 있어도 탭·시장·상세·채팅을 자유롭게 이동한다. 화면에 문의 확인 바로가기를 표시한다. 실제 번개 소모 행동은 답변 전 실행할 수 없다. 무료 열람·흥정·가치 확인·수리·주식 주문 등의 기존 무료 행동은 가능하다. 정산 진입 자체는 가능하며 납부 시점의 기존 우선 처리는 유지한다. 판매 성사 시 같은 물품의 다른 문의는 기간 종료 기록으로 남긴다.

이 규칙은 과거 문서의 ‘문의가 오면 화면 이탈 자체 금지’를 대체한다.

## 저장과 호환 — 구현 정책

- `domain/chats.ts`가 공개된 대사와 표시 금액만 기록한다. 구매자 최대 허용가·물품 숨은 가치 등은 채팅 기록으로 공개하지 않는다.
- 기존 물품/문의가 거래의 원본이며 기록은 거래 결과와 함께 동기화한다. 가격·확률·경제 계산은 변경하지 않는다.
- IndexedDB 자동 저장·저장 슬롯·백업/복원에 기록과 읽음 상태를 포함한다. 새로고침하면 채팅 목록으로 복귀하고 방을 다시 열어 같은 대화와 남은 선택지를 이어간다.
- 기존 저장에 남아 있는 물품 대화·현재 문의는 이전한다. 이미 판매·삭제되어 원본 데이터에 없는 과거 대사는 복구할 수 없다. 이번 변경 이후 거래 완료·물품 매각 후에도 기록이 남는다.
- 매물 갱신·만료로 구매 원본이 사라지면 해당 방은 기간 종료 처리한다. 기록을 열어 사라진 물품을 구매할 수 없다.
- 보관 상한은 최근 200개 방, 방당 최근 128개 대사다. 오래된 종료 방부터 제거하며 진행 중인 방은 우선 보존한다. 이는 저장 크기 관리를 위한 개발자 초기 정책이다.
- 스토리·이벤트 연출 대화는 거래 채팅 기록과 별개다.

## 검증

`tests/chats.test.ts`, `tests/actions.test.ts`에서 재접속·이전·읽음·파토·완료 후 중복 실행 차단·문의 이동/행동 제한을 검증한다. `scripts/prepare-chat-fixtures.mjs`, `scripts/verify-chats.py`는 실제 IndexedDB와 모바일 브라우저에서 이어하기를 확인한다.

## 종료 채팅 나가기

완료·파토·기간 종료된 채팅방에는 화면 하단에 `채팅 나가기`를 고정 표시한다. 누르면 현재 레이어를 닫고 채팅 탭 목록으로 돌아간다. 대화·읽음·거래 결과·현금·행동은 변경하거나 삭제하지 않는다. 진행 중인 방에는 별도 종료 버튼을 표시하지 않으며 기존 뒤로/닫기로 이동한다. 종료된 방을 다시 열어도 같은 나가기 버튼을 사용할 수 있다. 남은 행동이 0일 때는 기존 정산 버튼도 함께 유지한다.

## 답변 대기 연출 — 2026-11-13

사용자 요청에 따라 질문과 가격 제안 뒤 상대방 답변에 짧은 간격을 둔다. 구매자·판매자 채팅에 공통 적용한다.

- 내가 고른 메시지는 즉시 표시한다. 상대는 말풍선의 점 세 개로 입력 중임을 표시한 뒤 약 0.65~1초 후 답한다. 여러 답변은 같은 간격으로 순차 표시한다. 간격은 문장 길이에 따라 계산하며 게임 난수를 사용하지 않는다.
- 같은 채팅의 질문·추가 흥정·거래 확정은 답변이 모두 표시될 때까지 잠근다. 저장소 명령 진입점에서도 중복 실행을 막는다. 다른 채팅/화면 탐색은 허용하며 대기 상태는 화면을 나가도 계속된다.
- 채팅 목록은 대기 중인 답변 대신 입력 중 표시를 사용한다. 거래 종료 답변도 먼저 연출을 마친 뒤 종료 문구와 나가기 버튼을 표시한다.
- 경제/대화 결과는 기존 순수 엔진에서 한 번만 결정해 즉시 저장한다. 지연은 웹의 일시적 표시 상태이며 돈·시간·행동·확률을 추가로 소모하지 않는다. 저장 형식은 바꾸지 않는다.
- 재접속/새로고침 시 이미 저장된 대화는 즉시 보여주고 연출을 재실행하지 않는다. 메뉴 복귀·슬롯 전환·백업 가져오기는 대기 타이머를 정리한다. 기존 기록이나 최초 판매자 안내를 열 때도 지연하지 않는다.
- OS/게임의 모션 감소 설정에서는 점 애니메이션만 멈추고 답변 간격은 유지한다. 입력 중 상태는 접근성 알림으로도 제공한다.

`src/app/chatReplies.ts`는 채팅별 표시 큐와 타이머만 관리한다. `TradeChat`과 구매/판매 선택지가 이를 공유하며 도메인 계산과 분리한다.

## 채팅 탭 목적 재확인 — 2026-11-13

채팅 탭은 진행하던 거래를 재개하는 화면이다. 단순 대화 기록 화면으로 취급하지 않는다. 기본 진입은 진행 중이며 해당 원본 매물/문의의 선택지·흥정 가격·입력 중 답변·결제/수락 흐름을 그대로 사용한다. 진행 중인 방이 없으면 그 상태를 표시하고 종료 기록으로 자동 전환하지 않는다. 새로고침 후에도 채팅 방을 열어 남은 거래를 계속한다. 종료 기록은 별도 필터로 보존하며 거래를 다시 실행하지 않는다.

# 구매 후 상태·결함 확인

## 사용자 확정 — 최신 변경

- 구매 전 상태 확인 행동을 없앤다. 상태는 구매 후에 알 수 있다.
- 매물 화면에는 실제 상태·결함·실제 가치를 공개하지 않는다. 과거 저장에 구매 전 확인 이력이 있어도 상태를 표시하지 않는다.
- 구매·나눔 수령·수집 후 보관함 상세에서 상태(양호·사용감·고장)를 즉시 표시한다. 상태 공개 자체는 추가 시간이나 비용이 없다.
- 실제 가치·숨겨진 결함·가품 여부는 기존의 별도 가치 확인(행동 소모 없음·감정 비용)으로 공개한다. 별도 가치 확인과 수리의 기존 정책은 유지한다.

이 결정은 이전의 ‘구매 전 일부 결함 확인 가능’ 및 구매 전 확인 비용 정책을 대체한다. 구매 전 상태 확인 명령과 비용 청구는 제거했다.

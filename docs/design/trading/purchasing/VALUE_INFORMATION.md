# 구매 전후 물건 가치 정보

**확정: 구매 전에는 판매자가 올린 가격만 보여주고, 실제 가치는 구매해야 알 수 있다.**

- 구매 전 장터 화면에서 게임이 실제 가치나 별도의 예상 시세를 표시하지 않는다.
- 가격 정보는 판매자가 올린 가격을 보여준다.
- 실제 가치는 구매한 뒤 알 수 있다.
- 물건 설명·상태와 숨겨진 결함의 확인 규칙은 [구매 전후 결함 확인](DEFECT_DISCOVERY.md)을 따른다. 판매자 가격만 보여준다는 결정으로 기존의 상태·결함 확인 선택을 없애지 않는다.

선택 근거: 사용자가 구매 정보 질문 C에 ‘판매자가 올린 가격만 보여주고 실제 가치는 구매해야 알 수 있음’이라고 직접 지정했다.

구매 후 실제 가치를 바로 표시하는지 별도 확인 행동이 필요한지, 구체적인 표시 방식, 상태·결함 발견에 따른 가치 변화는 아직 정하지 않았다. 별도 유료 감정이 필수라고 가정하지 않는다.

# 구매 전후 물건 가치 정보

**확정: 구매 전에는 판매자가 올린 가격만 보여주고, 실제 가치는 구매해야 알 수 있다.**

- 구매 전 장터 화면에서 게임이 실제 가치나 별도의 예상 시세를 표시하지 않는다.
- 가격 정보는 판매자가 올린 가격을 보여준다.
- 구매한 직후 실제 가치가 자동 공개되는 것은 아니다. 별도의 확인 행동을 해야 알 수 있다.
- 물건 설명·상태와 숨겨진 결함의 확인 규칙은 [구매 전후 결함 확인](DEFECT_DISCOVERY.md)을 따른다. 후속 사용자 결정으로 구매 전 상태 확인은 제거했다. 상태는 구매 후 보관함 상세에서 바로 표시한다.

선택 근거: 사용자가 구매 정보 질문 C에 ‘판매자가 올린 가격만 보여주고 실제 가치는 구매해야 알 수 있음’이라고 직접 지정했다.

후속 선택 근거: 사용자가 구매 후 가치 공개 시점 A의 2번 ‘별도의 확인 행동을 해야 공개’를 선택했다.

확인 행동의 구체적인 방식·비용·소요 시간, 표시 방식, 상태·결함 발견에 따른 가치 변화는 아직 정하지 않았다. 별도 유료 감정이 필수라고 가정하지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

구매 전 판매자 가격만 표시. 구매 후에도 별도 가치 확인 전 실제 가치 비공개. 행동 소모 없음. 실제 기본 가치의 1%·최소 50원, 감정 레벨 할인. 공개 뒤 본래 가치와 현재 시장 기준을 구분한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

# 물건 구매 시 운반비

**확정: 별도 운반비는 없다.**

- 물건을 구매해 획득할 때 물건값 외 별도 운반비를 부과하지 않는다.
- 구매 합의 후 [행동 한 번으로 거래를 완료](TRANSACTION.md)하는 규칙을 유지한다.

선택 근거: 사용자가 구매 비용 질문 F에 ‘운반비 없음’이라고 직접 지정했다.

운반비가 없다는 결정은 거래 행동의 시간·상태 소모까지 없다는 뜻은 아니다. 구체적인 소요 시간과 상태 소모량은 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

운반비 없음. 매입·나눔 수령은 지불/수령 15분 행동에 포함한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

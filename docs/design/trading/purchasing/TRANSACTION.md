# 구매 합의 후 거래 완료

**확정: 구매에 합의하면 행동 한 번으로 대금을 지불하고 물건을 획득한다.**

- 구매 합의 후 별도의 예약 대기 단계를 두지 않는다.
- 한 번의 거래 행동으로 대금 지불과 물건 획득을 완료한다.

선택 근거: 사용자가 구매·정보·보관 일괄 질문 B의 1번 ‘행동 한 번으로 대금 지불·물건 획득 완료’를 선택했다.

별도 [운반비는 없다](TRANSPORT_COST.md). 구체적인 소요 시간과 상태 소모량은 아직 정하지 않았다. 한 번의 행동으로 끝난다는 규칙을 시간 소모가 없다는 뜻으로 해석하지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

행동 1회 한 행동으로 합의 가격 지불·물품 수령. 비용·공간·조건을 먼저 검사하여 거부 시 자원 유지. 중복 구매 불가.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

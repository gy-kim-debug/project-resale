# 장터 구매 가격 협상

## 사용자 확정

- 플레이어는 가격 선택지로 판매자에게 네고할 수 있다.
- 채팅으로 여러 번 제안과 역제안을 주고받는다. 이전 한 매물 1회 제한을 대체한다.
- 흥정과 종료에는 행동을 쓰지 않는다. 실제 구매와 물품 수령에만 행동 1회를 쓴다.
- 구매 전에는 물품 상태나 실제 가치를 공개하지 않는다.

## 중고 장터 기준 수치 — 개발자 조정안

중고 장터 첫 제안은 게시가의 70% 또는 85%다. 다른 시장의 초기 제안·판매 성향 보정·접근 전략은 [시장별 흥정 공략](../bargaining/MARKET_STRATEGIES.md)을 따른다. 첫 제안 시 판매자의 최소 수락 가격(게시가 78–90% 미만, 100원 단위 반올림)과 인내심(4–6라운드)을 난수로 결정해 저장한다. 물품 실제 가치·상태·감정 결과는 흥정 판정에 사용하지 않는다.

제안이 최소 수락 가격 이상이면 합의한다. 그보다 낮으면 판매자는 현재 제시 가격과 플레이어 제안 간격의 15–30% 미만을 양보하되 최소 수락 가격 아래로 내리지 않는다. 25% 확률로 가격을 고수한다. 다음 플레이어 선택지는 직전 제안과 판매자 역제안 사이의 25%·50%·75% 지점이며 중복과 범위 밖 금액은 제거한다. 지난 가격의 반복 전송은 거부한다.

인내심에 도달한 미합의 제안에서는 30% 확률로 판매자가 거래를 끊고 해당 매물 구매를 거절한다. 그 외에는 마지막 가격을 제시하며 추가 네고 없이 그 가격으로 구매할 수 있다. 합의·최종 가격·파토 이후에는 재흥정을 시작할 수 없다. 플레이어도 언제든 흥정을 종료할 수 있다. 단순 화면 닫기·재접속으로 라운드나 판매자의 한계가 초기화되지 않는다.

게시가는 유지하고 구매 확인창에는 최신 합의/역제안 가격을 적용한다. 비용 부족·공간 부족 시 구매는 원자적으로 거절한다. 판매자 파토를 제외하고는 현재 가격으로 구매 가능하다. 무료나눔·경매 입찰·즉시 판매 가격 정책에는 적용하지 않는다.

## 저장 호환

물품별 `purchaseBargain`에 라운드·판매자 한계·파토 상태·선택 필드 previousOffer를 저장하고 대화는 누적한다. 최대 6회 답변과 마지막 구매/종료 메시지를 포함할 수 있게 채팅 검증 상한은 16개다. 구버전의 미시작 매물은 새 규칙으로 흥정하고, 이미 끝난 예전 대화의 결과·금액은 유지한다. 잘못된 협상 상태는 백업 검증에서 거절한다.

## 매물 태그에 따른 판매 성향

신규 태그 매물은 [실제 판매 성향별 프로필](../../items/LISTING_TAGS.md)에 따라 최소 수락가·인내심·고수 확률·양보 폭을 정한다. 위 일반 프로필은 실제 일반 성향과 태그 정보가 없는 구 물품의 기본값이다. 표시 태그는 틀릴 수 있으며 실제 성향을 사용한다. 이미 저장된 최소 수락가·인내심은 유지한다.

일반 시장 5곳은 공통 구매 흥정 함수를 사용한다. 시장별 숫자는 콘텐츠 데이터에 분리하고 게임 화면에는 공략 설명을 붙이지 않는다. 이미 시작한 협상의 수락가·인내심·가격은 유지한다.

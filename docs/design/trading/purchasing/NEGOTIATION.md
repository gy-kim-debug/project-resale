# 장터 구매 가격 협상

**확정: 장터에서 물건을 구매할 때 판매자에게 가격을 깎는 네고가 가능하다.**

선택 근거: 사용자가 구매·정보·보관 일괄 질문 A의 2번 ‘가격을 깎는 네고 가능’을 선택했다.

**추가 확정: 플레이어가 구매 가격을 제안하되, 선택지에서 고르는 방식으로 진행한다.**

- 플레이어가 제시할 구매 가격을 선택지에서 고른다.
- 판매자는 플레이어의 제안에 응답한다.

선택 근거: 사용자가 후속 F에서 ‘1번인데 선택지가 있는 걸로’라고 지정했다.

가격 선택지의 구성·개수·금액, 별도 자유 입력 허용 여부, 판매자의 구체적인 대응, 협상 횟수·시간·파토 조건은 아직 정하지 않았다. 장터 판매 시의 네고 규칙을 구매에도 자동으로 적용하지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

게시 가격의 70% 또는 85% 선택, 수락률 40%/80%, 15분. 한 매물 1회만 제안. 거절 후 원래 가격 구매 가능, 재협상·자유 입력 없음.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

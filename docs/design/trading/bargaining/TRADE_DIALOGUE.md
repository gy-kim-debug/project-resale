# 선택지형 거래 대화

## 사용자 요청

- 가격 흥정만 하는 채팅에서 인사·상태 질문·거래 관련 대화와 이벤트로 확장한다.
- 직접 입력 대신 선택한 문장이 플레이어 말풍선으로 입력된다.
- 판매자 성향·나이·성별·상품 상태·새 상품/한정판 등 맥락을 반영한다.
- 기존 원칙에 따라 대화는 행동을 소비하지 않으며 구매 완료만 행동 1회를 소비한다.

## 이번 적용 범위

중고 장터·전자상가·악기시장·중고차시장·부동산의 판매자 채팅과 무료나눔 문의에 적용한다. 경매는 기존 진행자/입찰 흐름, 판매 중 구매자 문의는 기존 가격 선택지 흐름을 유지한다. 구매자와의 일반 대화·경매 출품자 질의는 후속 확장 범위다.

인사, 사용 상태, 구성품/자료, 게시글 특징, 판매 이유, 사용 배경을 질문할 수 있다. 상태나 특징 답변 뒤에는 상세 질문, 대화 뒤에는 감사 인사도 선택할 수 있다. 구매 제안과 구매 확정은 기존 경로를 사용한다. 질문 순서를 강제로 따를 필요는 없다.

상태/판매 이유를 처음 질문하면 판매자가 조건을 되묻는다. 가격 고정, 빠른 결정, 미개봉 유지, 작동 미확인/본품만, 소장품 등의 맥락에 따라 질문이 달라지고, 플레이어는 조건을 확인하거나 더 살펴보겠다고 답할 수 있다. 두 선택은 서로 배타적이며 다음 질문으로 이어진다. 이 분기는 예약·경쟁 구매·검사·배송 같은 새 시스템을 실제로 실행하지 않는다.

## 인물과 물건 반영

- 가격 고정: 할인 불가를 일관되게 안내한다.
- 쿨거래: 간결한 응답, 빠른 결정을 선호한다.
- 신중한 거래: 추가 질문과 설명을 선호한다.
- 유연한 흥정: 설명을 듣고 조율하는 태도에 긍정적으로 반응한다.
- 큰 폭 흥정·일반 거래도 기존 가격 성향을 유지한다.
- 나이·성별은 가상 프로필, 사용 배경 대답과 인물별 문장 변형에만 활용한다. 특정 나이/성별이 정직하거나 유리한 가격을 주도록 만들지 않는다.
- 차량은 상태/정비·차량 자료, 부동산은 내부 설비·관련 자료를 질문한다.
- 미개봉, 작동 미확인, 장기 보관, 풀구성, 본품만 등 케이스가 답변에 반영된다.
- 폐업 정리·소장품·미확인 특가의 판매 이유와 보증 조건을 반영한다.
- 한정판/정품/빈티지/단종 등의 답변은 게시글 주장에 기초한다. 실제 진위 판별 결과를 무료로 알려주지 않는다.

## 초기 구현 수치 — 개발자 조정값

아래는 사용자 확정 밸런스가 아니며 플레이 후 조정할 수 있다.

- 일반 상태 답변의 솔직한 설명 비중 85%. 나머지는 낙관적이거나 불확실한 답변이다. 미개봉/미확인 매물은 작동 확인을 보증하지 않는다.
- 상태 설명은 판매자가 알고 있다고 주장하는 내용이다. 숨겨진 결함 문구, 정확한 가치, 진위 결과는 공개하지 않는다. 구매 후 감정 규칙을 유지한다.
- 인사·조건 확인과 성향에 맞는 답변으로 호감이 최대 2까지 상승한다. 최초 흥정 하한에 최대 2%p만 반영하며 가격 고정에는 적용하지 않는다.
- 이미 정해진 흥정 하한은 이후 대화로 변경하지 않는다. 실제 상품 가치·상태·판매 문의 확률도 변경하지 않는다.
- 동일 질문 및 조건 응답을 재선택할 수 없다. 대화만으로 가격이 자동 인하되지 않는다.
- 답변의 변형과 솔직함은 매물/인물 식별자로 고정한다. 다시 열기·저장 불러오기·질문 반복으로 재추첨하지 않으며 경제 난수 시드도 소비하지 않는다.

## 저장과 확장

`Item.dialogue`에 선택한 주제와 호감을, 기존 `Item.chat`에 양쪽 말풍선을 저장한다. 구매 후에도 기록을 유지한다. 기존 저장에 해당 필드가 없어도 정상 동작한다. 최대 64개 메시지, 11종 주제, 중복 없는 선택을 저장 검증한다.

대화 선택지/조정값은 `content/tradeDialogue.ts`, 응답·분기 순수 함수는 `domain/tradeDialogue.ts`가 관리한다. UI는 선택지를 렌더링하고 명령을 보내며 문구나 가격 계산을 직접 결정하지 않는다. 새 대화 사건을 추가할 때는 조건·선택지·일회성 효과·저장 호환성 테스트를 함께 추가한다.

## 채팅 UI 개선

판매자와 채팅을 열면 상품 상세 대신 전용 대화 화면으로 전환한다. 채팅 중에는 상태 헤더 영역까지 확장하며 상품 상세로 돌아가면 기존 헤더를 복원한다. 상단에는 판매자·상품명·현재 제안 가격을 간결하게 표시하고, 가운데 대화 기록과 하단 선택 영역을 분리한다. 하단은 `질문` / `가격 제안`으로 전환하며 질문 버튼에는 짧은 이름을 표시하되 선택 시 기존 전체 문장을 전송한다. 조건 확인 대기 표시는 질문 메뉴에 붙인다. 상품 보기 → 대화 이어보기로 이동할 수 있고, 구매 확인 중에는 선택 영역을 접어 확인 버튼을 확보한다. 대화 종료는 상단에서 명시적으로 선택한다. 경제·분기·행동·저장 규칙은 변경하지 않는다.

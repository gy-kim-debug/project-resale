# 시장별 흥정과 공통 처리

## 사용자 요청과 기존 규칙

일반 시장 전체의 흥정 지원을 검토하고, 로직을 공통화하면서 시장마다 공략 방식이 조금씩 달라지도록 한다. 공략과 구현 정책을 문서로 먼저 기록한 뒤 코드에 적용한다.

일반 시장 5곳은 모두 판매자 채팅·가격 선택·반복 역제안·합의·최종가·파토를 지원한다. 고가 경매시장 구매만 입찰 방식이며 즉시 판매는 실제 가치 60% 고정이다. 흥정은 행동·현금·기한을 소모하지 않고 실제 구매/판매 확정에만 행동 1회가 든다. 구매 전 실제 가치·결함은 공개하지 않는다. 아래 숫자와 전략은 사용자 확정 수치가 아닌 **개발자 초기 밸런스안**이다.

## 시장별 초기 공략

| 시장          | 첫 제안 / 게시가 | 일반 성향 최소 수락가 | 대화의 특징과 유리한 접근                                                                                                                                  |
| ------------- | ---------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 중고 장터     | 70%, 85%         | 78–90% 미만           | 기준 시장. 낮게 시작해 역제안에 맞춰 가격을 올리거나 바로 합의한다.                                                                                        |
| 전자상가      | 80%, 90%         | 82–94% 미만           | 호가에 민감하다. 현재 판매자 가격의 90% 이상 제안에는 양보가 커진다. 게시가 82% 미만의 과도한 저가는 35% 확률로 조기 파토 위험이 있다.                     |
| 악기시장      | 70%, 85%         | 78–90% 미만           | 차분한 조율. 이전 제안과 현재 판매자 가격 사이 간격의 절반 이하로 조금씩 올리면 양보가 커진다. 인내심을 1회 늘리되 최대 6회다.                             |
| 중고차시장    | 65%, 85%         | 76–88% 미만           | 마지막 조건을 확실히 올리는 방식. 두 번째 제안부터 남은 간격의 65% 이상을 올리면 양보가 커진다.                                                            |
| 부동산 시장   | 75%, 90%         | 80.5–92.5% 미만       | 초반은 가격을 고수하지만 세 번째 제안부터 양보가 커진다. 낮은 초기 제안으로 몇 차례 조율할지, 높은 제안으로 바로 합의할지 선택한다. 인내심 +1회, 최대 6회. |
| 고가 경매시장 | 기존 입찰 선택지 | 판매자 수락가 없음    | 경쟁 입찰·낙찰·결제. 일반 흥정으로 우회하지 못한다. 보유품의 경매 출처 위탁 판매 문의는 기존 판매 흥정 규칙을 사용한다.                                    |

일반 성향을 기준으로 설명한 범위다. 실제 급처·이사정리·네고환영·가격고정 성향이 시장 보정에 함께 적용된다. 표시 태그는 틀릴 수 있으므로 확정 공략 정보가 아니다. 실제 가격고정 판매자는 어느 시장에서도 게시가보다 낮게 팔지 않는다. 유리한 접근은 양보 폭과 가격 고수 확률에 영향을 주며 최소 수락가를 뚫는 성공을 보장하지 않는다.

## 공통 구매 흥정 처리

1. 시장별 최초 가격 선택지를 생성한다. 선택지 중 현재 유효한 금액만 전송할 수 있다.
2. 첫 제안에서 실제 판매 성향과 시장 설정으로 최소 수락가·4~6회 인내심을 생성하고 저장한다.
3. 현재 가격과 이전 플레이어 제안, 제안 횟수로 접근 방식을 판정한다. 실제 가치·품질·가품 여부·캐릭터 능력치는 사용하지 않는다.
4. 최소 수락가 이상이면 합의한다. 전자상가 저가 위험, 인내심 종료 파토, 가격 고수 또는 제한된 양보를 공통 함수에서 처리한다.
5. 기본 양보 배율은 중고 장터/악기 1.0, 컴퓨터 0.7, 중고차 1.1, 부동산 0.7이다. 유리한 접근 시 악기/중고차 +0.5, 컴퓨터 +0.4, 부동산 +0.8을 더하고 가격 고수 확률을 0.15 낮춘다. 부동산 기본 고수 확률은 +0.15다. 확률은 0~1로 제한한다.
6. 역제안은 현재 가격 이하·저장된 최소 수락가 이상이다. 다음 선택지는 직전 플레이어 제안과 새 역제안 사이 25%·50%·75%이며 중복을 제거한다.
7. 인내심 마지막 미합의 시 30% 파토, 그 외 최종가다. 합의·최종가·파토·플레이어 종료 후 재시작할 수 없다.

`src/content/bargaining.ts`가 조정 가능한 시장별 설정을 보관한다. `domain/purchaseBargaining.ts`는 선택지·프로필·접근 판정, `domain/bargaining.ts`는 구매와 판매 문의의 순수 상태 전이를 담당한다. `engine.ts`는 명령 검증·난수 공급·결과 적용·로그만 연결한다. 시장별 엔진/화면을 복제하지 않는다.

## 공통 판매 문의 처리

구매자 대상 역제안과 거절을 하나의 순수 함수로 통합한다. 가격 입력 범위, 최대 2회 재제안, 구매자의 최대 지불 의사, 파토 시 해당 문의만 제거, 판매 글/다른 문의 유지를 보존한다. 구매자와 판매자의 역할이 다르므로 한 계산식으로 억지로 합치지 않는다. 이번 시장별 차이는 **NPC에게 구매하는 흥정**에 적용한다. 판매 문의의 시장별 성격은 추후 조정 대상으로 남긴다.

## UI·저장 호환·검증

게임 메뉴에 공략 설명을 붙이지 않는다. 공통 채팅 화면에서 제안 가격과 시장에 맞는 대사로 반응을 보여준다. 이미 생성된 매물의 선택지와 시작한 대화의 최소 수락가·인내심·현재 가격·로그를 재설정하지 않는다. 새 `previousOffer`는 선택 필드로 저장하고, 구 대화에는 다음 실제 제안부터 누적한다. 매물 출처 ID가 없는 저장은 중고 장터로 처리한다.

시장별 구매→흥정→구매 확정 경로, 전략 효과, 가격고정 예외, 고액/원 단위 경계, 잘못된 명령의 원자적 거절, 파토 후 구매 차단, 재접속·백업·행동 0회 흥정을 검증한다. 경매와 즉시 판매는 기존 회귀 검증을 유지한다.

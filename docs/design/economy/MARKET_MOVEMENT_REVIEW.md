# 현재 시세 변동 점검 — 2026-11-13

## 범위

사용자가 행동 후 현재 가격 변동이 크다고 느껴 점검을 요청했다. 물건 현재 시세와 주식 현재가를 모두 검토했다. 이 문서는 현행 계산과 제안을 구분한다. 이번 변경에서는 가격 수치·갱신 주기·난수·확률을 변경하지 않는다.

## 현행: 보유 물건의 현재 시세

`domain/engine.ts`의 `marketValue`는 실제 가치 × (시장 계수 + 유행 보너스)를 계산하고 100원 반올림과 기존 가치 상한을 적용한다. 실제 가치 자체가 재추첨되는 것은 아니다.

- 시장 계수는 85~115% 중 정수다.
- 품목 Kind가 현재 유행과 같으면 20%p를 추가한다. 따라서 합산 계수의 범위는 85~135%다.
- 내부 날짜가 바뀔 때 계수와 유행을 새로 뽑는다. 보통 행동 1회가 내부 480분이므로 연속 행동 3회마다 갱신한다. 매 행동 무조건 갱신하는 방식은 아니다. 무료 대화·수리·가치 확인은 시세를 갱신하지 않는다.
- 직전 계수에 작은 변화를 더하는 방식이 아닌 범위 전체 재추첨이다. 유행도 바뀌므로 같은 물건이 보너스를 얻거나 잃을 수 있다.

실제 가치가 100,000원이고 가치 상한에 걸리지 않는 물건의 예:

| 상황                      | 현재 시세 |
| ------------------------- | --------: |
| 시장 계수 85%, 유행 아님  |  85,000원 |
| 시장 계수 115%, 유행 일치 | 135,000원 |

이 두 극단을 연속으로 뽑으면 이전 표시 대비 상승 약 58.8%, 역방향 하락 약 37.0%가 가능하다. 매번 이런 폭으로 변한다는 뜻은 아니며, 물건 실제 가치가 변한 것도 아니다. 보유 물건의 호가 불확실성과는 별개로 이미 감정한 물건의 시세까지 크게 바뀌어 비교/등록 판단이 흔들릴 수 있다.

시드 42에서 같은 생활 물건의 `walk` 0~9회 재현도 1/2회는 동일, 3/6/9회에 시장 계수·유행이 바뀌는 것을 확인했다. 한 번의 행동으로 결제하는 거래, 정산으로 시간을 건너뛰는 경우는 실제 경과/정산 로직을 따른다.

## 현행: 주식 현재가

`domain/daily.ts`의 `advanceStocks`가 실제 소비한 행동 1회마다 직전 주가에 변동률을 적용한다. 주식 주문·열람·무료 대화는 시세를 갱신하지 않는다. 주식 전용 난수 시드를 사용한다.

| 테마    | 행동당 변동률 추첨 범위 |
| ------- | ----------------------- |
| 반도체  | -1%, 0%, +1%            |
| 바이오  | -2~+2%, 1%p 단위        |
| 2차전지 | -4~+4%, 1%p 단위        |

100원 반올림과 100원~10억 원의 주가 제한이 적용된다. 변동은 복리로 누적되며 고변동 테마의 연속 상승/하락은 체감 폭이 커질 수 있다. 이는 물건 시세의 85~135% 재추첨과 다른 계산이다.

## 제안 — 미확정·미적용

1. 물건 시세의 시장 계수를 직전 값에서 소폭 움직이게 바꾸는 것을 우선 추천한다. 예를 들어 갱신당 ±1~2%p씩 이동하고 전체 범위는 별도로 제한한다. 기존의 3행동 갱신은 유지할 수 있다.
2. 유행 보너스는 현재 20%p보다 작은 3~5%p 수준을 후보로 검토한다. 보너스 전환까지 포함한 최종 변동 폭을 비교해야 한다.
3. 주식도 큰 폭이라고 느낀다면 테마별 차이는 유지하면서 변동률을 낮추는 별도 조정을 검토한다. 주식 가격을 물건 시세 방식으로 통합하지 않는다.
4. 갱신 주기·상하한·복귀 시점·기존 저장의 현재 계수 처리·거래 수요/제안 금액에 미치는 영향을 확인한 뒤 수치를 확정한다. 가격 변경은 플레이 결과를 보고 별도 작업으로 적용한다.

# 아직 정하지 않은 내용

기존 설계서의 미정 사항을 옮긴 문서다. 아래 항목은 확정 규칙이 아니며, 기존 초안의 제안을 자동으로 채우지 않는다.

무료 나눔의 구체적인 등장·갱신·수령 조건과 물품 내용, 물건 수집의 세부 진행 방식·물품 구성·가치 분포, 아르바이트의 구체적인 일거리 목록·보수·소요 시간, 각 방법의 비용·위험·구체적인 상태 조건은 아직 정하지 않았다. 체력·포만감·피로도의 범위·초기값·구체적인 변화량, 피로도 0에서 다음 날로 넘어갈 때의 세부 처리는 미정이다. 아르바이트가 선택됐다는 이유로 별도의 직업 상태나 성장 시스템을 추가하지 않는다. 나머지 세부 규칙은 다음 논의에서 결정하며, 후보를 제시했다는 이유만으로 규칙에 포함하지 않는다.

세부 미정 사항은 [주제별 목차](README.md)의 각 문서를 확인한다. 결정이 나면 해당 주제 문서와 이 목록을 함께 갱신한다.

## 판매·네고 일괄 결정 후 남은 사항

- [가격 설정·수정 제한](trading/marketplace/LISTING_PRICE.md): 취소 또는 파토 후 재등록할 때 다른 가격을 설정할 수 있는지.
- [복수 구매 문의](trading/marketplace/INQUIRIES.md)와 [파토 후 재등록](trading/marketplace/LISTING_LIFECYCLE.md): 한 구매자의 파토가 다른 문의·판매 글 전체에 미치는 영향, 문의 만료도 파토와 동일하게 처리하는지.
- 등록·취소·재등록·문의 응답·네고의 구체적인 시간·상태 소모·비용.
- [매각처 네고](trading/outlets/NEGOTIATION.md)의 가격 격차 기준, 인상 상한과 파토 후 처리.
- [가격과 수요](trading/marketplace/PRICE_AND_DEMAND.md)의 판단 기준과 구체적인 발생 규칙.

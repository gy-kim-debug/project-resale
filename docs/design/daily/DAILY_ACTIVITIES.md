# 일상 탭

## 사용자 요청으로 확정한 방향

- 기존 사업 탭을 중고거래 외 활동을 하는 공간으로 개편한다. 명칭은 변경할 수 있다.
- 복권을 구매하고 주간 정산 후 당첨 등수를 이벤트로 확인한다.
- 코인 또는 주식 중 하나를 매매한다. 행동 시세 갱신과 그래프, 탭 안에서 매수·매도를 제공한다.
- 아르바이트는 행동 1회로 정해진 금액을 받는다.
- 산책은 시간을 보내는 행동이며 특수한 사건이 일어날 수 있다.
- 키보드 입력은 닉네임에만 사용한다. 행동 소모는 번개 아이콘으로 표시한다.

## 이번 구현에서 선택한 초기 정책

- 이름은 **일상**으로 한다. 기존 거래 도중 발생하는 스토리 이벤트와 하단 메뉴의 의미를 구분한다.
- 투자 대상은 가상 주식으로 한다. 실시간 시세나 실제 기업·외부 금융 서비스와 연결하지 않는다.
- 네 활동은 세로 목록으로 표시한다. 아르바이트·산책·복권 신규 구매는 목록에서 확인창을 거쳐 바로 실행한다. 주식과 구매한 복권/이력은 상세 화면으로 들어간다. 활동 홈에는 시장을 표시하며 즉시 판매는 보관함에서 진입한다.
- **후속 사용자 확정: 사업은 모두 제거한다.** 신규 구매·보유 UI·주간 수입을 없앤다. 기존 보유 사업은 원가를 현금으로 한 번 환급한다. 이미 받은 수입은 회수하지 않는다.
- 아래 금액·확률·상한·수수료는 개발자가 정한 조정 가능한 초기 밸런스이며 사용자 확정 수치가 아니다.

| 활동       | 행동 | 기본 정책                         |
| ---------- | ---- | --------------------------------- |
| 복권       | 없음 | 장당 5,000원, 주당 1장·자동 번호  |
| 주식       | 없음 | ⚡1마다 시세 갱신, 매도 수수료 1% |
| 아르바이트 | ⚡1  | 20,000원 확정 수령                |
| 산책       | ⚡1  | 조용한 산책 또는 소규모 사건      |

## 주간 흐름

복권·주식 구매 → 자유롭게 거래/활동(⚡마다 시세 갱신) → 정산 진입 → 의무 원금 납부 → 이자 납부 성공 → 복권 추첨·상금 반영 → 기존 상환 장면 → 복권 결과 장면 → 다음 주 플레이.

- 복권 상금으로 이미 실패한 정산을 되살리지는 않는다. 납부 실패 시 추첨·주가 갱신 없이 기존 규칙으로 종료한다.
- 조기 정산에도 같은 순서를 적용한다. 주중 원금 상환 등 실제 ⚡를 쓴 행동은 주가를 진행한다. 정산 납부·화면 진입·앱 종료·새로고침은 주가나 추첨을 진행하지 않는다.
- 각 행동의 시세와 정산의 복권 보상을 먼저 저장하고 연출은 그 결과를 재생한다. 대화·스킵·새로고침으로 추가 지급되지 않는다.
- 엔딩은 기존 규칙대로 우선한다. 최종 상환으로 끝난 회차에서 새 활동을 강제하지 않는다.
- 필수 구매 문의·스토리·정산 도중에는 다른 활동을 실행하지 못한다. 이 규칙과 주당 행동 20회는 기존과 같다.

## 저장·구조

- `src/content/daily.ts`: 종목, 금액, 한도, 산책 내용.
- `src/domain/daily.ts`: 주식 원장·주가, 복권 추첨, 별도 저장 RNG, 결과 검증.
- `src/domain/engine.ts`: 명령 실행, 기존 행동·채무·로그와 연결.
- `src/components/DailyViews.tsx`: 일상 목록과 복권·주식 상세 화면. 공통 Button·뒤로가기·상단 상태를 사용한다.
- `src/components/DailyStage.tsx`: 고정 구도의 도트 무대. 기존 스토리 대화/스킵 UI를 사용한다.
- `Game.daily`는 선택 필드다. 구버전 저장은 물품·주차를 보존하고 기존 사업 원가만 한 번 현금으로 반환하며 최초 이용 시 현재 주차부터 시작한다. 과거 주가·당첨금을 소급 생성하지 않는다.
- 세션의 예전 사업 탭 복귀 기록은 일상 탭으로 옮긴다. 일반 새로고침 자동 복귀와 저장 슬롯은 유지한다.

## 기존 사업 저장 이전

- `src/content/businesses.ts`의 이전 가격표는 구버전 검증·원가 환급에만 사용한다. 다시 구매할 수 있는 실행 경로는 없다.
- 보유 목록을 비운 뒤 환급하므로 같은 슬롯을 재접속·백업 복원해도 같은 저장 안에서 중복 환급하지 않는다. 환급은 투자금 반환으로 처리하고 수입 경험치/통계를 올리지 않는다.
- 이미 지급된 수입·거래 내역·물품·주식·채무·주차·난수는 보존한다. 환급으로 끝난 회차를 부활시키지는 않는다.
- 현금 상한 때문에 한 번에 받을 수 없는 잔액은 `businessRefund`에 보존하고 이후 저장 정규화 시 현금 여유만큼 반환한다. 기존 상환 장면이 열려 있으면 영수증 현금도 맞춰 저장 유효성을 유지한다.
- 이전 사업 수입 관련 스토리 장면은 예전 저장·개발 미리보기 호환을 위해 읽을 수 있지만 새 정산에서는 선택되지 않는다.

## 후속 UI 확정

4분할 카드를 세로 목록으로 바꾼다. 아르바이트·산책은 중간 상세 화면을 없앤다. 복권 신규 구매와 실제 주식 주문에도 확인창을 적용하며 취소하면 명령을 보내지 않는다. 실행 결과 안내는 기존 토스트를 유지한다. 주식의 회사 명칭은 테마 명칭으로 대체하고 복권은 자동 6/45 번호 대조·보너스 추첨으로 개편한다. 상세 수치는 각 문서에 따른다.

## 확인창 표현 확정

사용자 후속 요청으로 일상 실행 확인은 **게임 안의 공통 디자인 모달**로 표시한다. 브라우저 alert/confirm 팝업을 사용하지 않는다. 제목·금액/번개·취소·실행(구매/매수/매도)을 표시하며, 취소·Escape는 명령을 실행하지 않는다. 배경 조작과 스크롤을 막고 닫으면 원래 버튼으로 포커스를 복원한다. 주식 상세 화면에서 Escape는 확인 모달만 닫는다. 결과 안내 토스트는 유지한다.

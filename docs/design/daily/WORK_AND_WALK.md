# 아르바이트와 산책

## 확정 요구

- 아르바이트: 행동 1회로 정해진 현금을 얻는다. 사용자 예시는 2만 원이다.
- 산책: 시간을 보내며 특수한 사건이 일어날 수 있다.

## 구현 초기안 — 밸런스 조정 가능

### 아르바이트

- 일상 목록 → 아르바이트 확인창 → 바로 실행. 별도 상세 화면을 열지 않는다.
- ⚡1, 20,000원 확정 수령. 행동과 필수 응답 조건이 허용하면 연속 실행할 수 있다.
- 예전 무료나눔·수집·3종 아르바이트 구조를 복구하지 않는다. 새로운 단일 명령 `dailyWork`로 실행한다. 구형 `job`·`scavenge` 명령은 계속 거절한다.
- 현금 상한에서는 남은 한도만 수령한다. 금액·행동 진행·로그·저장은 하나의 원자적 명령으로 처리한다.

### 산책

- 일상 목록 → 산책 확인창 → 바로 실행. 별도 상세 화면을 열지 않는다. ⚡1, 별도 비용 없음.
- 다음 결과를 추첨하고 결과와 보상을 먼저 저장한다.

| 결과          | 확률 | 효과                               |
| ------------- | ---- | ---------------------------------- |
| 조용한 골목   | 68%  | 사건 없이 산책을 마침              |
| 떨어진 지갑   | 5%   | 주인에게 돌려준 뒤 사례금 10,000원 |
| 무거운 짐     | 7%   | 이웃을 도와 사례금 5,000원         |
| 소나기        | 10%  | 비를 피하는 짧은 장면              |
| 골목의 고양이 | 10%  | 고양이를 만나는 짧은 장면          |

- 조용한 산책은 행동 연출과 결과 토스트로 끝나며 나머지는 고정 구도의 도트 무대·자연스러운 대사로 표시한다. 대사 진행에 추가 행동은 없다.
- 산책 결과는 토스트 또는 해당 사건 장면으로 보여준다. 보상이나 시세 변경을 예고하는 공략 설명을 메뉴에 추가하지 않는다.
- 무료 매물·임의 아이템·수집 기능을 산책 보상으로 재도입하지 않는다. 체력·피로·포만감 시스템도 부활시키지 않는다.

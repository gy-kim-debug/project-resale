# 테마 주식

## 확정 요구

코인 또는 주식 중 한 가지를 탭에서 매매하며, 매주 시세를 갱신하고 그래프를 제공한다.

## 구현 초기안 — 밸런스 조정 가능

주식을 선택한다. 사용자 후속 요청에 따라 회사 이름 대신 반도체·바이오·2차전지 테마로 표시한다. 테마마다 변동 폭이 다르다.

| 종목     | 분야   | 시작 주가 | 주간 등락 범위 |
| -------- | ------ | --------- | -------------- |
| 동네유통 | 유통   | 20,000원  | -8%~+8%        |
| 새봄테크 | 전자   | 50,000원  | -16%~+16%      |
| 2차전지  | 테마주 | 100,000원 | -28%~+28%      |

- 범위 안 정수 퍼센트를 균등 추첨한다. 이 범위는 수익 보장이 아니다. 상승·하락·보합이 모두 가능하다.
- 기존 거래 엔진과 다른 저장 RNG를 사용한다. 주간 이자 납부 성공 시에만 종목당 한 번 갱신한다. 한 주 동안 모든 매수·매도에 같은 가격을 사용한다.
- 주가는 공통 원화 반올림 함수로 100원 단위 계산하며 하한 100원·상한 10억 원이다. 배당·공매도·레버리지·추가 뉴스 시스템은 도입하지 않는다.
- 종목당 최대 10,000주. 수량은 1·5·10·최대 중 가능한 후보만 선택한다. 직접 숫자를 입력하지 않는다.
- 매수에는 수수료가 없고 매도에는 1% 수수료를 뗀다. 공통 반올림을 적용하며 최소 100원, 매도 총액을 넘지 않는다. 같은 주 매수·매도 반복은 이익이 되지 않는다.
- 행동 소모는 없다. 잔액 부족·초과 매도·잘못된 종목·소수/음수/비정상 수량은 원장·난수·행동 변경 없이 거절한다.
- 매입 금액, 평가 금액, 평가 손익을 표시한다. 평가 손익은 현재 주가 기준이며 예상 매도 수수료는 주문에서 별도 표시한다. 일부 매도 시 남은 수량 비율로 원가를 배분하고 마지막 전량 매도 시 원가를 0으로 한다.
- 그래프는 최근 24주의 저장 가격을 사용한다. 주별 가격 목록에서 과거 주를 선택할 수 있다. 최초 1주만 있어도 점과 현재가를 표시한다.
- 보유 주식은 현금이 아니다. 정산 전에 매도해야 채무에 사용할 수 있으며 자동 매도나 담보 상환은 없다. 정산 실패 시 기존 게임 종료 규칙을 따른다.
- 구버전 슬롯은 처음 이용한 주부터 시작 주가를 부여하고 가짜 과거 수익·보유 주식은 만들지 않는다.

## 이름 변경과 주문 확인

- 기존 내부 식별자 local·tech·motion은 각각 반도체·바이오·2차전지로 표시만 바꾼다. 기존 보유 수량·매입 원가·현재가·가격 이력은 그대로 연결한다. 이름 변경으로 새 자산을 만들거나 가치를 재계산하지 않는다.
- 종목·수량·매수/매도를 선택해야 하므로 주식 상세 화면은 유지한다. 실제 매수·매도 버튼을 누르면 테마·수량·결제/수령 금액을 확인창에서 확인한다. 취소는 현금·원가·수량·행동·난수를 바꾸지 않는다.

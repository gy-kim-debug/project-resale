# 테마 주식 — 행동마다 시세 갱신

## 확정 요구

- 반도체·바이오·2차전지 테마를 매매하고 그래프로 시세 흐름을 확인한다.
- 사용자 후속 선택에 따라 **실제로 ⚡1을 쓸 때마다 시세를 1회 갱신**한다.
- 매수·매도·화면 이동은 시세를 움직이지 않는다. 앱을 닫거나 읽는 동안에도 멈춘다.
- 갱신이 잦아지는 만큼 한 번의 등락 폭을 줄이고 그래프는 주차 대신 최근 시세를 표시한다.

## 구현 초기안 — 밸런스 조정 가능

| 테마    | 시작 주가 | ⚡1당 등락 범위 |
| ------- | --------- | --------------- |
| 반도체  | 20,000원  | -1%~+1%         |
| 바이오  | 50,000원  | -2%~+2%         |
| 2차전지 | 100,000원 | -4%~+4%         |

- 기존 주간 ±8%/±16%/±28%를 작은 행동 단위 폭으로 대체했다. 각 범위 안 정수 퍼센트를 균등 추첨한다. 상승·하락·보합이 가능하며 수익을 보장하지 않는다.
- 행동 예산을 차감하는 공통 `advance`에서 실제 소모량만큼 갱신한다. ⚡2인 거래라면 시세도 두 칸 진행한다. 마지막 남은 ⚡1도 동일하다.
- 물건 매입·판매·등록·탐색·대기·아르바이트·산책·주중 원금 상환 등 실제 행동 소모가 대상이다. 감정·수리·흥정·복권/주식 구매·조회·확인 취소·대화 진행은 대상이 아니다. 이벤트 선택도 실제 행동을 쓴 경우에만 대상이다.
- 조기 정산 때 버리는 남은 행동은 실제 수행한 행동이 아니므로 시세를 갱신하지 않는다. 정산 시작·납부·다음 주 이동에서도 추가 갱신하지 않는다. 복권의 주간 추첨은 기존대로 유지한다.
- 주가용 난수 상태 `stockSeed`를 별도로 저장한다. 주가 갱신은 중고거래의 RNG와 복권·산책 RNG를 소비하지 않는다. 거절된 명령은 시세·난수·행동·재무를 원본 그대로 유지한다.
- 주가는 공통 원화 함수로 100원 단위 반올림하며 하한 100원·상한 10억 원이다. 반올림/상하한으로 같은 가격이 이어질 수 있고, 표시되는 실제 등락률은 원래 추첨한 퍼센트와 조금 다를 수 있다. 공매도·배당·레버리지·실시간 외부 시세는 도입하지 않는다.

## 매매와 그래프

- 종목당 최대 10,000주. 1·5·10·최대 중 가능한 수량을 선택한다. 직접 입력하지 않는다.
- 매수 수수료 없음, 매도 수수료 1%. 공통 반올림을 적용하며 최소 100원, 매도 총액을 넘지 않는다. 실제 주문 전에 게임 내부 확인 모달을 사용한다.
- 현재 시세로만 매매한다. 같은 시세에서 반복 매매하면 수수료만 나가며 시세 갱신을 강제할 수 없다.
- 매입 금액·평가 금액·평가 손익을 비교한다. 일부 매도 시 남은 수량 비율로 원가를 배분하고 전량 매도 시 원가를 0으로 한다. 평가 손익은 수수료 전이며 매도 수수료는 주문에 별도 표시한다.
- 그래프는 **최근 24개 시세**를 표시하고 ‘시세 N’, ‘직전 시세 대비’, ‘시세 기록 보기’로 표현한다. 기록 선택으로 과거 가격을 확인할 수 있다. 그래프 진입·기록 선택은 시세를 바꾸지 않는다.
- 보유 주식은 현금이 아니다. 정산 전에 팔아야 채무에 사용할 수 있으며 자동 매도나 담보 상환은 없다.

## 저장 이전

- 기존 local·tech·motion 식별자는 그대로 반도체·바이오·2차전지에 연결한다. 보유 수량·원가·현금·이전 실제 가격·주차를 바꾸지 않는다.
- 구버전 주간 기록에는 순서 식별자인 `tick=week-1`만 붙이고 마지막 기록 뒤에서 새 행동 시세를 이어간다. 과거 행동을 소급 추첨하거나 가짜 시세를 보간하지 않는다. 기록의 원래 주차도 보존한다.
- `stockTick`은 저장된 시세 순서다. 구버전 기록을 이어받을 수 있으므로 회차의 총 행동 수를 의미하지 않는다. 같은 주차의 여러 시세는 서로 다른 tick으로 식별한다.
- 이전 시세 상태와 새로운 상태를 모두 읽되, 빠진/혼합된 난수·순서 필드와 중복·미래·불연속 tick은 가져오기에서 거절한다. 이전은 멱등적이며 새로고침은 가격이나 난수를 진행하지 않는다.

## 시세 기간 표기 후속 변경

`시세 1·2` 같은 누적 순번을 화면에서 제거한다. 최신 기록은 `현재`, 바로 이전 기록은 `직전`, 그 이전은 `2회 전`처럼 최신 갱신 대비 상대 순서로 표시한다. 선택된 기록·기록 목록에는 실제 저장된 주차를 함께 표시한다. 그래프 축도 과거 상대 순서/현재를 사용하며 기록 하나일 때 현재 라벨만 표시한다. 테마 요약에는 현재 주차만 표시한다. 상대 횟수는 시세 갱신 횟수이며 실제 날짜·분·시간을 새로 만들지 않는다. 기존 주간 기록 이전 데이터에도 같은 방식이 적용된다. 가격·갱신 주기·저장 구조는 변경하지 않는다.

# 주간 복권 — 자동 번호와 추첨

## 확정 요구

- 복권은 **한 주에 1장만** 구매한다.
- 로또를 사는 듯한 추첨 이벤트로 보여준다.
- 단순 구매는 일상 목록에서 누르고 확인창에 수락하면 실행한다. 번호나 금액을 직접 입력하지 않는다.
- 해당 주 정산을 성공적으로 마친 뒤 결과를 확인한다.

## 이번 구현의 초기 정책

- 기존 장당 가격 5,000원을 유지한다. 구매에는 현금만 사용하고 행동은 쓰지 않는다.
- 1~45 중 중복 없는 번호 6개를 자동으로 발급해 즉시 저장한다. 다시 누르면 구매 대신 내 복권을 보여준다. 번호 재발급·환불·추가 구매는 없다.
- 추첨은 1~45에서 중복 없이 7개를 뽑아 앞의 6개를 당첨 번호, 마지막 1개를 보너스로 정한다. 기존처럼 등수를 먼저 확률로 고르지 않고 **실제 번호 일치 수**로 판정한다.
- 앞서 개발자가 정한 1~4등 상금은 유지하고, 3개 일치의 5등을 추가했다. 상금은 게임용 초기 밸런스로 사용자 확정 수치가 아니며 실제 로또의 가격·상금 구조를 재현하지 않는다.

| 등수 | 판정                        | 초기 상금   |
| ---- | --------------------------- | ----------- |
| 1등  | 당첨 번호 6개 일치          | 1,000,000원 |
| 2등  | 당첨 번호 5개 + 보너스 일치 | 200,000원   |
| 3등  | 당첨 번호 5개 일치          | 50,000원    |
| 4등  | 당첨 번호 4개 일치          | 10,000원    |
| 5등  | 당첨 번호 3개 일치          | 5,000원     |
| 낙첨 | 2개 이하 일치               | 0원         |

## 구매·연출

1. 일상 목록의 복권을 누른다.
2. 확인창에 1장·금액·자동 번호를 표시한다. 취소하면 명령·지출·난수 추첨이 없다.
3. 구매 후 같은 목록을 누르면 내 번호를 확인한다. 지난 추첨은 별도 링크로 접근한다.
4. 정산을 성공적으로 납부하면 당첨 번호·보너스·등수·수령액을 먼저 저장한다.
5. 기존 상환 장면 뒤 16개 장면이 이어진다: 방에서 방송 기다리기 → 복권 클로즈업 → 방송 시작 → 공 혼합 → 번호 6개 순차 공개 → 보너스 대기 → 보너스 공개 → 번호 대조 → 등수별 결과 → 실제 수령액 확인 → 일상 복귀. 다음으로 진행하고 스킵으로 마지막 결과에 도달한다.
6. 내 번호와 공개된 당첨 번호를 함께 표시하고 기본 번호 일치 개수·보너스 일치를 강조한다. 번호별 반응과 1~5등·낙첨 대사를 분기하며, 당첨 결과에는 축하 색종이를 표시한다. 마지막에는 등수와 당첨금을 유지한다. 스킵으로 결과까지 이동할 수도 있다.

- 무대는 고정 크기이며 대사·공 개수가 바뀌어도 캐릭터가 이동하지 않는다. 동작 줄이기에서는 회전·등장 애니메이션을 멈춘다.
- 공개 도중 새로고침하면 저장된 번호와 대사 순서를 그대로 복원한다. 연출에서 추첨·보상을 다시 실행하지 않는다.
- 미납이면 기존 규칙대로 종료하고 복권으로 실패한 정산을 구제하지 않는다. 최종 엔딩도 기존 우선순위를 따른다.
- 최근 12주의 내 번호·당첨 번호·보너스·결과를 저장한다. 현금 상한에서는 실제 받은 금액만 기록한다.

## 구버전 호환

- 이전 규칙으로 이미 산 1~5장의 번호 없는 복권은 없애거나 다시 청구하지 않는다. 해당 주만 이전 확률과 결과 화면으로 한 번 정산하고 이후 신규 구매는 1장·번호 방식으로 제한한다.
- 과거 결과와 이미 열려 있는 이전 추첨 장면도 읽을 수 있다. 이전 복권을 소급해서 새 번호·등수로 재추첨하지 않는다.
- 신규 번호/보너스 중복·범위 오류·실제 번호와 불일치한 등수는 저장 가져오기에서 거절한다.

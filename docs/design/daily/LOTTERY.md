# 주간 복권

## 확정 요구

복권을 구매한 주의 정산 후 추첨 결과를 이벤트로 보여준다. 등수를 확인할 수 있어야 한다.

## 구현 초기안 — 밸런스 조정 가능

- 1장 5,000원, 한 주 최대 5장. 1·3·5장 중 남은 한도에 맞는 수량을 선택한다. 반복 구매도 합계 한도를 넘지 못한다.
- 구매에는 현금만 사용하며 행동을 쓰지 않는다. 환불·재추첨·자동 구매는 없다.
- 각 장은 독립 추첨한다. 0~9,999 정수 난수의 구간으로 아래 등수를 결정한다.

| 결과 | 확률  | 상금        |
| ---- | ----- | ----------- |
| 1등  | 0.01% | 1,000,000원 |
| 2등  | 0.09% | 200,000원   |
| 3등  | 0.9%  | 50,000원    |
| 4등  | 9%    | 10,000원    |
| 낙첨 | 90%   | 0원         |

- 한 장의 기대 상금은 1,630원이다. 구입 비용보다 작으며 고정 수입 수단으로 설계하지 않는다.
- 해당 주 의무 원금과 이자를 성공적으로 납부한 후에만 추첨한다. `quoteWeek` 가드로 같은 주를 두 번 처리하지 않는다.
- 결과에는 구입한 모든 장의 등수와 총 수령액을 저장한다. 기존 상환 대화 뒤 도트 무대와 대화로 보여준다. 마지막 대사에서 돌아가기를 선택한다.
- 지난 추첨은 최근 12주를 확인할 수 있다. 구매하지 않은 주는 결과 이벤트를 만들지 않는다.
- 현금 상한까지의 금액만 실제 지급하고 그 수령액을 기록한다. 결과 화면은 지급 명령을 재실행하지 않는다.
- 주당 5장 제한과 별도 RNG는 회차·슬롯마다 저장된다. 화면 열기나 새로고침은 난수를 소비하지 않는다.

# 피로도 0으로 다음 날 아침이 되었을 때의 회복

**확정: 피로도만 가득 회복하고 체력은 그대로 유지한다.**

- 피로도가 0이 되면 해당 날짜가 종료되고 다음 날 아침이 된다.
- 다음 날 아침에는 피로도를 최대치까지 회복한다. 최대치의 구체적인 값은 미정이다.
- 이 회복으로 체력이 증가하거나 감소하지 않는다.
- 수면 중 포만감은 일정량 감소한다([수면 중 포만감 감소](SATIETY_LOSS.md)). 다른 사건의 효과와 처리 순서는 아직 정하지 않았다.

선택 근거: 사용자가 다음 날 아침의 회복 방식 후보 1번 ‘피로도만 가득 회복 — 체력은 그대로’를 선택했다.

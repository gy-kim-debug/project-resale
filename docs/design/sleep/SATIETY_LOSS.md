# 수면 중 포만감 감소

**확정: 수면 중에는 포만감이 일정량 감소한다.**

- 수면의 포만감 감소는 정해진 양을 적용한다.
- 구체적인 감소량은 아직 정하지 않았다.
- 포만감이 감소량보다 적을 때의 처리와 다른 효과의 적용 순서는 아직 정하지 않았다.

선택 근거: 사용자가 ‘수면 중에는 일정량 포만감 감소’라고 직접 지정했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

수면 한 번당 포만감 18 감소, 최저 0. 수면 중 추가 체력 손실은 없다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

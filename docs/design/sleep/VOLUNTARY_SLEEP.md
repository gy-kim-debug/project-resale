# 직접 수면 선택

**확정: 피로도가 남아 있어도 직접 수면을 선택할 수 있다.**

- 플레이어가 원할 때 수면을 선택해 해당 날짜를 마친다.
- 수면 후 다음 날 아침으로 이동한다.
- 피로도 0에서의 자동 수면은 유지한다.
- 수면 비용은 항상 무료다([수면 비용](COST.md)). 아침 기준 시각과 수면 장소 등은 아직 정하지 않았다.

선택 근거: 사용자가 수면 선택 방식 후보 2번 ‘직접 수면 가능 — 원할 때 하루를 마치고 다음 날 아침으로 이동’을 선택했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

피로도 0이 아니어도 무료로 잠들 수 있다. 포만감 0에서도 가능. 새벽 수면도 날짜 기준 다음 날 09:00로 간다. 문의가 있으면 먼저 응답한다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

# 피로도 소모 방식

**확정: 게임 시간에 따른 기본 소모와 힘든 행동의 추가 소모를 함께 적용한다.**

- 게임 시간이 흐른 만큼 피로도가 기본적으로 줄어든다.
- 힘든 행동을 하면 시간에 따른 기본 소모 외에 피로도가 추가로 줄어든다.
- 기본 소모율, 추가 소모 대상 행동과 소모량은 아직 정하지 않았다.
- 수면은 [피로도 0으로 다음 날 아침이 되었을 때의 회복](../sleep/NEXT_MORNING_RECOVERY.md)의 회복 규칙을 따르며, 수면 외 회복 행동 중 기본 소모와 회복을 적용하는 방식은 아직 정하지 않았다.

선택 근거: 사용자가 피로도 소모 방식 후보 3번 ‘혼합형’을 선택했다.

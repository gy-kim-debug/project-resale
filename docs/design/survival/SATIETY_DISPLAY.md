# 포만감 수치의 표시 방향

**확정: 포만도 방식으로 표시한다.**

- 수치가 높을수록 배부른 상태다.
- 포만감을 소모하는 행동을 하면 수치가 줄어든다.
- 수치가 부족하면 포만감을 소모하는 행동이 제한된다.

선택 근거: 사용자가 배고픔 수치 표시 방향 후보 1번 ‘포만도 방식’을 선택했다.

지표 이름은 사용자가 지정한 ‘포만감’을 사용한다. 수치 범위, 초기값, 활동별 소모량과 무료 급식 외 구체적인 회복 수단·수치는 아직 정하지 않았다. 소모 방식은 [포만감 소모](SATIETY_CONSUMPTION.md), 무료 급식 효과는 [무료 급식](../food/FREE_MEALS.md)을 따른다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

상단 포만감은 아이콘·숫자·게이지를 함께 표시한다. 100이 가득 찬 상태다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

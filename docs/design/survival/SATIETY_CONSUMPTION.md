# 포만감 소모

포만감은 생존과 행동 가능 여부를 제한하며 물품 실제 가치나 거래 확률을 보정하지 않는다. 0이면 포만감 소모 행동을 할 수 없다. 식사·치료·수면·무료 이동/대화는 가능하다.

## 하루 3행동 적용 정책

일반 행동 1회당 기본 12와 작업별 추가 소모를 합산한다. 하루 종료 시 추가 18 감소. 일반 행동 중 바닥나면 체력 8 감소하며 회복 행동·문의 응답은 이 체력 손실을 적용하지 않는다. 실제 경과 시간·오프라인 대기에는 비례 소모하지 않는다. 식사는 기본 소모 후 회복을 적용하고 하루 종료가 있다면 그 뒤 포만감을 차감한다.

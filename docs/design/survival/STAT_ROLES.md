# 체력과 피로도

## 사용자 확정

포만감과 식사 개념을 삭제한다. 배고픔·급식·음식 섭취·굶주림 피해·포만감에 따른 행동 제한을 사용하지 않는다.

- 체력은 생명력이며 0이면 사망해 게임이 끝난다.
- 피로도는 행동으로 감소하는 활동 여유다. 0이면 행동 완료 후 다음 날로 넘어간다.
- 두 수치 모두 물품 실제 가치·거래 확률을 직접 보정하지 않는다.

## 현재 구현 정책

범위 0–100, 초기값 100. 피로도는 행동별 기본·추가 비용으로 감소하고 하루 종료 시 100으로 회복한다. 체력은 치료로 회복하며 수면으로 회복하지 않는다. 굶주림 피해를 제거했으므로 현재 행동에는 체력을 깎는 요인이 없다. 대체 체력 피해·사고 규칙은 도입하지 않았으며 후속 설계 대상으로 남긴다.

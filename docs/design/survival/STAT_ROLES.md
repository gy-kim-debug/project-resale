# 체력과 포만감의 역할

**확정: 체력은 생명력, 포만감은 포만감을 소모하는 행동의 가능 여부를 제한하는 지표로 사용한다.**

- 체력: 다치거나 무리하면 감소하며, 0이 되면 사망한다.
- 포만감: 활동 에너지 역할을 맡으며, 포만감을 소모하는 행동의 가능 여부를 제한한다.
- [무료 급식](../food/FREE_MEALS.md)으로 포만감과 체력을 조금 회복할 수 있다. 체력은 [음식과 치료로 회복](HEALTH_RECOVERY.md)할 수 있다. 구체적인 회복 수단·수치·비용은 아직 정하지 않았다. 행동 제한 방식은 [포만감 부족 시 행동 처리](ACTION_RESTRICTIONS.md)를 따른다.

선택 근거: 사용자가 체력은 후보 2번 ‘생명력’, 배고픔은 후보 1번 ‘활동 에너지’ 역할로 지정했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

범위 0–100. 포만감은 높을수록 배부름, 피로도는 행동으로 감소하는 잔여 활동 여유, 체력은 생명이다. 생존 수치를 거래 난수·물품 가치 입력에 넣지 않는다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

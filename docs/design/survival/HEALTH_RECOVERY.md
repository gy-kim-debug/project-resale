# 체력 회복 방법

**확정: 음식과 치료 모두로 체력을 회복할 수 있으며, 회복 효과는 서로 다르다.**

- 음식으로 체력을 회복할 수 있다.
- 치료로 체력을 회복할 수 있다.
- 어떤 음식·치료가 대상인지, 구체적인 회복 효과·비용·소요 시간은 아직 정하지 않았다.
- 무료 급식도 포만감과 체력을 조금 회복한다. 구체적인 수치는 미정이다.

선택 근거: 사용자가 체력 회복 방법 후보 3번 ‘둘 다 가능 — 음식과 치료로 체력을 회복하되 효과가 다름’을 선택했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

급식은 체력 +5, 주먹밥 +2, 한 끼 +12, 치료 +60이다. 최대 100. 수면은 체력을 회복하지 않는다. 사망 상태는 회복 행동을 할 수 없다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

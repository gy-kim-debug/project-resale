# 포만감 부족 시 행동 처리

**확정: 필요한 포만감이 부족하면 포만감을 소모하는 행동만 실행할 수 없다.**

- 포만감을 소모하지 않는 행동은 포만감 부족만을 이유로 막지 않는다. 다른 조건 충족 여부는 별개다.
- 식사 등 포만감을 회복하는 행동은 가능하다.
- 부족한 포만감을 체력 소모로 대신하여 강행하는 방식은 사용하지 않는다.

선택 근거: 사용자가 ‘행동 불가’를 선택한 뒤, 포만감이 소모되는 행동만 제한한다고 구체화했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

포만감 0이면 포만감 소모 행동은 차단한다. 음식·급식·치료·수면·버리기·문의 응답은 가능하다. 상태 부족으로 거부한 행동은 시간·금액·난수도 유지한다.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

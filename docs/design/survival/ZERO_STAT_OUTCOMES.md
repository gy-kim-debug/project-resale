# 지표가 0일 때의 처리

| 지표   | 처리                                                                         | 결정 상태                                                                                                       |
| ------ | ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 포만감 | 포만감을 소모하는 행동 불가. 회복하면 다시 가능하며 식사 등 회복 행동은 가능 | 사용자 확정                                                                                                     |
| 체력   | 사망                                                                         | 사용자 확정                                                                                                     |
| 피로도 | 해당 날짜 종료, 다음 날 아침으로 이동                                        | 사용자 확정, 회복 방식은 [피로도 0으로 다음 날 아침이 되었을 때의 회복](../sleep/NEXT_MORNING_RECOVERY.md) 참조 |

**확정: 지표 이름은 ‘피로도’를 유지한다.** ‘기력’으로 변경하지 않는다.

다음 날 아침에는 피로도만 가득 회복하고 체력은 그대로 유지한다([피로도 0으로 다음 날 아침이 되었을 때의 회복](../sleep/NEXT_MORNING_RECOVERY.md)). 아침의 기준 시각, 수면 장소, 채무·판매 대기·이벤트 시간 처리는 아직 정하지 않았다. 수면 비용은 항상 무료다([수면 비용](../sleep/COST.md)). 포만감은 수면 중 일정량 감소한다([수면 중 포만감 감소](../sleep/SATIETY_LOSS.md)). 여러 수치가 동시에 0이 되는 경우의 판정 순서와 행동 보상 지급 시점도 아직 미정이다.

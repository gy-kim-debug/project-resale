# 캐릭터 능력치 도입 계획

**확정: 캐릭터 능력치를 도입할 예정이다.**

사용자는 장터 판매 글 등록 한도 확장을 선택하면서 캐릭터 능력치를 넣을 예정이라고 지정했다. [판매 글 등록 한도](../trading/marketplace/LISTING_LIMITS.md)와 관련된 확장 구조를 후속 논의한다.

최초 도입 논의 시 능력치 목록·초기값·상승 방법·효과, 경험치나 레벨의 존재 여부는 미정이었다. 이후 결정은 아래에 기록한다. 캐릭터 능력치를 도입한다는 사실만으로 직업·회차·계승·영구 성장 시스템을 추가하지 않는다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

거래 감각: 판매 5회마다 +1, 동시 판매 글 기본 3개에서 레벨당 +1(최대 8개). 감정 지식: 가치 확인 4회마다 +1, 확인비 레벨당 5% 절감. 수리 기술: 시도 4회마다 +1, 성공률 70%에서 레벨당 5%p 증가(최대 95%). 모두 Lv.0 시작·최대 10, 회차 계승 없음.

[전체 수치·판정·예외 정책](../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

## 이번 확장 — 자동 성장

사용자가 **거래·감정·수리 등 행동에 따라 자동 성장**하는 방식을 선택했다. 포인트 배분과 회차 계승은 추가하지 않는다. 능력치 종류와 세부 수치는 아래 개발자 초기 조정안을 적용한다.

- 기존 거래 감각·감정 지식·수리 기술과 누적 경험은 유지한다.
- **매입 감각** 추가: 물품 구매/수령 5회마다 Lv.+1, 최대 10. 레벨당 판매자의 최소 수락 가격 범위에서 게시가의 1%p를 낮추는 여지를 준다. 실제 가격고정 판매자는 할인하지 않는다. 최소 가격은 100원이다.
- 실제 가치·희귀도·진품 확률·수리 전 상태는 능력치로 변경하지 않는다. 사업 구매는 물품 구매 경험에 포함하지 않는다.
- 새 협상 시작에 현재 능력치를 적용하고 이미 저장된 최소 수락가/인내심은 재설정하지 않는다.
- 내 정보에 4개 능력치·레벨·경험·효과를 표시한다. 상승 시 기록/우편으로 알리고 별도 배분 화면이나 강제 팝업은 만들지 않는다.

성장 간격·최대 레벨·효과 수치는 개발자 초기 조정안이다.

## 후속 사용자 결정 — 시장별 전문 수리 능력치

사용자는 전문 능력치의 구분을 품목 분야 대신 **시장별**로 지정했다. 시장마다 취급하는 물건과 특징이 다르므로, 수리 성공 확률은 물건의 수리 난이도와 해당 시장의 전문 수리 능력치를 반영한다.

- 시장 구분은 기존 중고 장터·전자상가·악기시장·중고차시장·부동산 시장·고가 경매시장을 따른다. 컴퓨터/가전 등 별도 품목별 능력치 목록을 확정한 것은 아니다.
- 같은 시장에서도 물건별 고장과 수리 난이도가 다르므로 성공 확률이 모두 같지는 않다.
- 모든 물건에 동일한 기본 성공률과 단일 수리 레벨 보너스를 적용하는 기존 v1 수리 정책은 현재 구현 설명으로 남긴다. 신규 설계에서는 시장별 능력치를 반영하도록 변경할 예정이다.
- 성장 수치는 아래 표를 따른다. 기본 성공률은 쉬움 80%·보통 60%·어려움 30%, 레벨당 +2%p, 최종 상한 95%다. 별도 하한 보정은 추가하지 않는다.
- **무료나눔·수집품은 중고 장터**, 일반 물품은 최초 생성 시장 귀속이다. 부동산 보수·경매품 복원은 같은 계산 규칙을 사용한다.
- **경험치 획득 행동은 해당 시장 물건의 구매·판매·가치 확인·수리**다. 행동에 따라 자동 성장한다는 기존 방향을 유지한다.
- 수리 실패 시 **성공했을 때의 절반 경험치**를 지급한다. 수리 성공 4, 실패 2로 정해 소수점 경험치는 발생하지 않는다.
- 시장별 능력치의 효과는 **수리 성공률 상승에만 적용**한다. 수리비·감정·흥정·물건의 회복 한계에는 이 능력치 보너스를 적용하지 않는다. 기존 공통 수리 기술만 교체하고 거래 감각·감정 지식·매입 감각은 유지한다. 과거 공통 수리 경험은 통계에 보존하며 새 시장 능력에 분배하지 않는다.
- 무료나눔 수령·물건 수집 자체와 즉시 판매에는 시장 경험치를 지급하지 않는다. 일반·경매 판매는 거래 완료 시 지급한다.
- 수리로 도달할 수 있는 최고 등급 A, 실패 후 재시도 불가 등 확정된 상태 등급 규칙은 유지한다.
- 구현 정책과 저장 호환은 아래 연결 문서를 따른다.

[상태 등급·수리·폐기 규칙과 미확정 항목](../items/CONDITION_GRADES_PROPOSAL.md)을 함께 참고한다.

## 시장별 성장 수치 — 사용자 확정

사용자는 추천 조합 A1 / B2 / C2 / D1을 선택했다.

| 행동      | 해당 시장 경험치 |
| --------- | ---------------- |
| 구매      | 2                |
| 판매      | 2                |
| 가치 확인 | 2                |
| 수리 성공 | 4                |
| 수리 실패 | 2                |

- 다음 레벨까지 필요한 경험치는 첫 레벨업 20부터 30, 40, 50…으로 10씩 증가한다. 최대 레벨은 **10**이다. 시작 레벨은 기존 Lv.0을 기준으로 정리한다.
- Lv.0에서 Lv.1까지 20, Lv.1에서 Lv.2까지 추가 30이 필요하다. 누적 기준 Lv.2는 50, Lv.10은 650이다. 요구량은 누적 경험치와 구분한다.
- 시장별 능력치는 **레벨당 수리 성공률 +2%p**, 최대 레벨에서 +20%p를 준다.
- 최종 성공률은 물건별 기본 성공률에 해당 시장의 레벨 보너스를 더하되 **95%를 상한**으로 한다. 기본 성공률은 쉬움 80%·보통 60%·어려움 30%다. 수리 난이도는 상태 등급과 별도로 고장·손상 종류에 따라 정한다. 난이도는 생성 시 무작위 지정하며 상태 등급과 독립이다.
- 예: 기본 성공률 60%, 해당 시장 Lv.5이면 최종 성공률 70%. 기본 80%, Lv.10이면 상한에 따라 95%다.
- 실제 구매·판매·확인·수리 완료 시에만 지급한다. 과거 경험을 소급 지급하지 않고 시장 경험은 0부터 시작한다. 최대 레벨에서는 경험치를 누적 650으로 제한하고 최대 레벨로 표시한다.
- 이름: 생활 수리·전자 수리·악기 정비·차량 정비·부동산 보수·경매품 복원. 부동산은 보수, 경매품은 복원 동작으로 표시한다.

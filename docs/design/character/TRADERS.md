# 거래 상대 프로필

## 사용자 요청

- 판매자와 구매자에게 아이디·나이·성별 등 간단한 프로필과 거래 성향을 부여한다.
- 매물에서 판매자 정보를 확인하고, 구매 문의에서 구매자 정보를 확인한다.
- 성향은 표시만 하지 않고 실제 흥정에 영향을 준다.

## 첫 구현 기본안 — 조정 가능

- 오프라인 가상 인물은 18개 기본 프로필을 바탕으로 생성한다. 신규 인물은 조합형 랜덤 닉네임과 고유 ID를 갖고, 기존 고정 인물 ID도 계속 지원한다. 같은 인물 ID는 어느 시장에서도 동일한 프로필을 갖는다. 계정·실제 사용자·인증 기능이 아니다.
- 프로필은 별명, @아이디, 나이, 성별, 거래 성향 한 가지로 구성한다. 성별·나이는 거래 확률이나 물건 가치와 무관하다.
- 일반: 기존 시장별 흥정 규칙 유지. 가격 고정: 판매자는 할인 제안을 받지 않으며 구매자는 첫 제안 금액을 올리지 않는다. 큰 폭 흥정: 판매자는 가격을 잘 유지하고 구매자는 낮은 금액으로 시작한다. 쿨거래: 판매자는 짧고 큰 폭으로 조율하며 구매자는 예산 안에서 등록가를 우선한다. 유연한 흥정: 판매자는 양보폭/기회를 늘리고 구매자는 등록가에 가까운 제안으로 시작한다. 신중한 거래: 판매자는 더 오래 조율하며 구매자는 잘 파토내지 않는다.
- 기존 시장별 공략과 캐릭터 성장 위에 적용한다. 판매자의 네고 불가/급처/네고 환영 사실과 어울리는 인물을 배정한다. 태그의 사실 확률은 변경하지 않는다. 폐업 정리 전환 시에도 급처 인물을 배정한다.
- 신규 매물/문의에 traderId를 저장한다. 해시 선택으로 프로필 배정 자체는 기존 물건 생성 난수나 가치를 변경하지 않는다. 매각/재접속 후에도 ID 유지.
- 기존 저장에 ID가 없으면 기존 이름·흥정 로직을 보존하고, 안정적인 가상 기본 프로필을 표시한다. 진행 중 협상의 최저가·인내심을 재추첨하지 않는다.
- 구매 흥정 0행동, 구매 확정 1행동. 판매 흥정 0행동, 판매 확정 1행동. 파토 후 판매 글 유지. 경매는 출품자 정보를 표시하되 입찰 규칙 유지.

## 추후 논의

인물 관계/단골 성장, 프로필 사진, 후기·신뢰도, 더 많은 성향, 인물별 대사 확장, 출현 가중치는 아직 확정하지 않았다.

## 랜덤 닉네임 — 사용자 요청

- 신규 판매자·구매자·출품자에게 수식어 40개·명사 40개·장소 12개·두 자리 숫자를 조합한 닉네임을 생성한다. 수식어+명사, 명사+숫자, 수식어+명사+숫자, 명사+의+장소 형태를 섞는다. 같은 닉네임이 우연히 겹칠 수 있지만 거래 상대 ID는 별개다.
- 닉네임 난수는 거래/경제 난수와 분리한다. 성향별 배정 비율·나이·성별·흥정 수치를 변경하지 않는다.
- 생성 ID에 이름 시드를 포함하고 판매자 이름/구매자 이름을 저장한다. 목록·프로필·채팅에서 같은 이름을 표시하고 재접속·백업·흥정 시 재추첨하지 않는다. 저장된 표시 이름을 우선해 향후 단어 목록 수정에도 기존 이름을 유지한다.
- 기존 매물/문의/보유품의 고정 닉네임은 바꾸지 않는다. 새로 등장하는 상대부터 적용한다.

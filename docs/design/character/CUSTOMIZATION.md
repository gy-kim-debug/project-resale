# 새 게임 캐릭터 설정

## 사용자 요청

새로 시작할 때 캐릭터 모습과 닉네임을 설정할 수 있다. 선택한 캐릭터를 내 정보에 표시하고 기존 행동 도트 연출에도 같은 모습으로 사용한다.

## 초기 구현 정책

- 닉네임: 1~12자. 문자·숫자·공백·`_ . -` 허용. 앞뒤 공백을 제거하고 NFKC로 정규화한다. 빈 이름·제어 문자·태그 문자열·범위를 벗어난 이름은 거부한다.
- 헤어: 짧은 머리, 긴 머리, 모자.
- 옷 색상: 민트, 블루, 앰버, 로즈.
- 피부색: 밝은 톤, 중간 톤, 짙은 톤.
- 선택 즉시 동일한 도트 컴포넌트로 미리보기를 제공한다. 게임을 생성하기 전에 바꿀 수 있다.

이 선택은 외형과 표시 이름에만 적용한다. 외형·닉네임은 경제 RNG, 거래 성향, 능력치, 가치, 확률, 자금에 영향을 주지 않는다. 캐릭터 이름을 게임 제목이나 회차 번호로 사용하지 않는다. 성별·나이·직업 선택과 외형 변경 상점은 추가하지 않는다.

Game.player의 선택적 필드에 nickname과 appearance(hair/outfit/skin)를 저장한다. 새 프로필이 있는 백업은 검증해 그대로 복원한다. 기존 게임의 필드가 없으면 기본 민트 캐릭터와 플레이어 표시를 사용하며 임의로 이름을 새로 저장하지 않는다. 게임 시작 후 프로필 편집은 이번 범위가 아니다.

팔레트·외형 키는 content/player.ts, 프로필 검증과 이전 게임 표시 정책은 domain/player.ts, 렌더링은 PixelCharacter가 담당한다. 슬롯마다 독립적인 프로필을 사용한다.

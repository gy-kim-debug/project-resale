## 최신 적용 — 도트 캐릭터 시각 개선 (2026-11-11)

공통 PixelCharacter의 실제 도트를 다듬었다. 기존 24×32 정수 좌표 SVG·그룹별 애니메이션·여자/남자·헤어 5종·옷 5종·색상 6종·피부 3종을 유지한다. 기존 저장 외형을 그대로 사용하며 게임 계산이나 외형 옵션을 추가하지 않는다.

- 얼굴: 계단형 턱선·귀·코·두 눈과 따뜻한 음영으로 윤곽을 정리한다.
- 머리: 외곽·기본색·부분 하이라이트로 짧은 머리/단발/긴 머리/묶은 머리/모자 실루엣을 구분한다.
- 옷: 좌상단 광원과 외곽 명암을 맞추고 재킷 칼라·티셔츠 주머니·후드 끈/주머니·코트 라펠/단추·원피스 주름을 분리한다.
- 소품: 가방 스트랩·덮개·버클·옆면과 운동화 발등·밑창을 표현한다.
- 팔/다리/몸통 그룹의 기존 클래스와 캔버스 비율을 유지해 거래·수리·스토리 연출에 그대로 사용한다. 상대 캐릭터도 같은 도형을 사용하고 기존 블루/회색 머리 구분을 유지한다.

새 이미지 라이브러리·네트워크 자산·애니메이션 의존성은 추가하지 않는다. 아래는 초기 구현 기록이며 현재 외형 선택은 [캐릭터 설정](CUSTOMIZATION.md)을 따른다.

# 도트 캐릭터와 행동 장면

## 사용자 요청

- 행동 로딩에 캐릭터가 해당 행동을 수행하는 도트 장면을 보여준다.
- 거래 중에는 내 캐릭터와 상대 캐릭터가 만나 거래하는 모습을 표현한다.
- 내 캐릭터는 내 정보에서도 확인할 수 있다.

## 이번 표현

민트색 옷·짙은 바지·작은 가방을 착용한 공통 플레이어 스프라이트를 사용한다. 상대는 모자와 푸른색 옷으로 구분한다. 캐릭터의 이름·성별·직업·능력치를 새로 확정하지 않는다. 외형 선택이나 성장에 따른 의상 변경은 이번 범위가 아니다.

24×32 정수 좌표의 SVG 도트를 공통 PixelCharacter 컴포넌트로 그린다. 내 정보에는 정지 포트레이트와 기존 누적 거래 횟수를 표시하며, 행동 장면에는 같은 스프라이트를 사용한다. 외부 이미지·네트워크·라이브러리 의존성은 추가하지 않는다.

| 행동                                      | 장면                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------- |
| 구매·나눔 수령                            | 플레이어와 판매자가 만나 물건을 전달한다. 돈 표시는 유료 거래에만 사용한다. |
| 판매 성사·즉시 판매                       | 상대에게 물건을 건네고 돈을 받는다.                                         |
| 물건 수집                                 | 상자를 살펴보고 발견 표시가 나타난다.                                       |
| 아르바이트                                | 상자를 옮긴다.                                                              |
| 가치 확인                                 | 작업대에서 확대경으로 살펴본다.                                             |
| 수리                                      | 작업대에서 공구를 움직인다.                                                 |
| 판매 등록·취소                            | 기기를 이용해 게시물을 처리한다.                                            |
| 상환·주간 정산·사업 구매                  | 돈을 정리한다.                                                              |
| 매물 탐색·기다리기·그 밖의 기존 로딩 행동 | 거리를 이동한다.                                                            |

장면 종류는 앱의 ActionPresentation에만 보관하며 게임 저장에는 추가하지 않는다. 엔진 계산, 실행 횟수, 성공/실패 확률, 돈과 행동 비용을 변경하지 않는다. 채팅처럼 원래 즉시 응답하는 명령에는 새 로딩을 만들지 않는다. 기존에 로딩을 표시하는 행동에서만 장면을 사용한다.

기존 750ms 표시 시간을 유지한다. 게임 상태는 기존처럼 한 번 먼저 저장하고 연출을 보여준다. 연출에서 거래나 상태 변화를 재실행하지 않는다. 화면의 물건·돈 아이콘은 전달을 상징하며 추가 보상이나 실제 운반·예약 시스템을 뜻하지 않는다.

`prefers-reduced-motion` 환경에서는 움직임 없이 정지 장면을 표시하고 기존 처리 시간·완료 동작을 유지한다. 도트 SVG는 장식으로 숨기고 기존 로딩 텍스트를 보조 기술에 제공한다.

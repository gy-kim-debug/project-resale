# 최신 변경 — 일상 탭 아르바이트

이 문서의 3종 기능 제거 기록 이후, 사용자 요청으로 **단일 아르바이트**를 일상 탭에 추가했다. 현재 정책은 [일상 활동](../daily/DAILY_ACTIVITIES.md)과 [아르바이트·산책](../daily/WORK_AND_WALK.md)을 따른다. 무료나눔·물건 수집·예전 아르바이트 명령은 계속 폐기 상태다. 추가 사용자 결정으로 사업도 모두 폐기하고 원가 환급만 제공한다. 아래 사업 유지 설명은 이전 기록이다.

# 수입 경로 — 최신 사용자 결정

## 확정: 무료나눔·아르바이트·물건 수집 모두 제거

사용자는 활동 화면의 돈벌기 세 기능을 모두 제거하도록 선택했다. 무료나눔을 중고 장터에 통합하는 대안은 선택하지 않았다.

- 활동 화면의 ‘돈 벌기’ 그룹과 세 진입 메뉴를 제거한다.
- 무료나눔 게시판과 새 0원 매물 생성을 제거한다. 기존 저장의 미수령 0원 NPC 매물도 불러올 때 제거한다.
- 아르바이트·수집의 실행 명령과 보상/획득 경로를 제거한다. 과거 명령을 직접 호출해도 현금·물품·시간·행동·난수·경험치를 바꾸지 않는다.
- 새 게임은 기존과 같은 현금 500,000원·보유품 없음에서 시작한다. 별도 시작 물품·지원금·구제 수입은 추가하지 않는다.
- 실제 플레이 수입은 물품 매매와 기존 사업 수입을 중심으로 한다. 시장·즉시 판매·사업은 유지한다. 주간 상환/이자·행동 예산·게임 종료 조건도 바꾸지 않는다.

## 기존 저장과 기록

이미 무료나눔·수집으로 획득한 물품의 매입가 0원·실제 가치·상태·확인/수리 이력을 유지한다. 일반 판매·즉시 판매·도감 기록도 유지한다. 과거 아르바이트로 받은 현금이나 수입 통계·기록을 소급 차감하지 않는다. 미수령 NPC 글만 제거하고 자산·현금·행동·경제 난수는 보존한다.

새로 획득할 수 없는 옛 도감 품목은 기존 정책대로 발견한 경우에만 보이며, 출현 경로는 ‘기존 획득품’으로 표시한다. 시작 안내 우편에서는 삭제된 세 기능을 권하지 않는다. 과거 세부 문서는 폐기된 설계 기록으로 남긴다.

## 검증 도구

경제 자동 플레이에서 아르바이트 전용·아르바이트 병행 정책을 제거한다. 판매 대기에는 기다리기를 사용하고 현금/물품을 새로 지급하지 않는다. 기존 보고서 호환용 `jobIncome` 열은 0으로 유지한다. 상태 등급의 수리 가능 조건과 F 폐기 규칙도 현재 엔진에 맞춰 사용한다.

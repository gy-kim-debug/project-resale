# 아르바이트 반복 조건

**확정: 체력·포만감 등 상태가 허용하면 같은 일거리도 연속으로 선택할 수 있다.**

- 별도의 하루 횟수 제한 대신 상태 조건으로 수행 가능 여부를 판단한다.
- 구체적으로 어떤 상태를 확인하고 어느 수치에서 제한하는지는 아직 정하지 않았다.

선택 근거: 사용자가 체력·배고픔 등이 가능하다면 연속 선택할 수 있다고 지정했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

하루 횟수 제한 없음. 포만감과 생존 상태가 허용하면 반복한다. 피로도 소진은 자동 다음 날 처리한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

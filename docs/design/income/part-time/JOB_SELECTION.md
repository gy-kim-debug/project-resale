# 아르바이트 선택 방식

**확정: 고정 일거리 여러 개 중에서 선택한다.**

- 일거리마다 소요 시간과 보수가 다르다.
- 플레이어가 원하는 일거리를 선택한다.

선택 근거: 사용자가 아르바이트 선택 방식 후보 2번 ‘고정 일거리 여러 개’를 선택했다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

전단 배포·매장 정리·창고 분류를 고른다. 행동 횟수·보상을 표시한다. 구체 값은 v1 행동표와 rules.ts가 원본이다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

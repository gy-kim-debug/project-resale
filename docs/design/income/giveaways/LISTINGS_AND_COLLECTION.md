# 무료 나눔 수령과 게시글 등장

**확정: 무료 나눔은 확정 수령 방식이지만, 나눔 글의 등장은 무작위다.**

- 올라온 나눔 글에서 수령에 필요한 조건과 시간을 충족하면 물건을 받는다.
- 다른 사람과의 경쟁으로 수령에 실패하는 방식은 사용하지 않는다.
- 무료 나눔 글은 무작위로 올라오며, 나눔 글이 없을 수도 있다.
- 플레이어에게 돈이 없더라도 무료 나눔 글이 올라오는 것은 보장하지 않는다.
- 현금 0원이라는 이유로 나눔 글을 확정 생성하거나 항상 이용할 수 있게 하지 않는다.

선택 근거: 사용자가 ‘확정 수령’을 선택하고, 게시글의 무작위 등장과 무자금 상태에서도 이용이 보장되지 않음을 직접 지정했다.

등장 확률·평가 시점, 글의 유지·갱신 규칙, 수령에 필요한 구체적인 시간·상태 조건, 물품의 종류·상태·가치는 아직 정하지 않았다.

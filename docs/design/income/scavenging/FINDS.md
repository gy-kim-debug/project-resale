# 물건 수집 결과

**확정: 시간을 쓰면 항상 물건을 얻지만, 대부분 저렴한 물건이다.**

- 물건 수집에서는 항상 물건을 발견하고 얻는다.
- 얻는 물건의 종류·상태·가치는 매번 다르다.
- 대부분은 저렴한 물건이며, 가치 있는 물건은 대부분 찾지 못한다.
- 물건 수집에는 시간이 소모된다.

선택 근거: 사용자가 ‘항상 물건 발견’을 선택하고, 대부분 저렴한 물건이며 종류·상태·가치가 다르다는 내용을 포함하도록 지정했다.

소요 시간, 획득 수량, 물품 목록과 가격 범위, 가치 있는 물건의 구체적인 발견 확률, 다른 상태 지표의 소모량과 이용 조건은 아직 정하지 않았다.

## 플레이 가능 v1 적용 정책 — 개발자 위임 결정

행동 1회·추가 포만감 5/피로도 5로 물품 1개를 항상 발견. 97% 저가 기본 가치 200–1,999원, 3% 8,000원. 상태·희귀도에 따라 실제 가치는 달라진다. 공간이 없으면 실행 전 거부한다.

[전체 수치·판정·예외 정책](../../implementation/V1_RULES.md)과 구현 `src/content/rules.ts`, `src/domain/engine.ts`를 함께 참고한다. 사용자가 직접 고른 규칙을 개발자 결정으로 바꿔 표기하지 않는다.

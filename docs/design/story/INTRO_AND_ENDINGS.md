# 시작과 엔딩의 짧은 스토리

## 사용자 확정 — 새 오프닝

- 긴 메인 챕터 대신 시작과 엔딩에 짧은 이야기를 사용한다. 기존 플레이 중 거래 이벤트는 유지한다.
- 십여 년 전 부모가 보증을 잘못 섰고, 어린 주인공을 두고 떠났다. 독촉에 시달리던 주인공은 성인이 된 후 벗어나려다 자기 이름으로 상환 약정에 묶였다.
- 현재 주인공은 낡고 습한 반지하에서 눈을 뜬다. 채무 100억 원과 현금 50만원을 확인하고, 이사 급처 알림에서 중고거래의 가능성을 발견한다.
- 주간 납부와 증가하는 부담은 상환 약정·초기 유예 기간이라는 대사로 연결한다. 게임의 이자·의무 원금·주간 행동 규칙 자체는 변경하지 않는다.
- 부모 채무가 자녀에게 자동 이전된다고 설명하지 않는다. 채권자 독촉과 성인이 된 뒤의 약정을 구분한다.
- 구도는 장면별로 바꾸되 무대의 위치·높이는 고정한다. 대사 길이와 선택지 때문에 캐릭터 위치가 밀리지 않게 한다.

대사 원문은 `src/content/intro.ts`의 `INTRO_BEATS`에 둔다. 닉네임과 현재 선택한 외형을 주인공·어린 주인공에 반영한다. 부모 모습은 회상용 보조 인물이다. 알림은 연출이며 물품·현금 보상이나 강제 구매를 발생시키지 않는다.

## 조작·동작·소리

- 각 컷은 자동으로 다음 대사로 넘어가지 않는다. 본문 터치나 텍스트 ‘다음’으로 한 컷 진행한다.
- 새 컷의 짧은 등장 동작(1.1초) 뒤 다음 조작을 활성화한다. 상단 중앙은 장면 제목, 오른쪽은 스킵이다. 최종 ‘시작하기’는 직접 선택한다.
- OS 동작 줄이기에서는 움직임과 대기를 없애고 완성된 정지 구도를 즉시 보여준다. 점멸 플래시는 사용하지 않는다.
- 효과음은 기본 꺼짐이다. ‘소리 켜기’를 직접 누르면 브라우저 Web Audio로 빗소리·노크·도장·문자음을 짧게 합성한다. 음성·외부 음원·네트워크 다운로드는 사용하지 않는다. 소리가 없어도 자막과 동작만으로 이해할 수 있다.
- 재접속과 다시 미리보기에서는 소리가 기본 꺼짐으로 돌아간다. 오디오를 지원하지 않거나 허용하지 않아도 스토리는 진행된다.

## 저장 호환과 미리보기

- 새 슬롯 생성 시에만 `introVersion: 2`인 도입을 설정한다. 매 컷의 `story.active.step`을 기존 저장 경로로 저장하고 재접속 시 해당 컷을 이어간다.
- 이미 시작을 마친 저장에 오프닝을 소급 삽입하지 않는다. 이전 버전의 도입을 진행 중인 저장은 기존 7줄 도입과 기존 위치를 그대로 유지한다.
- 도입·스킵·읽기는 현금·채무·시간·행동·물품·경제 난수를 변경하지 않는다. 최종 시작을 중복 실행할 수 없다.
- 개발자 콘솔 `previewIntro()`로 저장을 바꾸지 않는 독립 복사본을 볼 수 있다. 스킵은 마지막 컷, 시작하기·Escape는 미리보기 종료다. 실제 저장의 스킵은 마지막 컷으로 이동한 뒤 시작하기를 직접 선택한다.

## 엔딩 — v1 개발자 작성 대사

다음 대사는 ‘성공·실패 시 짧은 엔딩’ 요구를 구현하기 위한 초안이며 별도로 사용자에게 확정받은 문구는 아니다.

### 성공

- 채권 담당자: “마지막 상환까지 확인했습니다.”
- 채권 담당자: “남은 채무는 없습니다.”
- 전화를 내려놓는다. 방 안이 조용하다.
- 주인공: “……끝났다.”
- **결과 보기** → 기존 클리어 결과 화면.

### 실패

- 채권 담당자: “이번 주 상환금을 확인하지 못했습니다.”
- 주인공: “조금만 더 시간을……”
- 채권 담당자: “약속한 기한은 지났습니다.”
- 통화가 끝난 화면을 한동안 바라본다.
- **결과 보기** → 기존 게임 종료 결과 화면.

기존 저장의 이미 종료된 게임에는 엔딩을 새로 끼워 넣지 않는다. 이야기 도입 이후 새로 종료된 진행에는 엔딩을 표시하고, 완료 여부를 슬롯에 저장한다. 현행 게임의 실패 조건은 주간 의무 원금·이자 미납이며 별도 체력·사망 시스템을 추가하지 않는다.

## 연출과 조작

- 기존 엔딩과 거래 이벤트는 방·거리 배경과 공유 도트 캐릭터를 유지한다. 새 도입은 위 12컷 전용 구도를 사용한다.
- 전체 문장은 즉시 표시한다. 새 도입의 선택적 효과음 외에는 기존 엔딩·거래 이벤트에 오디오를 추가하지 않는다.
- **다음** 버튼 또는 대화 본문 터치로 한 대사 진행. **스킵**는 마지막 대사·결정 지점까지만 이동한다. 최종 시작/결과 확인은 직접 선택한다.
- 선택지는 버튼이며 키보드로 금액·대사를 입력하지 않는다. 키보드 접근 시 포커스를 장면 안에 유지한다.
- 작은 높이에서도 도트 장면 위치는 고정하며 하단 대화 영역만 세로 스크롤할 수 있다. OS 동작 줄이기 설정에서는 애니메이션을 끈다.
- 대사 진행·건너뛰기·읽기 자체는 현금, 시간, 행동, 경제 난수를 변경하지 않는다.

## 저장과 책임

- `Game.story.active`에 장면 종류, 대사 위치, 거래 대상, 후속 거래 명령을 저장한다.
- 완료 여부·발생 이력은 슬롯마다 독립적이다. 대화 문구는 금액·대상 정보로 구성하며 저장된 임의 대사를 실행하지 않는다.
- `src/content/story.ts`: 장면 목록·제목·발생 정책.
- `src/domain/story.ts`: 대사·선택지 구성과 조건 평가.
- `src/domain/engine.ts`: 선택 검증, 자산 변경, 거래 원자성.
- `src/components/StoryPlayer.tsx`: 도트 장면·대화·선택 버튼. 저장이나 경제 계산을 직접 실행하지 않는다.

## 미정·향후 검토

- 최종 게임 제목, 엔딩 대사의 최종 문구.
- 엔딩·거래 이벤트의 전용 구도 확대. 새 오프닝 구도·효과음은 위 명세를 적용한다.

## 대사 진행 표시 후속 변경 (2026-11-02)

사용자 요청에 따라 다음 대사 버튼은 테두리·배경·둥근 도형·화살표 없이 **다음** 글자만 오른쪽에 표시한다. 터치 영역 48px 높이, 실제 button 의미, 키보드 포커스는 텍스트 밑줄로 표시한다. 도입·엔딩·이벤트·콘솔 미리보기의 공유 StoryPlayer에 함께 적용한다. 최종 선택지 버튼의 배경과 테두리는 유지한다.

## 상단 배치와 장면 고정 (2026-11-02)

사용자 확정: 대화 상단은 **이벤트명 가운데 / 스킵 오른쪽**으로 표시하며 닫기 버튼은 제거한다. 제목은 양쪽에 같은 폭을 확보해 실제 패널 중앙에 둔다. 마지막 대사·선택 지점에서는 스킵을 숨기되 제목 위치는 유지한다. 스킵은 기존대로 선택을 대신 고르지 않고 마지막 대사까지만 진행한다.

도트 장면을 포함한 패널은 뷰포트·Safe Area 내 일정 높이(최대 760px)를 사용한다. 상단 바와 도트 영역은 줄어들지 않고 대화·선택지 영역만 스크롤된다. 대사나 선택 개수·목록 펼침이 바뀌어도 패널의 중앙 정렬 기준과 도트 영역 위치가 움직이지 않는다. 대사마다 도트 영역을 재생성하지 않아 입장 애니메이션도 불필요하게 재시작하지 않는다. 캐릭터 자체의 의도된 동작 연출은 유지한다.

콘솔 미리보기도 같은 헤더를 사용한다. 중도 종료는 Esc로 제공하고, 모바일에서는 스킵 후 마지막 선택·완료로 빠져나올 수 있다. 이벤트 선택 목록의 닫기는 대화 장면 밖의 개발자 메뉴 조작으로 유지한다.

## 다음 글자 깜빡임 (2026-11-04)

사용자 요청에 따라 ‘다음’ 글자만 1.6초 주기로 불투명도 1↔0.45를 부드럽게 반복한다. 버튼 전체나 도트 장면은 깜빡이지 않으며, 글자가 완전히 사라지지 않는다. 투명 배경·테두리 없는 형태·48px 터치 높이·키보드 밑줄은 유지한다. OS 동작 줄이기 설정에서는 애니메이션 없이 정적으로 표시한다.

# 콘솔 엔딩 미리보기

개발자 도구 Console에서 아래 명령을 실행한다. 배포된 게임에서도 사용할 수 있다.

```js
previewEnding(); // 성공 엔딩 (기본)
previewEnding('failure'); // 주간 상환 실패 엔딩
```

- 저장이 없는 시작 메뉴에서도 볼 수 있다. 진행 중인 게임이 있다면 현재 닉네임·외형으로 재생한다.
- **다음**, 대화 터치, **건너뛰기**로 대사를 진행한다. **미리보기 마치기** 또는 **닫기**를 누르면 원래 화면으로 돌아온다.
- 실제 게임·슬롯·자동 저장을 수정하지 않는다. 복사한 상태만 별도 React 루트에서 진행하며, 엔딩 완료 여부나 채무 원금도 실제 저장에 반영하지 않는다.
- 실행 중에는 원래 앱 화면을 inert 처리한다. 기존 도입/이벤트 대사가 열려 있었다면 닫은 후 동일 지점에서 이어진다. 새로고침하면 미리보기는 사라진다.
- 이미 미리보기 중이거나 실제 행동 연출·슬롯 작업 중에는 `false`를 반환한다. 열었으면 `true`. 허용되지 않는 인수는 오류를 반환한다.
- 실제 클리어·파산을 강제로 만드는 치트 명령은 제공하지 않는다.

`app/endingPreview.ts`는 콘솔 명령과 임시 루트 생명주기, `components/EndingPreview.tsx`는 복사본의 대화 진행을 담당한다. 기존 `StoryPlayer`에 미리보기 입력을 전달해 실제 엔딩과 동일한 도트·대사·조작을 재사용한다. 미리보기에서는 실제 게임의 `act`·저장소 쓰기 함수를 호출하지 않는다.

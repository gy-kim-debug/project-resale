# 콘솔 엔딩·이벤트 미리보기

개발자 도구 Console에서 아래 명령을 실행한다. 배포된 게임에서도 사용할 수 있다.

```js
previewEnding(); // 성공 엔딩 (기본)
previewEnding('failure'); // 주간 상환 실패 엔딩
```

- 저장이 없는 시작 메뉴에서도 볼 수 있다. 진행 중인 게임이 있다면 현재 닉네임·외형으로 재생한다.
- **다음**, 대화 터치, **건너뛰기**로 대사를 진행한다. **미리보기 마치기** 또는 **닫기**를 누르면 원래 화면으로 돌아온다.
- 실제 게임·슬롯·자동 저장을 수정하지 않는다. 복사한 상태만 별도 React 루트에서 진행하며, 엔딩 완료 여부나 채무 원금도 실제 저장에 반영하지 않는다.
- 실행 중에는 원래 앱 화면을 inert 처리한다. 기존 도입/이벤트 대사가 열려 있었다면 닫은 후 동일 지점에서 이어진다. 새로고침하면 미리보기는 사라진다.
- 이미 미리보기 중이거나 실제 행동 연출·슬롯 작업 중에는 `false`를 반환한다. 열었으면 `true`. 허용되지 않는 인수는 오류를 반환한다.
- 실제 클리어·파산을 강제로 만드는 치트 명령은 제공하지 않는다.

`app/endingPreview.ts`는 콘솔 명령과 임시 루트 생명주기, `components/EndingPreview.tsx`는 복사본의 대화 진행을 담당한다. 기존 `StoryPlayer`에 미리보기 입력을 전달해 실제 엔딩과 동일한 도트·대사·조작을 재사용한다. 미리보기에서는 실제 게임의 `act`·저장소 쓰기 함수를 호출하지 않는다.

## 이벤트 미리보기

```js
previewEvent(); // 이벤트 8종 선택 목록
previewEvent('bundle'); // 묶음 정리 바로 보기
previewEvent('묶음 정리'); // 한글 이름도 지원
```

| ID           | 장면             |
| ------------ | ---------------- |
| `missing`    | 빠진 구성품      |
| `rehaggle`   | 현장 재흥정      |
| `regular`    | 단골의 부탁      |
| `model`      | 이름표 확인      |
| `memory`     | 추억이 담긴 물건 |
| `competitor` | 경쟁자의 제안    |
| `bundle`     | 묶음 정리        |
| `creditor`   | 채권자의 방문    |

- 인수 없이 실행하면 목록에서 고른다. 사건의 선택을 마치거나 장면을 닫으면 목록으로 돌아가 다른 사건도 볼 수 있다. 목록의 닫기를 누르면 원래 게임으로 돌아간다.
- ID 또는 표의 정확한 한글 이름을 지정하면 그 장면만 바로 열린다. 장면 완료/닫기 시 원래 게임으로 돌아간다.
- 이벤트는 현재 캐릭터 외형·닉네임을 사용하지만, 물건·거래 상대·현금·행동 등은 `app/eventPreview.ts`의 고정 샘플이다. 실제 보유품·매물·문의·빚·진행은 참조하거나 변경하지 않는다.
- 실제 이벤트와 같은 대사·선택지·번개 표시를 사용한다. 모델 설명, 할인 구매, 묶음 구매, 현장 재흥정, 단골 부탁, 일괄 판매도 샘플 상태에서만 실행한다. 재생을 위해 본 게임의 발생 확률이나 조건을 변경하지 않는다.
- 엔딩과 이벤트가 하나의 미리보기 잠금을 공유한다. 이미 하나가 열려 있으면 다른 명령은 `false`다. 잘못된 이름은 허용 ID가 담긴 오류를 반환한다.
- `EventPreviewMenu`는 목록과 장면 선택을 담당하고 `EndingPreview`의 복사본 진행기를 엔딩·이벤트가 함께 사용한다. 실제 게임 `act`나 저장소 쓰기는 호출하지 않는다.

# 플레이 가능 v1 — 위임받아 정한 정책

이 문서는 사용자가 **“전부 다 알아서 정책을 정한 다음 게임을 진행할 수 있게 만들어달라”**고 위임한 뒤, 개발자가 선택해 구현한 초기 정책이다. 사용자가 직접 고른 기존 규칙과 구분한다. 밸런스는 조정 가능하며, 코드의 원본 데이터는 `src/content/rules.ts`, 계산은 `src/domain/engine.ts`다. [사용자 확정 UI](../ui/LAYOUT.md)는 그대로 유지한다.

## 시작·목표·종료

- 1일째 09:00. 현금 0원, 물품 없음, 원금 10,000,000,000원, 이자 0원.
- 포만감·체력·피로도는 100으로 시작하며 범위는 0–100.
- 체력 0은 사망, 진행 종료. 종료한 저장에서는 어떤 행동도 실행하지 못한다.
- 원금과 이자를 전부 갚으면 클리어. 무일푼 자체는 종료 조건이 아니다. 무료 급식·알바·수집으로 재기 가능하다.
- 새 게임은 명시적 확인 후 이전 진행을 교체한다. 회차 표시·계승·영구 성장·사망한 진행의 부활은 없다.

사용자 후속 확정으로 행동 단위를 정수 시간으로 변경했다. 기존 1시간 미만 행동은 1시간으로 올리고 1·2·3시간 행동은 유지하는 환산을 개발자가 적용했다. 구체적인 시간 원칙과 기존 저장 호환 처리는 [시간·진행](../core/TIME_AND_PROGRESS.md)에 기록한다.

## 시간·생존

- 정수 시간 단위. 행동 실행에만 시간이 흐른다. 메뉴·상세·안내 읽기·백업·앱 종료·오프라인 대기는 시간 소모 없음.
- 시간당 포만감 3, 피로도 4 감소. 기존 저장 데이터의 소모 잔여치는 유지한다.
- 활동별 추가 소모는 아래 표에 합산한다. 포만감이 0이면 포만감 소모 행동은 불가하며 무료 급식·음식·치료·수면·폐기·문의 응답은 가능하다.
- 일반 활동 중 포만감이 바닥나면 해당 행동 1시간당 체력 4씩 감소한다. 회복 행동·문의 응답은 이 체력 손실을 적용하지 않는다.
- 피로도 0이면 실행 중 행동을 마친 뒤 해당 날짜를 종료하고 다음 날 09:00로 넘어간다. 수면 중에는 시간 비례 생존 소모 대신 고정 포만감 18 감소만 적용한다. 피로도 100, 체력 유지.
- 자발적 수면도 무료이며 다음 날짜 09:00로 간다. 새벽에 자더라도 날짜 기준 다음 날이다.
- 수면을 가로질러 자정 이자 정산·일별 시장 변화·매물 교체·판매 글 만료를 처리한다. 거래 문의가 이미 있으면 먼저 응답해야 수면 가능하다.
- 회복 행동의 수치는 경과 시간 반영 후 가산·100 제한한다. 자동 수면이 발생하면 수면까지 반영된 뒤 가산한다.
- **생존 수치를 실제 가치·매매 확률의 입력으로 사용하지 않는다.** 다만 행동 가능 여부와 사망·하루 종료에는 영향을 준다.

## 물품·획득·불확실성

- 4개 카테고리: 생활·디지털·가구·수집품. 가격대별 이름은 콘텐츠 데이터로 분리한다.
- 게시판 기본 8개, 24시간 유효. 탐색·수면으로 새 매물을 만든다.
- 갱신 때 현금과 무관하게 50% 확률로 무료나눔 1개가 추가된다. 없을 수 있다. 있으면 시간·보관·포만감 조건 충족 시 확정 수령하며 경쟁 실패는 없다.
- 수집은 97% 저렴한 기본 가치 200–1,999원 품목, 3% 기본 가치 8,000원 품목. 아래 상태·희귀도 판정도 적용하므로 실제 가치는 달라진다.
- 상태는 고장 18%, 사용감 37%, 양호 45%. 상태 가치 계수는 각각 18%·75%·100%다.
- 별도 희귀도는 가품/부품 이상 10%(기본 가치 8%), 보통 76%(100%), 희소 11%(150%), 희귀 3%(400%). 상태와 희귀도는 독립이며 구매 전에는 상태를 확인할 수 없다. 상태는 보유 후 즉시 표시하며 실제 가치·숨겨진 결함은 별도 가치 확인으로 공개한다.
- 판매자 가격은 등급 기준 가치의 약 42–90%로 표시하고, 실제 상태·희귀도와 별도 생성한다. 저가 이유가 결함일 수도, 판매자가 가치를 몰랐기 때문일 수도 있다.
- 구매 네고는 게시 가격의 70% 또는 85%(정수 내림)를 선택. 수락률은 각각 40%·80%. 거절되면 원래 가격으로 구매 가능, 재제안은 불가하다.
- 구매·나눔·수집 전에 보관함 공간과 비용을 검사한다. 조건 미충족이면 시간·비용·난수 모두 그대로다.
- 수리 성공률은 기본 70%, 수리 레벨당 +5%p, 최대 95%. 성공하면 상태 양호·본래 기본 가치 회복. 가품 자체를 진품으로 만들지는 않는다. 실패 시 비용은 사용하고 가치는 유지하며 재수리 불가.

## 보관·장터 판매

- 보관함 고정 12칸. 물품 하나당 1칸. 등록 중에도 공간을 점유한다. 보관 공간은 성장으로 늘지 않는다.
- 동시 판매 글 기본 3개, 거래 감각 레벨당 +1개, 최대 8개.
- 원하는 정수 가격 1원–1,000조 원 입력. 등록 중 수정 불가. 취소·만료 후 새 가격 재등록 가능.
- 모든 등록은 게임 시간 48시간 뒤 만료된다. 문의 처리 중인 글은 응답을 마칠 때까지 만료 보류한다.
- 등록 완료 후 최초 1시간 이후, 시간이 소모되는 행동으로 1시간이 경과할 때 문의 판정. 한 번에 한 물품에 구매자 2명이 나타난다. 일괄 오프라인·장시간 건너뛰기의 판정을 소급 누적하지 않는다.
- 등록가/시장가 비율이 1.1 이하이면 문의 등장 85%, 1.6 이하 50%, 그 이상 20%. 과도한 가격에도 낮은 구매 제안만 올 수 있다.
- 구매자 최대 지불 의사는 시장 가치의 90–120%. 최대 금액 내의 등록가에는 50% 확률로 정가 문의, 나머지는 등록가/최대 지불액 중 낮은 금액의 75–95% 제안(정수 내림, 최소 1원).
- 문의가 있으면 시간·금액을 쓰는 다른 행동과 탐색·폐기·메뉴 이탈을 막는다. 비교·수락·거절·파토만 가능. 앱을 닫아도 문의는 저장된다. 문의 자체의 자동 만료는 적용하지 않는다.
- 거절하면 30% 확률로 즉시 파토. 그 외에는 구매자 최대액 이내에서 약 12%(최소 1원) 올려 재제안한다. 최대 2회 재제안, 최대액 도달 뒤 거절 시 파토.
- 플레이어도 등록가 이내에서 구매자에게 더 높은 가격을 제안할 수 있다. 파토가 나면 해당 문의만 종료하고 판매 글·다른 문의·원래 가격·만료 시각은 유지한다.
- 수락 시 물품·대금을 한 행동으로 교환하고 같은 글의 남은 문의를 함께 종료한다.

## 매각처

- 고물상: 모든 카테고리, 현재 시장 가치의 45%.
- 중고 상점: 디지털·가구, 72%.
- 수집품 상점: 수집품, 85%.
- 매각처로 이동해서 가격을 표시한다. 이동은 행동이 아니며 시간·상태 소모가 없다. 방문 시 보유한 취급 물품을 함께 견적 낸다. 유효 기간 2시간, 가격 내림·최소 1원. 재방문도 시간 소모 없이 현재 시세로 새 견적을 받는다.
- 장터 등록품은 등록 취소 전 매각 불가. 가격 협상 없음.

## 성장·시장

- 매각·장터 판매 5회마다 거래 감각 +1. 별도 가치 확인 4회마다 감정 지식 +1. 수리 시도 4회마다 수리 기술 +1. 최대 레벨 10, 처음은 0.
- 감정 지식은 가치 확인비 레벨당 5% 절감(최대 50%). 수리 기술 효과는 위 수리 성공률. 영구 계승 없음.
- 현금 최고 기록으로 거래 규모를 해금한다: 0 / 3만 / 15만 / 100만 / 1천만 / 1억 / 10억 / 50억 원. 기준 물품 가치는 각각 6천 / 4만 / 20만 / 120만 / 1,200만 / 1.2억 / 12억 / 60억 원.
- 갱신 게시판은 가장 저렴한 물품, 현재 현금에 맞는 등급/한 단계 낮은 등급, 최고 해금 등급을 섞는다. 손실로 현금이 줄어도 저가 거래로 재기 가능하다.
- 매일 전반 시장 계수 85–115%, 한 카테고리 수요 +20%p. 표시되는 확인 가치는 물품 본래 실제 가치이고, 구매자/매각처는 일별 시장 가치를 기준으로 한다.

## 이자·사건

- 처음 3일 무이자. 4일째부터 자정마다 남은 원금 / 1,000,000을 올림하여 이자 발생(일 0.0001%). 복리 없음. 일부 상환은 이자→원금, 초과·소수·음수·현금 초과는 거부한다.
- 수면·자동 다음 날에도 이자가 발생한다. 최종 상환으로 원금 0이면 이후 이자는 없다.
- 시장 변화와 가품·희귀품·수리 실패는 기본 변칙 요소다.
- 최소 3시간 간격으로 조건을 만족할 때 15% 확률의 이사 정리 제안: 1시간·포만감 추가 8·피로도 추가 5·15,000원 보상, 8시간 유효.
- 판매 3회 후 수리 전문가의 교육 제안: 5,000원·1시간·수리 경험 +4, 48시간 유효. 수락 뒤 최소 24시간 후 다음 행동에서 단골 소개 감사금 10,000원. 이 후속 사건은 한 번만 발생한다.
- 제안은 선택 가능하며 거절 1시간. 만료되면 사라진다. 사건·문의 모두 순수 엔진의 게임 시간·시드·자산·이력으로 판정한다.

## 저장·정확성·오프라인

- Zustand는 상태 반영, 순수 엔진은 계산, IndexedDB 저장소는 버전 2 전체 게임 스냅샷을 저장한다. 매 성공 행동과 관심 변경 후 직렬화 저장한다.
- 행동 비용은 정수 시간, 저장 시간은 호환성을 위해 정수 분, 돈은 안전 정수 원 단위, 플레이어가 다룰 금액 상한은 1,000조 원이다. 소수 금액 계산은 정수 내림/올림 정책을 명시하고 마지막 원 단위로 보관한다.
- 난수 시드도 함께 저장해 재로딩으로 같은 협상 결과를 반복 추첨하지 못한다. 실제 가치는 오프라인 싱글 플레이 특성상 저장 데이터에 포함되지만 확인 전 UI에는 공개하지 않는다.
- 과거 v1 관심 매물 전용 저장은 별도 키 `legacy-v1`에 보관하고 실제 진행은 새로 시작한다. 잘못된 저장 데이터는 원본을 덮어쓰지 않도록 자동 저장을 중지한다.
- JSON 백업 내보내기·가져오기, 입력 검증, 종료 상태 보관, 명시적 새 게임 확인을 제공한다. 저장 불가 시 화면 안내와 메모리 플레이는 유지된다.
- 첫 정상 접속에서 서비스 워커가 앱 파일을 받은 뒤 오프라인 재실행 가능. 설치/캐시가 막힌 브라우저는 이미 로드한 화면과 IndexedDB만 사용할 수 있다. 새 버전은 저장을 마친 후 적용한다.
- 백엔드·계정·결제·네이티브 프로젝트·회차 계승은 추가하지 않는다. 다른 기기 간 자동 동기화는 없고 백업 파일로 옮긴다.

이 버전은 플레이 검증을 위한 첫 밸런스다. 초기 목표까지 가는 경로를 테스트하지만 재미·경제 균형·난도는 실제 플레이 피드백으로 추가 조정한다.

## 사용자 후속 확정 — 무료 흥정과 구매 후 상태 확인

- 구매 전 가격 제안과 판매자 답변, 대화 종료는 모두 채팅으로 진행하고 0시간이다. 구매 확정 시 물품 수령에 1시간을 적용한다. 흥정 자체의 종료 비용은 없다.
- 판매 문의 거절·재제안·직접 파토·구매자 이탈은 모두 0시간. 판매 성사 시에만 물품·대금 교환에 1시간을 적용한다.
- 모든 흥정과 종료에는 생존 소모·이자·매물 만료·사건·750ms 시간 경과 연출이 없다. 대화 변경은 즉시 저장한다.
- 기존 매입 1회 제안, 판매 재제안 최대 2회와 파토 확률, 문의 응답 강제, 매각처 무협상은 유지한다.
- 구매 전 상태 확인 행동과 비용을 제거했다. 매물은 상태·결함 비공개이며, 과거 확인 이력도 구매 전에는 사용하지 않는다. 구매 후 보관함에서 상태를 즉시 표시한다. 실제 가치·숨겨진 결함은 기존 별도 가치 확인 정책을 유지한다.

## 사용자 후속 확정 — 판매자 가격 제안·파토 후 판매 유지

판매 채팅에서 플레이어도 가격을 제안한다. 구매자 답변은 수락·재제안·파토 중 하나이며, 대화와 파토는 0시간이다. 실제 거래 확정에만 1시간을 적용한다. 제안 범위·횟수·답변 정책은 [판매 네고](../trading/marketplace/NEGOTIATION.md)에 구분해서 기록한다.

파토가 나도 해당 판매 글을 유지하고 그 구매자의 문의만 닫는다. 기존 문의는 계속 처리할 수 있고 모두 종료된 뒤에는 원래 글에서 새 문의를 기다린다. 명시적 취소·원래 기한 만료·실제 판매 성사에만 글이 종료된다.

# 플레이 가능 v1 — 위임받아 정한 정책

이 문서는 사용자가 **“전부 다 알아서 정책을 정한 다음 게임을 진행할 수 있게 만들어달라”**고 위임한 뒤, 개발자가 선택해 구현한 초기 정책이다. 사용자가 직접 고른 기존 규칙과 구분한다. 밸런스는 조정 가능하며, 코드의 원본 데이터는 `src/content/rules.ts`, 계산은 `src/domain/engine.ts`다. [사용자 확정 UI](../ui/LAYOUT.md)는 그대로 유지한다.

## 시작·목표·종료

- 1주차 · 남은 행동 20/20. 현금 500,000원, 물품 없음, 원금 10,000,000,000원, 이자 0원.
- 원금과 남은 이자를 전부 갚으면 클리어. 사용자 후속 결정으로 주간 의무 원금 또는 이자 미납은 게임 오버다. 마지막 상환은 클리어가 우선이다.
- 새 게임은 명시적 확인 후 이전 진행을 교체한다. 회차 표시·계승·영구 성장·종료된 진행의 부활은 없다.

사용자 후속 확정으로 주당 20행동 모델을 적용했다. 소진 또는 조기 정산 확정 후 이자를 납부하면 다음 주를 시작한다. [날짜·행동·저장 전환 정책](../core/TIME_AND_PROGRESS.md)을 기준으로 한다.

## 날짜·주간 납부

- 1주차 · 남은 행동 20/20. 주요 행동은 종류와 관계없이 각각 1회. 20회 소진 후 정산하거나 홈에서 조기 정산한다. 이자 납부 후 다음 주 20회를 지급한다.
- 포만감·체력·피로도와 식사·수면·치료는 사용자 후속 결정으로 제거했다.
- 이동·흥정·파토·폐기·특별 제안 거절·메뉴·오프라인 대기는 행동 소모 없음.
- 생존 수치의 소모·회복·사망 판정은 없다. 물품 가치·거래 확률 계산은 유지한다.

## 물품·획득·불확실성

- 8개 분류: 생활·디지털·가구·수집품·악기·자동차·부동산·항공기. 6개 시장의 가격대와 고유 품목은 [시장별 문서](../markets/OVERVIEW.md)와 `src/content/markets.ts`로 분리한다.
- 시장별 기본 8개, 전체 유료 48개, 무료나눔은 장터에만 최대 1개. 일반 매물은 행동 3회 동안 유효. 실제 급처·이사정리 매물은 행동 2회. 탐색·행동 3회 간격·새 주 시작로 새 매물을 만든다.
- 갱신 때 현금과 무관하게 50% 확률로 무료나눔 1개가 추가된다. 없을 수 있다. 있으면 행동·보관 조건 충족 시 확정 수령하며 경쟁 실패는 없다.
- 수집은 97%가 카테고리 적용 전 기준 가치 5,000–19,999원, 3%가 80,000원 품목. 아래 상태·희귀도 판정도 적용하므로 실제 가치는 달라진다.
- 상태는 고장 18%, 사용감 37%, 양호 45%. 상태 가치 계수는 각각 18%·75%·100%다.
- 수집·구 물품의 기존 희귀도는 가품/부품 이상 10%(기본 가치 8%), 보통 76%(100%), 희소 11%(150%), 희귀 3%(400%)다. 신규 태그 매물의 진위·특징·가치 판정은 [태그 정책](../items/LISTING_TAGS.md)으로 대체한다. 상태는 독립이며 구매 전에는 확인할 수 없다. 상태는 보유 후 즉시 표시하며 실제 가치·숨겨진 결함·진위와 특징은 별도 가치 확인으로 공개한다.
- 판매자 가격은 카테고리 적용 기준 가치의 약 35–70% 미만에서 1,000원 단위로 표시하고, 실제 상태·희귀도와 별도 생성한다. 실제 급처는 이 가격에 90%를 추가 적용한다. 저가 이유가 결함일 수도, 판매자가 가치를 몰랐기 때문일 수도 있다.
- 구매 네고는 시장별 최초 제안(중고 장터 70%/85%) 이후 판매자 역제안과 플레이어 재제안을 반복한다. 라운드·양보·합의·최종 가격·파토·저장 정책은 [구매 협상](../trading/purchasing/NEGOTIATION.md)을 따른다. 흥정은 행동 소모 없음, 실제 구매만 행동 1회다.
- 구매·나눔·수집 전에 보관함 공간과 비용을 검사한다. 조건 미충족이면 시간·비용·난수 모두 그대로다.
- 수리 성공률은 기본 70%, 수리 레벨당 +5%p, 최대 95%. 성공하면 상태 양호·본래 기본 가치 회복. 가품 자체를 진품으로 만들지는 않는다. 실패 시 비용은 사용하고 가치는 유지하며 재수리 불가.

## 보관·장터 판매

- 보관함 고정 12칸. 물품 하나당 1칸. 등록 중에도 공간을 점유한다. 보관 공간은 성장으로 늘지 않는다.
- 동시 판매 글 기본 3개, 거래 감각 레벨당 +1개, 최대 8개.
- 원하는 100원 단위 가격 100원–1,000조 원 입력. 등록 중 수정 불가. 취소·만료 후 새 가격 재등록 가능.
- 모든 등록은 게임 시간 2일 뒤 만료된다. 문의 처리 중인 글은 응답을 마칠 때까지 만료 보류한다.
- 등록 완료 후 다음 주요 행동부터, 각 주요 행동이 끝날 때 문의를 판정한다. 한 번에 한 물품에 구매자 2명이 나타난다. 시장 갱신 시에도 판정을 소급 누적하지 않는다.
- 등록가/시장가 비율이 1.1 이하이면 문의 등장 85%, 1.6 이하 50%, 그 이상 20%. 과도한 가격에도 낮은 구매 제안만 올 수 있다.
- 구매자 최대 지불 의사는 시장 가치의 90–120%. 최대 금액 내의 등록가에는 50% 확률로 정가 문의, 나머지는 등록가/최대 지불액 중 낮은 금액의 75–95% 제안(100원 단위 반올림, 최소 100원).
- 문의가 있으면 시간·금액을 쓰는 다른 행동과 탐색·폐기·메뉴 이탈을 막는다. 비교·가격 제안·수락·거절·파토만 가능. 앱을 닫아도 문의는 저장된다. 문의 자체의 자동 만료는 적용하지 않는다.
- 거절하면 30% 확률로 즉시 파토. 그 외에는 구매자 최대액 이내에서 약 12%(최소 100원) 올려 재제안한다. 최대 2회 재제안, 최대액 도달 뒤 거절 시 파토.
- 플레이어도 등록가 이내에서 구매자에게 더 높은 가격을 제안할 수 있다. 파토가 나면 해당 문의만 종료하고 판매 글·다른 문의·원래 가격·만료 시각은 유지한다.
- 수락 시 물품·대금을 한 행동으로 교환하고 같은 글의 남은 문의를 함께 종료한다.

## 즉시 판매

사용자 후속 확정으로 여러 매각처를 `즉시 판매` 하나로 통합했다. 실제 가치의 60%를 100원 단위 반올림하여 지급한다. 시세·호가·매입가·이전 견적은 계산에 사용하지 않는다. 감정 전에도 판매 가능하며 별도 방문·견적 만료는 없다. 등록 중인 물품은 먼저 취소한다. 상세 정책은 [즉시 판매](../trading/INSTANT_SALE.md)를 따른다.

## 성장·시장

- 매각·장터 판매 5회마다 거래 감각 +1. 별도 가치 확인 4회마다 감정 지식 +1. 수리 시도 4회마다 수리 기술 +1. 최대 레벨 10, 처음은 0.
- 감정 지식은 가치 확인비 레벨당 5% 절감(최대 50%). 수리 기술 효과는 위 수리 성공률. 영구 계승 없음.
- 신규 유료 매물은 현금 최고 기록에 따른 단일 게시판 확장 대신 시장별 고정 가격대를 사용한다. 모든 시장을 둘러볼 수 있고 실제 매입은 현금·보관 공간으로 제한한다. 최고 현금 기반 거래 등급 표시는 기존 기록으로 유지하며 시장 입장을 잠그지 않는다.
- 갱신 게시판은 가장 저렴한 물품, 현재 현금에 맞는 등급/한 단계 낮은 등급, 최고 해금 등급을 섞는다. 손실로 현금이 줄어도 저가 거래로 재기 가능하다.
- 매일 전반 시장 계수 85–115%, 한 카테고리 수요 +20%p. 표시되는 확인 가치는 물품 본래 실제 가치이고, 시장 구매자는 시장 가치를 기준으로 하며 즉시 판매는 실제 가치의 60%다.

## 이자·사건

- 주간 정산을 확정하면 해당 주 이자 납부가 필요하다. 0.001%부터 매주 0.002%p 증가. 납부 시 남은 원금으로 계산하며 100원 단위 반올림. 현금 부족은 종료, 충분하면 납부 후 진행한다. 원금 상환과 주간 이자 납부를 분리한다.
- 일별 이자 누적·3일 유예는 폐기했다. 자세한 주차·저장 전환·납부 정책은 주간 채무 문서를 따른다.
- 시장 변화와 가품·희귀품·수리 실패는 기본 변칙 요소다.
- 최소 행동 1회 간격으로 조건을 만족할 때 15% 확률의 이사 정리 제안: 행동 1회·15,000원 보상, 1일 유효.
- 판매 3회 후 수리 전문가의 교육 제안: 5,000원·행동 1회·수리 경험 +4, 행동 6회 유효. 수락 뒤 최소 행동 3회 후 다음 행동에서 단골 소개 감사금 10,000원. 이 후속 사건은 한 번만 발생한다.
- 제안은 선택 가능하며 거절은 행동 소모 없음. 만료되면 사라진다. 사건·문의 모두 순수 엔진의 게임 시간·시드·자산·이력으로 판정한다.

## 저장·정확성·오프라인

- Zustand는 상태 반영, 순수 엔진은 계산, IndexedDB 저장소는 버전 2 전체 게임 스냅샷을 저장한다. 매 성공 행동과 관심 변경 후 직렬화 저장한다.
- 행동 비용은 주간 20회 예산, 저장 시간은 호환용 정수 눈금, 돈은 안전 정수 원 단위, 플레이어가 다룰 금액 상한은 1,000조 원이다. 소수 금액 계산은 정수 내림/올림 정책을 명시하고 마지막 원 단위로 보관한다.
- 난수 시드도 함께 저장해 재로딩으로 같은 협상 결과를 반복 추첨하지 못한다. 실제 가치는 오프라인 싱글 플레이 특성상 저장 데이터에 포함되지만 확인 전 UI에는 공개하지 않는다.
- 과거 v1 관심 매물 전용 저장은 별도 키 `legacy-v1`에 보관하고 실제 진행은 새로 시작한다. 잘못된 저장 데이터는 원본을 덮어쓰지 않도록 자동 저장을 중지한다.
- JSON 백업 내보내기·가져오기, 입력 검증, 종료 상태 보관, 명시적 새 게임 확인을 제공한다. 저장 불가 시 화면 안내와 메모리 플레이는 유지된다.
- 첫 정상 접속에서 서비스 워커가 앱 파일을 받은 뒤 오프라인 재실행 가능. 설치/캐시가 막힌 브라우저는 이미 로드한 화면과 IndexedDB만 사용할 수 있다. 새 버전은 저장을 마친 후 적용한다.
- 백엔드·계정·결제·네이티브 프로젝트·회차 계승은 추가하지 않는다. 다른 기기 간 자동 동기화는 없고 백업 파일로 옮긴다.

이 버전은 플레이 검증을 위한 첫 밸런스다. 초기 목표까지 가는 경로를 테스트하지만 재미·경제 균형·난도는 실제 플레이 피드백으로 추가 조정한다.

## 사용자 후속 확정 — 무료 흥정과 구매 후 상태 확인

- 구매 전 가격 제안과 판매자 답변, 대화 종료는 모두 채팅으로 진행하고 행동 소모 없음이다. 구매 확정 시 물품 수령에 행동 1회를 적용한다. 흥정 자체의 종료 비용은 없다.
- 판매 문의 거절·재제안·직접 파토·구매자 이탈은 모두 행동 소모 없음. 판매 성사 시에만 물품·대금 교환에 행동 1회를 적용한다.
- 모든 흥정과 종료에는 생존 소모·이자·매물 만료·사건·750ms 시간 경과 연출이 없다. 대화 변경은 즉시 저장한다.
- 기존 매입 1회 제안, 판매 재제안 최대 2회와 파토 확률, 문의 응답 강제, 즉시 판매 무협상은 유지한다.
- 구매 전 상태 확인 행동과 비용을 제거했다. 매물은 상태·결함 비공개이며, 과거 확인 이력도 구매 전에는 사용하지 않는다. 구매 후 보관함에서 상태를 즉시 표시한다. 실제 가치·숨겨진 결함은 기존 별도 가치 확인 정책을 유지한다.

## 사용자 후속 확정 — 판매자 가격 제안·파토 후 판매 유지

판매 채팅에서 플레이어도 가격을 제안한다. 구매자 답변은 수락·재제안·파토 중 하나이며, 대화와 파토는 행동 소모 없음이다. 실제 거래 확정에만 행동 1회를 적용한다. 제안 범위·횟수·답변 정책은 [판매 네고](../trading/marketplace/NEGOTIATION.md)에 구분해서 기록한다.

파토가 나도 해당 판매 글을 유지하고 그 구매자의 문의만 닫는다. 기존 문의는 계속 처리할 수 있고 모두 종료된 뒤에는 원래 글에서 새 문의를 기다린다. 명시적 취소·원래 기한 만료·실제 판매 성사에만 글이 종료된다.

현재 종료·상단 주간 이자는 [채무·자본금](../debt/INTEREST_AND_BANKRUPTCY.md)을 따른다. 체력·피로도는 더 이상 저장·표시·계산하지 않는다.

매물 가격 규모 상향은 개발자 초기 적용안이며 [카테고리·가격대](../items/CATEGORIES_AND_PRICES.md)와 `src/content/market.ts`를 함께 수정한다. 기존 물품·판매 글은 소급 변경하지 않는다.

사용자 후속 확정: 가치 확인·수리는 주간 행동 예산에 포함하지 않는다. 금전 비용·1회 제한·수리 성공률·경험치는 유지하며 시간·기한·추가 문의·사건은 진행하지 않는다.

고가 경매시장에는 일반 판매자 네고 대신 [입찰·낙찰 결제 정책](../markets/AUCTION.md)을 적용한다. 입찰·포기는 행동 소모 없음, 낙찰 결제와 수령만 행동 1회다. 보유 경매품 재판매는 기존 정가 위탁 판매를 사용한다.

일반 시장별 구매 흥정의 차이는 [시장별 전략과 공통 처리](../trading/bargaining/MARKET_STRATEGIES.md)를 따른다. 유리한 제안 방식은 양보에 영향을 주지만 합의를 보장하지 않는다. 실제 가격고정 판매자에게 할인은 적용하지 않는다.

최신 채무 정책: 의무 원금은 1주차 50,000원부터 매주 2배이며 남은 원금에 제한한다. 이번 주 원금 상환액을 인정하고, 남은 의무 금액을 먼저 납부한 뒤 남은 원금으로 이자를 계산한다. 의무 원금 또는 이자를 납부할 수 없으면 종료한다. 자세한 계산·납부 순서·저장 전환은 [채무 문서](../debt/INTEREST_AND_BANKRUPTCY.md)를 따른다.

후속 초기 구현: 일반 시장의 특별 매물(18%·최대 1개), 구매 기반 매입 감각 자동 성장, 고정 주간 수입 사업 구매를 추가했다. 특별 매물의 할인/소장품 가치·사업 금액·능력치 효과는 개발자 테스트 수치이며 세부 문서를 따른다. 기존 주당 20행동·100원 단위·주간 의무 원금/이자는 유지한다. 사업 수입은 납부 능력 검사 전에 한 번 지급한다.

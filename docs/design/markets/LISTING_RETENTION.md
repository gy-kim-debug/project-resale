# 시장 매물 유지와 추가 탐색

## 사용자 확정 방향 — 2026-11-13

구매할 수 있는 시장 매물의 유지 기간을 늘린다. 새 매물 탐색이 유효한 기존 매물을 통째로 지우지 않도록 한다. 물건의 원래 가격·숨은 상태·가치·흥정·채팅·관심 정보를 유지한다.

## 이번 적용 수치 — 개발자 기본 조정

- 새 일반 매물은 등장 시점부터 12행동 틱 동안 유지한다.
- 실제 판매자가 급처/이사 성향인 매물과 급처 특별 매물은 6행동 틱 동안 유지한다. 표시 태그는 판매자 주장일 수 있으므로 급처 태그가 있다고 반드시 짧은 기간인 것은 아니다.
- 최초 공급은 시장당 12개다. 명시적 탐색은 행동 1회를 쓰고 해당 시장에 새 매물 4개를 추가해 목록 앞에 배치한다. 공급이 적은 시장은 최소 12개가 되도록 보충할 수 있다.
- 새 생성은 시장당 60개 이내로 제한한다. 상한 때문에 아직 유효한 기존 매물을 밀어내지 않는다. 저장 검증의 전체 게시판 상한은 활성 6시장 × 60개(360개)로 확장하고, 중복 ID/잘못된 데이터의 거절은 유지한다.
- 다른 시장의 유효한 매물도 보존한다. 날짜 경계/정산에서는 만료분을 제거하고 시장별 최소 공급만 보충한다. 날짜 경계의 명시적 탐색도 별도로 새 4개를 공급하며 기존 물건을 재추첨하지 않는다.

## 만료·재접속

- 기한까지 유효하며 실제 게임 시간이 기한에 도달한 매물만 제거한다. 해당 구매 채팅은 기간 종료 기록으로 남고 다시 결제할 수 없다.
- 기존 저장에 있는 매물의 만료 시각은 그대로 읽는다. 재접속/탐색이 기한을 새로 시작하거나 무한 연장하지 않는다. 새로 등장하는 매물부터 위 수치를 적용한다.
- 주간 정산으로 남은 시간을 넘기면 그 시간만큼 기한도 경과한다. 그래도 기한이 남은 최근 매물과 구매 채팅은 다음 주에도 보존한다.
- 구매한 물건은 보관함 자산이므로 NPC 매물 기한이 지나도 사라지지 않는다. 플레이어의 판매 등록 글은 별도의 기존 8행동 정책이며 이번에 변경하지 않는다.
- 저장 스키마 버전/새 저장 필드는 추가하지 않는다. 매물 ID·가격·실제 가치·감정/수리 결과·태그 진위·판매자/흥정 상태·관심 목록은 기존 데이터를 유지한다.

## 구현

`content/listingTags.ts`의 기간, `content/markets.ts`의 최초/탐색/상한 수치를 공통 사용한다. `domain/engine.ts`의 board는 유효한 기존 물건을 복사해 보존하고 필요한 신규분만 만든다. 특별 매물 확률/효과는 신규분에만 적용하며 기존 매물을 특별 매물로 다시 뽑지 않는다. 시장 제보 이벤트도 같은 추가 탐색을 사용한다.

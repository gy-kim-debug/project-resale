# 부동산 다음 시장 후보 — 미확정

사용자 질문: 비행기 시장을 제거하고 부동산 다음에 어떤 시장이 좋을지 검토한다. 아래는 개발자 제안이며 어느 것도 구현하거나 사용자 확정으로 취급하지 않는다.

| 후보                        | 거래 대상                                        | 불확실성과 흥정 소재                   | 검토할 점                                                |
| --------------------------- | ------------------------------------------------ | -------------------------------------- | -------------------------------------------------------- |
| 사업체 매매시장 — 우선 추천 | 프랜차이즈 매장 묶음·소형 제조업체·호텔·물류업체 | 실제 매출·숨은 채무·거래처·브랜드 가치 | 사업 운영 없이 매입·실사·재판매만으로 진행할지 결정 필요 |
| 고가 경매시장               | 희귀 미술품·보석·골동품·수집품                   | 진위·출처·희귀성·감정가 차이           | 기존 수집품과 차별화하고 입찰 방식을 추가할지 결정 필요  |
| 대형 부동산시장             | 빌딩·물류센터·개발 부지                          | 권리 관계·공실·입지·숨은 하자          | 기존 부동산 시장과 품목·규모의 경계를 정할 필요          |

사업체 매매는 작은 물건에서 부동산을 거쳐 더 큰 자산으로 성장하는 흐름과 잘 이어진다. 고가 경매는 기존 물품 감정·확률적인 대박/손실 구조를 가장 많이 재사용할 수 있다. 대형 부동산은 현재 시스템을 확장하기 쉽지만 새 시장으로서의 차별성이 약할 수 있다.

10억–100억 원대는 검토할 수 있는 규모의 예시일 뿐 가격대·품목·해금·실사 비용·가치 판정은 미정이다. 사용자 선택 후 별도 확정 문서와 구현으로 진행한다.

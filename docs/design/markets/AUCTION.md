# 고가 경매시장

## 사용자 확정

비행기 시장을 제거한 뒤 부동산 다음 시장으로 고가 경매시장을 선택했다. 사업체 매매시장이나 대형 부동산시장은 추가하지 않는다.

## 초기 적용 정책 — 개발자 결정

- 시작가 1,000,000,000–10,000,000,000원(10억–100억 원). 사용자에게 제안했던 규모를 초기 설정으로 채택했으며 최종 밸런스 확정값은 아니다.
- 수집품 분류의 근현대 회화·천연 다이아몬드·희귀 도자기·고급 기계식 시계·앤티크 조각상·희귀 보석 목걸이를 공급한다. 시장당 8개 규칙을 유지한다.
- 가격 범위는 경매 시작가다. 경쟁 입찰로 낙찰가는 범위를 초과할 수 있으며 실제 가치·재판매가와도 다르다.
- 시장 선택·읽기·입찰·포기는 행동 소모 없음, 낙찰 대금 결제와 수령만 행동 1회다. 입찰 중에는 원화를 차감하거나 보관함 공간을 예약하지 않는다. 결제 시 현금·공간을 다시 확인한다.
- 보관함 가치·진위 확인은 기존 비용만 차감하며 날짜·행동·시장/사건/주간 납부 시점은 진행하지 않는다.

## 입찰 흐름

1. 시작가·현재 입찰가·공개 태그와 진행 대화를 본다. 진위·실제 가치·경쟁자의 한도는 공개하지 않는다.
2. 최소 입찰가·한 단계 더 높은 금액·두 단계 더 높은 금액 중 선택한다. 현금을 넘는 선택지는 비활성화한다.
3. 경쟁자의 미리 정한 한도 미만이면 경쟁자가 한 단계 더 높게 응찰한다. 한도 이상이면 플레이어가 낙찰받는다.
4. 낙찰 내용 확인 후 결제를 확정하면 낙찰가를 한 번 차감하고 물품을 수령한다. 즉시 구매나 일반 가격 흥정으로 입찰을 우회할 수 없다.
5. 플레이어는 입찰 또는 낙찰을 포기할 수 있다. 초기 버전에서는 포기 비용은 없으며 해당 매물은 다시 입찰하지 못한다.

입찰 간격은 시작가 5%를 100만 원 단위 올림한 금액이다. 경쟁자의 한도는 시작가 110–145% 미만을 입찰 간격에 맞춰 생성한다. 시작 시 한 번 저장하며 실제 가치와 독립이다. 양쪽 입찰가는 단조 증가하고 이 한도에서는 최대 6회 플레이어 입찰로 결론이 난다. 값과 판정 로직은 별도 콘텐츠 설정/순수 함수에 둔다.

화면을 닫거나 앱을 종료하면 진행은 멈추고 그대로 저장한다. 다른 실제 행동을 하면 공통 매물 기한이 경과한다. 낙찰 후 결제 전에도 기한 내 결제하지 않으면 매물이 만료된다. 주간 납부·필수 문의 응답·종료 상태의 기존 잠금은 우선한다.

## 태그·감정·재판매

종류·특징 태그 2개를 붙인다. 진위·한정판·희귀성 등 주장성 태그의 85% 사실 확률과 실제 속성 기반 가치 계산은 유지한다. 판매자와 네고하는 시장이 아니므로 급처·네고환영·가격고정 같은 판매 성향 태그는 붙이지 않는다.

구매 후 보관함에서 매입가와 확인한 가치를 비교한다. 가품·희귀품 결과는 기존 감정과 우편 기록으로 공개하며 사전 감정은 없다.

이번 버전의 경매 입찰은 NPC 출품작 매입에 적용한다. 보유품은 기존 정가 위탁 판매(자유 가격·구매자 협상) 또는 수집품 매입처로 재판매한다. 판매 글에는 출처 시장을 유지하되 위탁 판매를 별도 플레이어 출품 경매로 오인시키지 않게 표시한다. 플레이어가 출품하는 경쟁 입찰은 후속 검토다.

## 저장·호환·검증

`Item.auction`에 현재가·경쟁 한도·간격·라운드·진행 상태·대화를 저장한다. 낙찰 상태와 결제 상태는 보유품 이전으로 구분해 중복 결제를 거절한다. 입찰 금액의 과거 선택지 재전송·부족한 현금·포기 후 재입찰·미낙찰 구매를 원자적으로 거절한다. 정상 입찰에는 시간·현금·난수·보유품이 변하지 않는다.

기존 저장은 자산을 바꾸지 않는다. 새 시장을 탐색하거나 다음 날짜에 갱신하면 경매 매물을 공급한다. 새 게임은 처음부터 포함한다. 잘못된 경매 상태·금액·대화는 백업 검증에서 거절한다. 비행기 시장은 계속 폐기 상태다.

## 후속 조정

시작가·경쟁 한도·입찰 간격·진품/희귀품 분포·주간 이자 대비 수익은 플레이 후 조정한다. 경매 수수료·보증금·포기 페널티·예약 입찰·실시간 타이머·플레이어 출품 경매는 이번에 추가하지 않는다.

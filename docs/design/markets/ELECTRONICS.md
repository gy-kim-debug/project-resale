# 전자상가

## 확정 방향

독립 시장으로 운영하고 다른 시장과 구분되는 품목을 공급한다. 거래 규모가 커지는 시장 구조를 따른다.

## 현재 적용 범위

- 생성 판매자의 게시 가격: 800,000–12,000,000원(양 끝 포함).
- 가격대 구분: **기존 최저 진입 가격 유지·상한은 후속 콘텐츠 확장안 적용**. 사용자가 지정하지 않은 수치는 조정 가능한 콘텐츠 설정이다.
- 품목: 60종. 분류/전체 품목/개별 가격대는 [전체 가격표](PRODUCT_CATALOG.md)를 기준으로 한다.
- 매물 수: 12개. 가격·기한·흥정·숨겨진 사실은 [공통 정책](OVERVIEW.md)을 따른다.
- 개별 시장에 들어가거나 다른 시장으로 이동하는 것은 행동을 소모하지 않는다. 실제 구매는 행동 1회, 구매 후 가치·진위 확인과 수리는 행동 소모 없음이다. 확인·수리의 기존 원화 비용은 유지한다.

## 성장과 위험

현금이 충분해야 매입할 수 있다. 시장 이동에 별도 레벨 해금·입장료는 두지 않는다. 높은 시장은 품목과 가격 규모가 커지는 것이며 성공·수익을 보장하지 않는다.

다른 시장으로 옮겨도 진행 중인 흥정·보유 자산·판매 글은 유지한다. 현실의 소유권 이전·취득세·보험·운송을 새로 추가하지 않고 기존 한 번의 거래 행동으로 자산을 교환한다.

## 흥정 공략 — 개발자 초기 조정안

전자상가은 호가에 가까운 제안에 잘 반응하며 과도한 저가에는 조기 파토 위험이 있다. 구체적인 수치·판매 성향 예외·저장 규칙은 [시장별 흥정](../trading/bargaining/MARKET_STRATEGIES.md)을 따른다. 메뉴에는 공략 설명을 표시하지 않는다.

## 명칭/저장 호환 — 사용자 요청

표시 이름을 전자상가로 바꾼다. 저장 식별자 computers는 유지해 기존 시장 선택·보유품·등록 글·대화가 이어진다. 기존 저장된 컴퓨터 매물은 보존하고 새 생성/갱신부터 확장 목록을 사용한다. 디지털 종류의 거래 성격·무료 흥정/확인/수리·구매 행동·판매 대기 정책은 유지한다. 가격 상한과 품목은 후속 확장 정책을 따른다. 새 기기의 도트는 공개 상품명으로만 구분하며 실제 가치/진위/결함을 그림에 반영하지 않는다.

## 품목·케이스 확장

후속 사용자 요청에 따라 [품목 확장](../items/CATALOG_EXPANSION.md)과 [케이스](../items/CASES.md)를 적용한다. 아래 기록의 이전 초기 가격 상한보다 최신 전체 가격표를 우선한다. 기존 저장 물품은 유지한다.

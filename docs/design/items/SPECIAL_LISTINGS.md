# 특별 매물

## 사용자 확정

거래의 반복감을 줄이기 위해 특별 매물부터 추가한다. 복잡한 의뢰·묶음 관리·새로운 거래 절차를 추가하지 않고 기존 장터의 물건처럼 흥정하고 구매·확인·판매한다.

## 개발자 초기 조정안

- 일반 시장의 게시판을 생성/탐색할 때 시장당 18% 확률로 최대 1개를 특별 매물로 만든다. 일반 매물 8개 중 하나를 대체하며 무료나눔/경매에는 붙이지 않는다.
- **폐업 정리**: 게시 가격을 20% 낮추되 해당 시장 가격 범위를 지킨다. 실제 판매 성향과 유효 기간을 기존 급처처럼 2행동으로 정하고 진위·상태는 별도 유지한다.
- **소장품 출품**: 중고 장터·컴퓨터·악기시장에서 등장한다. 실제 진품이면 본래 기본/실제 가치를 2배로 보정하고 가품이면 보정하지 않는다. 게시가는 유지한다. 특성 태그의 사실 확률과 원래의 품질 불확실성은 유지한다.
- **미확인 특가**: 부동산 외 일반 시장에서 등장한다. 게시 가격을 30% 낮추되 범위를 지킨다. 상태·가품 여부는 기존 생성 결과를 유지하며 정상 작동을 보장하지 않는 판매자 설명을 붙인다.
- 할인해도 기존 가격보다 100원 이상 낮아질 수 있는 매물을 고른다. 소장품은 가격 대신 가치의 가능성이 특징이다. 어느 종류도 항상 이익을 보장하지 않는다.
- 일반 목록/상세/보관함의 공통 태그에 특별 표시와 종류 이름을 넣는다. 별도 공략창·자동 팝업·실제 가치 사전 공개는 없다.

확률·할인율·가치 보정은 콘텐츠 설정에 두고 추후 플레이 테스트로 조정한다. 이미 보유한 물품과 진행 중인 대화에 소급 적용하거나 다시 추첨하지 않는다. 특별 표시·가치·가격은 구매 후에도 저장과 백업에서 유지한다. 금액은 공통 100원 반올림을 사용한다.

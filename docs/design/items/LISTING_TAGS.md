# 장터 매물 해시태그

문서 상태: 구현 적용. 사용자 확정 방향과 개발자가 선택한 초기 밸런스 수치를 구분한다.

## 사용자 확정 방향

- 장터 매물에 해시태그를 붙여 어떤 물건인지, 진품·가품 관련 정보, 급처 여부 등을 표현한다.
- 태그를 단순 장식으로 쓰지 않고 가격·게시 기한·흥정·수요 등 실제 거래 시스템과 연결한다.
- 태그는 사실을 보장하지 않는다. 태그가 붙어 있으면 높은 확률로 해당 내용이 사실이지만, 틀릴 수도 있다.
- 예를 들어 `#한정판` 매물을 구매했는데 실제로는 일반판일 수 있다.
- 구체적인 사실 확률은 아직 확정하지 않는다.

선택 근거: 사용자가 태그 기획의 별도 문서 분리를 요청하고, 거래 효과 연결 제안을 지지했다. 이어서 “#한정판 태그가 있더라도 알고보니깐 한정판이 아니었떤거지. 하지만 태그가 들어가면 높은 확률로 사실인걸로”라고 지정했다.

## 태그와 실제 사실의 구분

장터에 표시하는 태그는 신뢰할 만한 단서지만 시스템의 확정 보증은 아니다. 실제 물품 속성·판매자 성향과 표시 태그를 구분해 설계한다. 확률은 우선 **해당 태그가 표시된 매물에서 그 내용이 사실일 확률**을 뜻한다. 태그가 없는 매물에는 해당 특성이 없다는 뜻이 아니며, 태그 없는 매물의 분포는 별도 미정이다.

예시:

| 표시 태그   | 사실인 경우                      | 사실이 아닌 경우                            |
| ----------- | -------------------------------- | ------------------------------------------- |
| `#한정판`   | 실제 한정판이다.                 | 일반판인데 한정판으로 올라왔다.             |
| `#정품주장` | 실제 진품이다.                   | 가품인데 정품으로 소개됐다.                 |
| `#급처`     | 판매자가 빨리 처분하려 한다.     | 급처라는 표현과 달리 급하게 팔 이유가 없다. |
| `#네고환영` | 흥정에 비교적 적극적인 판매자다. | 실제로는 가격을 잘 양보하지 않는다.         |

위 표는 확정 방향을 설명하는 예시다. 태그 이름과 전체 목록은 최종 확정 전이다. 잘못된 태그의 원인을 판매자의 고의적 기만으로만 한정하지 않는다. 착각·정보 부족·과장 등을 구분할지는 미정이다.

## 현재 적용 정책 — 개발자 초기 밸런스안

이번 적용 요청에 따라 아래 수치를 선택해 구현했다. 사용자가 개별 숫자를 확정한 것은 아니며 플레이 후 조정한다. 설정 원본은 `src/content/listingTags.ts`, 순수 로직은 `src/domain/listingTags.ts`다.

### 태그 구성과 사실 확률

유료 매물에는 종류·특징·판매 성향을 하나씩, 총 3개 표시한다. 무료나눔은 종류·특징 2개다. 종류 태그는 물품 카테고리와 일치하며 나머지 주장성 태그는 각각 85% 확률로 사실이다. 여러 주장성 태그의 사실 여부는 독립 판정한다.

| 구분                    | 현재 태그                                                 |
| ----------------------- | --------------------------------------------------------- |
| 종류 — 정확한 분류      | `#생활용품`, `#디지털기기`, `#가구`, `#수집품`            |
| 특징·진위 — 확률적 주장 | `#한정판`, `#단종품`, `#빈티지`, `#정품주장`, `#레플리카` |
| 판매 성향 — 확률적 주장 | `#급처`, `#이사정리`, `#가격고정`, `#네고환영`            |

특징 태그 추첨 가중치는 한정판·단종품·빈티지·레플리카 각 1, 정품주장 3이다. 판매 성향 4개는 동일 가중치다. 같은 분류에서 하나씩 선택하므로 가격고정과 네고환영 등이 동시에 붙지 않는다.

태그가 정품주장이면 실제 진품 확률 85%, 레플리카이면 실제 가품 확률 85%다. 다른 특징 태그에서는 진품 확률을 90%로 둔다. 한정판·단종품·빈티지 중 표시되지 않은 특성은 이번 초기 모델에서 추가 생성하지 않는다. 모든 특성이 자유롭게 겹치는 모델은 후속 확장이다.

### 사실과 실제 가치

실제 속성이 일반·진품이면 기준 가치 계수는 100%다. 실제 한정판 150%, 단종품 125%, 빈티지 115%, 가품 8%를 사용한다. 가품 계수가 우선한다. 표시 태그가 거짓이면 그 특징의 가치는 붙지 않는다.

여기에 기존의 희귀 구성 배율(일반 100%·희귀 150%·특별 400%)과 상태 계수(고장 18%·사용감 75%·양호 100%)를 적용한다. 새 매물의 가품 여부는 별도의 과거 10% 저가 판정 대신 실제 진위 속성으로 일원화한다. 수집품의 기존 생성 규칙에는 적용하지 않는다.

실제 가치가 높아지면 기존 시장 계수·카테고리 수요와 함께 재판매·구매 문의·매각처 기준 금액에 반영된다. 태그 자체가 별도의 일일 수요 급등을 발생시키지는 않는다. 한정판·진품이어도 상태나 매입 가격 때문에 손해를 볼 수 있다.

### 판매 사정과 게시 가격·기한

| 실제 성향              | 게시 가격                                                   | 유효 기간        |
| ---------------------- | ----------------------------------------------------------- | ---------------- |
| 급처                   | 기존 게시 가격을 90%로 조정, 1,000원 단위 내림·최소 1,000원 | 생성 후 행동 2회 |
| 이사정리               | 기존 게시 가격 유지                                         | 생성 후 행동 2회 |
| 일반·가격고정·네고환영 | 기존 게시 가격 유지                                         | 생성 후 행동 3회 |

`#급처`·`#이사정리`가 거짓이면 일반 판매자라 해당 가격·기한 혜택이 없다. 급처여도 전체 게시판의 최저가나 수익을 보장하지 않는다. 무료나눔은 0원·일반 기한을 유지한다. 이사정리의 묶음 거래는 아직 구현하지 않는다.

### 판매 사정과 흥정

현재 [여러 차례 구매 흥정](../trading/purchasing/NEGOTIATION.md)에 실제 성향별 프로필을 연결한다. 태그가 아니라 실제 판매 성향으로 판정한다.

| 실제 성향 | 최소 수락가 — 게시가 대비 | 인내심 | 가격 고수 확률 | 양보 폭 — 제안 간격 대비 |
| --------- | ------------------------- | ------ | -------------- | ------------------------ |
| 일반      | 78–90% 미만               | 4–6회  | 25%            | 15–30% 미만              |
| 급처      | 65–78% 미만               | 5–6회  | 10%            | 25–40% 미만              |
| 이사정리  | 72–85% 미만               | 4–6회  | 15%            | 20–35% 미만              |
| 네고환영  | 70–84% 미만               | 5–6회  | 10%            | 20–35% 미만              |
| 가격고정  | 100%                      | 4회    | 100%           | 없음                     |

`#가격고정`이 거짓이면 실제 네고환영, `#네고환영`이 거짓이면 실제 가격고정 성향이다. 태그만으로 흥정 버튼을 없애지 않고 실제 반응으로 성향을 드러낸다. 실제 가격고정은 게시 가격을 유지한다. 인내심 도달 시 최종 가격 또는 파토, 흥정은 행동 소모 없음·실제 구매만 행동 1회라는 기존 흐름은 유지한다.

최소 수락가·인내심은 첫 제안에 한 번 정해 저장한다. 기존 저장에 이미 흥정 값이 있으면 새 프로필로 다시 뽑지 않는다.

## 구매 전후 정보 공개와 UI

매물 목록·상세와 보관함에서 원래 매물 태그를 표시한다. 태그에는 확실성 배지·사실 여부 색상·확률 설명을 붙이지 않는다. 매물 화면에서는 `checked`가 있더라도 실제 속성을 공개하지 않는다.

구매 전 상태 확인은 추가하지 않는다. 기존 [가치 정보](../trading/purchasing/VALUE_INFORMATION.md)와 [결함 확인](../trading/purchasing/DEFECT_DISCOVERY.md) 원칙을 유지한다. 구매 후 상태는 바로 볼 수 있지만, 실제 진위·특징은 가치 확인 후 `확인 결과`에 표시한다.

- 진위는 `진품` 또는 `가품`으로 표시한다.
- 한정판 주장이 틀렸으면 `일반판 · 한정판 아님`으로 표시한다.
- 단종품·빈티지도 원래 태그와 실제 확인 결과를 구분한다.
- 판매자의 급한 사정이나 흥정 성향은 물품 감정으로 공개하지 않고 거래 반응으로 드러낸다.
- 감정 결과는 우편 알림에도 남긴다. 가치 확인은 기존처럼 비용만 들고 행동은 소모하지 않는다.

```text
휴대용 게임기 판매합니다
180,000 원
#디지털기기  #한정판  #급처
```

확률표·공략 설명은 게임 메뉴에 추가하지 않는다. 태그 필터는 이번 범위에서 제외한다.

## 생성·저장·기존 진행 호환

- `Item.listing`에 표시 태그와 실제 속성을 구분해 저장한다. 실제 속성은 매물 생성 시 한 번 정하며 화면 이동·재접속·감정·수리로 다시 뽑지 않는다.
- 새 장터 매물과 무료나눔부터 적용한다. 물건 수집에는 판매자 태그를 생성하지 않고 기존 수집 가치 분포를 유지한다.
- 기존 게시판·보유품·매입가·판매 글·흥정 값은 소급 변경하지 않는다. 태그 정보가 없는 기존 물품은 종류 태그만 표시하며 새 매물 탐색 또는 날짜 변경 후 생성되는 매물에 전체 태그가 붙는다.
- 자동 저장·JSON 백업/복원에 포함하고 잘못된 태그 ID·모순된 태그 분류·잘못된 실제 속성 형식은 저장 검증에서 거절한다.
- 표시 태그를 수정해 실제 가치를 다시 계산하는 방식은 사용하지 않는다. 저장된 실제 가치와 실제 속성을 유지한다.

## 후속 조정·확장 후보

- 85% 사실 확률과 태그 추첨 가중치·가격·가치·흥정 수치의 플레이 밸런스.
- 미표시 특성의 독립 생성, 여러 희귀 속성의 조합, 판매자 신뢰도와 태그 간 상관관계.
- 보증서 포함·진위 미확인 등 추가 태그, 판별 불가·추가 감정 단계.
- 태그 필터·묶음 거래·사건 연결. 현재 구현된 기능으로 취급하지 않는다.

## 전문 시장 확장

[시장별 정책](../markets/OVERVIEW.md)에 따라 악기·자동차·부동산·항공기 종류 태그를 추가했다. 부동산은 특징 태그를 권리정상 주장으로 한정하고 실제 사실에 따라 권리 정상/권리 하자를 공개한다. 차량·항공기는 정품/레플리카 표현을 서류정상/서류문제로 바꾸고 한정판·빈티지도 한정모델·구형으로 표시한다. 주장성 태그의 사실 확률 85%와 가치 계산 원칙은 유지한다. 급처 게시가에도 시장별 하한을 적용한다.

흥정 프로필 표는 판매 성향의 기준값이다. [시장별 흥정 설정](../trading/bargaining/MARKET_STRATEGIES.md)이 수락가 범위·인내심·고수·양보에 결합된다. 실제 가격고정 성향의 게시가 100% 하한과 고수 확률 100%는 어느 시장에서도 유지한다.

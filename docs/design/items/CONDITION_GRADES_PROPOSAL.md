# 물품 등급 도입 검토 — 미확정 제안

## 사용자 의견

가치 확인 결과가 작고 눈에 띄지 않는다. 결과 구조/효과를 바꾸거나 SSS, SS, S, A, B, C, D, E, F처럼 물품 상태 등급을 표시하고 등급별 가격을 정하는 방향을 제안했다. **등급의 기준은 아직 정하지 않았다.**

## 이번에 적용하는 결과 UI

- 확인 후 물품 상세 상단의 큰 결과 카드로 실제 가치를 강조한다.
- 매입가 대비 실제 가치 차이, 매입가, 현재 시세를 분리한다. 이번에 지불한 확인 비용도 함께 표시한다.
- 기존에 확정된 상태(양호/사용감/고장 및 품목별 표시), 진품·가품/권리·서류 확인, 숨은 결함을 크게 보여준다.
- 결과는 물품 화면에 남으며 확인/닫기 버튼을 누르도록 강제하지 않는다. 새 결과에는 짧은 등장·빛 효과를 주고 동작 줄이기에서는 효과를 끈다.
- 기존 비용·행동·가격 계산은 유지한다. 이번에는 임의의 SSS 등급이나 등급 계수를 실제 게임에 넣지 않는다.

## 추천하는 등급의 의미 — 제안

등급은 **상태**를 나타내고, 희귀도와 진위는 별도 태그로 유지하는 쪽을 추천한다. 그러면 상태가 매우 좋은 저가 물품과 상태가 나쁜 고가 물품을 직관적으로 비교할 수 있다. SSS 전기 포트가 B 중고차보다 비싸야 하는 구조로 만들지 않는다.

가격은 ‘품목 기준가 × 상태 계수 × 진위/권리 보정 × 시장 보정’ 형태로 검토한다. 현재의 상태 가격 보정에 등급을 중복 곱하는 것이 아니라, 기준이 정해지면 상태 보정을 등급 계수로 대체하는 방향이다. 기존 가치 상한·희귀 확률을 다시 검토하지 않고 무작정 올리지 않는다.

## 후보 평가 요소 — 미확정

- 작동/사용 가능 여부.
- 외관 마모·파손.
- 기본 구성품의 완전성.
- 수리·복원 여부와 검증 상태.
- 품목별 상태 특성: 전자기기는 작동/부품, 악기는 연주 가능성, 자동차는 정비, 부동산은 설비 상태 등.

가품/권리 문제는 상태 점수와 별도로 표시하고 가격에 반영하는 안을 추천한다. 미개봉·한정판 태그만으로 최고 상태를 확정하지 않는다. 감정 전에는 등급을 미확인으로 두는 안이 기존의 정보 불확실성과 맞는다.

## SSS~F를 유지할 경우의 설명 후보

| 등급 | 설명 후보 — 확정 아님                  |
| ---- | -------------------------------------- |
| SSS  | 검증된 상태가 최상이며 구성도 완전함   |
| SS   | 매우 우수하며 사소한 단점만 있음       |
| S    | 상태가 좋고 사용상 문제가 없음         |
| A    | 정상 사용 가능, 가벼운 흔적            |
| B    | 일반적인 사용감                        |
| C    | 마모가 뚜렷하거나 일부 구성이 부족함   |
| D    | 정비·복원이 필요한 부분이 있음         |
| E    | 중요한 기능/상태에 문제가 있음         |
| F    | 정상 사용이 어렵고 부품/잔존 가치 위주 |

현재 데이터는 상태 3종 중심이므로 이 정보만으로 9등급을 나누면 근거 없는 세분화가 된다. 먼저 평가 요소를 어떤 데이터로 생성/확인할지 정해야 한다. 단순함을 우선하면 처음에는 S/A/B/C/D처럼 적은 등급으로 시작하는 대안도 있다.

## 다음에 결정할 사항

1. 상태 등급과 희귀도를 분리할지, 종합 가치 등급으로 할지.
2. 9등급을 모두 사용할지, 적은 등급으로 시작할지.
3. 각 평가 요소의 기준과 품목별 차이.
4. 등급별 가격 계수와 등장 비율.
5. 수리 후 등급 변화와 가품/권리 문제의 처리.
6. 기존 저장 물품은 유지할지, 어떤 근거로 등급만 부여할지.

수치·등장 확률·수리 상승량·기존 저장 재평가 정책은 확정하지 않는다.

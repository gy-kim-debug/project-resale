# 물품 상태 등급·수리 — 확정 규칙과 구현 정책

## 사용자 확정 사항

사용자 일괄 선택: **A1 B1 C1 D2 E1 F1 G1 H2 I1 J1 K1 L2 M2 N1 O2 P1**. 아래 신규 규칙은 신규 생성 물품에 적용한다. 기존 저장 물품의 가격·상태·수리 이력은 유지한다.

## 상태 등급과 가격

등급은 물건의 상태다. 품목마다 B등급 기준가는 다르며, 같은 등급이라고 같은 가격이 아니다. 작동 여부·외관·구성품을 종합해 등급 하나와 짧은 설명으로 표시한다. 품목에 맞춰 작동을 연주·운행·설비 사용 가능 여부 등으로 해석한다.

| 등급 | 상태                                           | B등급 기준가 대비 상태 배율 |
| ---- | ---------------------------------------------- | --------------------------- |
| SSS  | 새것에 가까운 최상 상태, 정상 작동·구성품 완전 | 150%                        |
| S    | 매우 좋은 상태, 미세한 사용 흔적               | 125%                        |
| A    | 가벼운 마모가 있으나 정상 사용 가능            | 110%                        |
| B    | 뚜렷한 사용감이 있으나 정상 사용 가능          | 100%                        |
| C    | 일부 기능·구조 문제 등 손상이 있으나 수리 가능 | 60%                         |
| F    | 복구 불가능, 판매·수리 불가, 폐기 대상         | 0원                         |

- 희귀도·진위는 상태와 분리한다. 가품이라고 자동으로 F가 되지 않는다.
- 기존 상태 배율을 새 배율로 교체하며 중복 적용하지 않는다. 태그·희귀·사례 보정은 기존 가격 경로에서 유지한다.
- 실제 가치 = 기존 보정 후 B상태 가치 × 등급 배율. 최종 실제 가치는 생성 시 고정한 품목 기준가(`valuationReference`)의 최대 3배다. F는 보정보다 우선해 0원이다.
- 수리비의 기준가는 보정 후 가치·매입가가 아닌 `valuationReference`다.
- 시장 변동은 기존처럼 현재 시세에 별도로 반영한다. 현재 시세에도 기존 상한을 유지한다.
- 금액은 공통 함수로 100원 단위 반올림한다. 생성 기준가와 숨은 상태는 확인·수리 견적을 볼 때 다시 뽑지 않는다.

## 등급 등장 확률

일반 매물 확률은 사용자 확정이다. 위험·특별 매물은 별도 분포를 사용하도록 선택했고, 아래 구체적인 별도 확률은 일괄 선택 H2에 따라 개발자가 작성한 초기 조정값이다. 대박·진품·희귀 확률과 별개다.

| 등급 | 일반 — 사용자 확정 | 위험 — 개발자 초기값 | 특별 — 개발자 초기값 |
| ---- | ------------------ | -------------------- | -------------------- |
| SSS  | 1%                 | 1%                   | 3%                   |
| S    | 7%                 | 3%                   | 17%                  |
| A    | 22%                | 11%                  | 30%                  |
| B    | 40%                | 30%                  | 30%                  |
| C    | 25%                | 40%                  | 17%                  |
| F    | 5%                 | 15%                  | 3%                   |
| 합계 | 100%               | 100%                 | 100%                 |

개발자 분류: 일반 매물 중 미검수·본품만·높은 주행거리·오래된 인테리어 사례는 위험 분포를 사용한다. 미확인 특가는 위험 분포, 폐업 정리·소장품 출품은 특별 분포다. 특별 전환 시에는 최종 분포를 적용한 뒤 구매·확인 과정에서 재추첨하지 않는다.

## 정보 공개와 결과 UI

- 구매 전에는 기존 판매자 설명·태그·채팅을 사용하고 정확한 등급은 공개하지 않는다.
- 구매 후 가치 확인 시 등급·결함·실제 가치와 수리 가능한 물품의 난이도·예상 회복 등급·비용·최종 성공률을 공개한다.
- 큰 결과 카드에 등급과 실제 가치를 강조하고 매입가·차액·현재 시세·지불한 확인 비용을 구분한다. 결과는 물품 화면에 남는다.
- 짧은 등장·빛 효과를 사용하고 동작 줄이기 설정에서는 끈다. 확인/닫기 버튼을 강제하지 않는다.

## 수리·보수·복원

- **B·C만 수리 가능, 물건당 한 번**이다. 성공·실패 후 모두 추가 시도할 수 없다. A·S·SSS는 수리하지 않으며 F는 복구 불가능하다.
- 판매 등록 중에는 수리할 수 없다. 글을 내린 뒤 수리해야 한다.
- 난이도는 상태 등급과 별개로 생성 시 쉬움·보통·어려움 중 무작위 지정한다. 개발자 초기값은 각각 1/3이다. 난이도에 맞는 시장별 고장·손상 설명을 사용한다.
- 회복 한계는 물건별로 고정하며 최고 A다. 영구적인 마모·손상이 남는 C물품은 B까지만, 복구 가능한 경우 A까지 회복한다. B물품은 성공하면 A로 회복한다.
- 회복 한계의 개발자 초기값: C 중 B까지 35%, A까지 65%. 난이도와 회복 한계는 별도 데이터다.
- 수리 전 비용·성공률·성공 시 등급과 가치를 표시한다. 수리는 행동을 소모하지 않는다.
- 부동산은 보수, 경매품은 복원으로 표시하되 같은 계산 규칙을 사용한다. 부동산도 F면 판매 불가능한 폐기 대상으로 처리한다. 토지 잔존 가치 등 별도 현실 모델은 추가하지 않는다.

| 난이도 | 기본 성공률 | B기준가 대비 비용 | 해당 시장 Lv.10 성공률 |
| ------ | ----------- | ----------------- | ---------------------- |
| 쉬움   | 80%         | 5%                | 95%                    |
| 보통   | 60%         | 10%               | 80%                    |
| 어려움 | 30%         | 15%               | 50%                    |

최종 성공률 = min(95%, 기본 성공률 + 해당 시장 레벨 × 2%p).

성공·실패와 관계없이 표시한 비용을 차감한다. 실패했을 때 80%는 등급 유지, 20%는 한 단계 하락한다. 수리 가능한 B·C 기준 B→C, C→F다. 능력치는 성공률에만 영향을 주며 수리비·회복 한계·조건부 하락 확률에는 적용하지 않는다. 예: 성공률 70%라면 전체 기준 성공 70%, 실패 유지 24%, 실패 하락 6%다.

F는 자동 제거하지 않는다. 보관함에서 무료·행동 소모 없이 직접 폐기한다. 개발자 실행 정책으로 짧은 실행 취소 토스트를 제공하며, 다른 행동을 진행하면 이전 폐기를 되돌릴 수 없다.

## 시장별 능력치와 경험

[능력치 문서](../character/ABILITIES.md)와 함께 적용한다.

- 중고 장터/전자상가/악기시장/중고차시장/부동산 시장/고가 경매시장별 능력을 분리한다.
- 물품의 최초 생성 시장을 유지한다. 무료나눔·수집품은 중고 장터 귀속이다.
- 구매 완료 2, 일반·경매 판매 완료 2, 가치 확인 완료 2, 수리 성공 4·실패 2 경험치를 지급한다.
- 무료나눔 수령·물건 수집 자체와 즉시 판매에는 시장 경험치를 지급하지 않는다. 이후 확인·수리·일반 판매에는 지급한다.
- 개발자 경계 정책: 실제 완료된 특별 개인 거래도 일반 거래와 동일하게 판매 경험치를 지급한다. 문의·흥정·등록·취소·실패한 명령·폐기에는 지급하지 않는다.
- 시장 능력치는 Lv.0부터 최대 10. 레벨업 필요 경험치 20→30→40…으로 증가하며 Lv.10 누적 650이다. 레벨당 수리 성공률 +2%p다. 최대 레벨 이후 경험치는 650에서 멈춘다.
- 이름은 생활 수리/전자 수리/악기 정비/차량 정비/부동산 보수/경매품 복원으로 표시한다.
- 공통 수리 기술을 시장별 능력으로 교체하며 기존 거래 감각·감정 지식·매입 감각은 유지한다. 수리 보너스를 중복 적용하지 않는다.

## 기존 저장 호환과 실행 정책

- 새 선택 이전의 물품에는 새 등급 필드를 소급 부여하지 않는다. 가격·상태·확인 여부·수리 이력을 그대로 유지하고 기존 상태 표시·수리 규칙을 사용한다.
- 과거 공통 수리 경험은 통계에 보존하되 새 시장 경험으로 임의 분배하지 않는다. 새 시장 경험은 0부터 시작한다. 기존 물품을 이후 거래·확인·수리하면 해당 시장 경험치를 얻는다.
- 기존 게시판 물품도 보존한다. 새 생성·갱신 이후부터 새 등급 물품이 등장한다.
- 숨은 등급·난이도·회복 한계는 생성 시 저장한다. 수리 결과는 실행 시 판정하고 연출 전에 즉시 저장한다. 새로고침으로 같은 수리를 재실행할 수 없다.
- 명령 검증 실패 시 원본 상태·현금·난수·경험치를 바꾸지 않는다. 가치 확인·구매·판매는 완료 상태를 통해 중복 경험 지급을 막는다.
- 새 데이터의 등급·수리 메타데이터와 시장 경험 범위를 저장 검증에 포함한다.

## 후속 조정

남은 필수 기획 결정은 없다. 개발자 초기값으로 구분한 위험·특별 분포, 무작위 난이도 분포, 회복 한계 비율·손상 설명은 플레이 결과로 조정한다. 새 영구 성장·추가 시장·수리 재시도 시스템은 이번 범위에 추가하지 않는다.

# 품목·분류·가격대 확장

## 사용자 요청

카테고리·품목·가격을 크게 늘리고 다양한 매물 케이스를 추가한다.

## 이번 적용 — 조정 가능한 콘텐츠안

- 활성 품목을 48종에서 240종으로 늘린다. 중고 장터 48 / 전자상가 60 / 악기 36 / 중고차 36 / 부동산 30 / 경매 30종이다.
- 기존 경제 계산용 종류(생활·디지털·가구·수집품·악기·자동차·부동산)는 유지하면서 36개 세부 카테고리를 추가한다. 장터 필터와 품목 정보에 사용한다. 카테고리별 수요·수리·희귀성 계산은 기존 종류의 설정을 따른다.
- 각 품목에 별도의 최저/최고 게시 가격을 둔다. 전기 포트와 커피머신, 노트북과 연산 워크스테이션 등을 같은 시장 가격 범위 전체에서 균일하게 뽑지 않는다.
- 시장별 최저 진입 가격은 유지하고 상한을 전자상가 1,200만원 / 악기 5,000만원 / 중고차 3억원 / 부동산 50억원 / 경매 500억원까지 확장한다. 중고 장터는 1만–50만원이다. 품목별 정확한 범위는 [전체 가격표](../markets/PRODUCT_CATALOG.md)를 기준으로 한다.
- 시장마다 12개 유료 매물을 품목 중복 없이 생성한다. 첫 매물은 그 시장의 최저 가격에 진입할 수 있는 품목이다. 무료나눔은 기존 확률로 별도 등장한다. 무료나눔을 확정 제공하지 않는다.
- 같은 품목에 [24개 케이스](CASES.md) 중 적용 가능한 사례를 부여한다. 케이스/진위/희귀성/상태/호가를 함께 조합하므로 동일 품목도 매번 같은 거래가 아니다.
- 물건 수집과 무료나눔은 중고 장터의 저가 품목 풀에서 생성한다. 물건 수집은 항상 발견하고 대부분 낮은 실제 가치를 갖는 기존 정책을 유지한다. 저가 물건을 모두 같은 '수집한 생활 잡화'로 바꾸지 않는다.
- 새 품목은 도감에 연결하고 세부 분류·품목별 참고 시세·특징을 보여준다. 케이스는 품목 안의 변형이며 도감 항목 수를 인위적으로 곱하지 않는다. 케이스별 해금이나 보상은 추가하지 않는다.
- 신규 품목 전부에 공개 이름/분류 기반 도트를 연결한다. 텐트·자전거·라켓·피아노·관악기·드럼·드론·프린터·상용차·건물·토지 등의 모티프를 추가한다. 진위·실제 가치·결함으로 그림을 바꾸지 않는다.

## 저장과 기존 규칙

기존 물건·게시글·문의·협상·해금·현금·채무는 재평가하거나 초기화하지 않는다. 세부 분류/케이스가 없는 저장도 읽는다. 기존 매물은 유지하고 새로 생성하는 매물부터 확장 콘텐츠를 적용한다. 이전 단계별 품목은 기존 획득 기록이 있을 때만 도감에 표시한다.

읽기·시장 이동·도감·흥정·가치 확인·수리의 행동 비용과 원화 비용 정책은 그대로다. 주당 20행동, 주간 의무 원금/이자, 사업 수익도 변경하지 않는다. 고가 경매의 게시 가격 범위는 시작가이며 낙찰가는 초과할 수 있다. 확장 후 경제 난이도는 플레이를 통해 추가 조정할 수 있다.

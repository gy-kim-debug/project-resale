# 매물 케이스

## 목적과 공개 정보

이름만 다른 상품을 늘리는 대신 같은 품목도 구성·보관·이력·출품 사정이 다른 사례로 생성한다. 게시글의 케이스 태그와 판매자 문장으로 관찰할 수 있다. 미개봉이나 자료 동봉도 정상 작동·진품을 보증하지 않으며 기존 진위/해시태그 사실 확률은 유지한다. 실제 상태·결함·개별 가치는 구매 후 확인하는 기존 흐름을 따른다.

## 적용 사례

- 일반 매물
- 휴대 가능한 물품: 풀구성, 본품만, 미개봉 보관품, 매장 전시품, 구형 모델, 장기 보관, 외관 사용 흔적, 추가 구성, 정비 이력, 작동 미확인, 매장 잔여 재고
- 자동차: 정비 기록 보유, 주행 많은 차량, 저주행 차량, 법인 차량 정리
- 부동산: 최근 수선, 노후 인테리어, 장기 공실, 접근성 좋은 입지
- 경매: 유산 컬렉션, 자료 동봉, 개인 장기 소장, 보존 처리 이력

종류/시장에 맞는 사례만 가중 추첨한다. 예를 들어 부동산에 미개봉 상자나 차량 주행 이력이 붙지 않는다. 정확한 수치와 가중치는 [콘텐츠 가격표의 케이스 설정](../markets/PRODUCT_CATALOG.md#매물-케이스-설정)에 기록한다. 수치는 이번 확장을 위한 개발자 초기 조정안이다.

## 계산과 수명

- 케이스는 생성 때 한 번 선택해 caseId로 저장한다. 독립된 결정적 추첨이므로 무료 화면 열기/구매/감정/수리/백업 시 다시 뽑지 않는다.
- 케이스의 품질 이동을 기존 상태 생성 롤에 적용한다. 실제 가치는 기존 종류·진위·희귀성 기준 가치에 케이스 가치 배율과 상태 배율을 적용한다. 정수 원화/100원 반올림 공통 함수를 사용한다.
- 게시 가격에는 케이스 게시가 배율과 기존 판매자 급처 효과를 반영하되 품목의 최저/최고 게시 가격을 벗어나지 않는다. 첫 진입 매물은 시장 최저가를 유지한다. 특별 매물 할인도 품목 최저 가격을 지킨다.
- 수리로 상태를 회복해도 구성·연식·입지 같은 케이스 차이까지 지워지지 않는다. 기존 물건의 base/value를 로드 시 재계산하지 않는다.
- 특별 소장품의 가치 배율은 최종 base에서 상태 가치를 다시 계산해 중간 100원 반올림 누적으로 생기는 오차를 방지한다. 새로 생성되는 특별 매물에만 적용한다.
- 소유권 서류 처리·실제 차량 주행·부동산 임대 수입 같은 별도 시스템을 추가하는 것은 아니다.

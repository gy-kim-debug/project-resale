# 물품 카테고리별 거래 성격

## 사용자 방향

숫자 규모만 커지는 반복에서 벗어나 기존 거래 안에 물품별 판단을 만든다. 모바일 조작·공통 네고·감정·수리·판매 과정은 유지한다. 이번 첫 적용은 활성 7개 카테고리의 공통 성격이며 모든 개별 상품에 별도 규칙을 붙이지는 않는다. 세부 수치는 개발자 초기 조정값이다.

| 종류   | 중심 선택                       | 정상 기준 가치 보정 | 시세 대비 문의 확률 배율 | 고장/사용감/양호 | 사용감/고장 가치 잔존 | 감정비 | 수리비 | 무작위 희귀 배수 상한 |

## 적용 원칙

- 기본 가치는 기존 시장 기준 `게시 기준가 / 55%`에 위 가치 보정을 적용한 뒤 진위/특성/희귀 보정을 적용한다. 생활만 낮은 마진을 두며 시장별 게시 가격 범위는 유지한다. 무료나눔/수집의 기존 CATEGORY_PRICING 기준 값에는 시장 기준 85%를 중복 적용하지 않는다.
- 상태 분포·잔존 가치·희귀 보정은 새로 생성하는 물품에 적용한다. 이미 보유한 물품의 상태/base/value·매입가·게시가를 다시 추첨하거나 계산하지 않는다.
- 수집품의 진품 특성 배수는 한정판 2배·단종 1.5배·빈티지 1.4배, 가품은 5%로 설정한다. 다른 종류는 기존 1.5/1.25/1.15배와 가품/서류/권리 문제 8%를 유지한다. 태그가 사실일 확률 85%는 바꾸지 않는다. 희귀 배수는 특성 배수와 별도이며 높은 이익을 보장하지 않는다.
- 문의 확률은 현재 가격/시세로 구한 기존 확률 × 카테고리 배율이며 최소 1%, 최대 95%다. 할인·정상가·고가의 순서를 유지하고 값이 같거나 매각이 확정되지는 않는다. 첫 조회 2행동·재조회 2행동·글 8행동은 공통이다.
- 감정비는 보유 물품 base의 비율에 기존 감정 레벨 절감을 적용한다. 수리비도 base 기준이다. 감정 최소 100원·수리 최소 300원·100원 반올림과 수리 성공률/경험을 유지한다. 기존 보유품에도 현재 비용과 수요 규칙은 적용한다.
- 수리 성공은 현재 물품 base를 회복한다. 가품을 진품으로, 서류/권리 문제를 정상으로 바꾸지는 않는다.
- 자동차/부동산의 물리 하자는 각각 정비/설비 하자로 표현한다. 별도 서류 게임·계약·배송·보관료·크기별 슬롯은 추가하지 않는다. 비행기 시장은 복구하지 않고 과거 보유 항공기는 기존 공통 규칙을 따른다.
- 행동 비용·즉시 판매 60%·채무·사업은 유지한다. 실제 가치/상태는 구매 후 확인하며 생존 수치로 물품 가치나 거래 확률을 보정하지 않는다. 게임 메뉴에 공략 설명창을 추가하지 않는다.

## 검증과 추후 조정

실제 엔진의 생성 분포·매각 대기·수리/감정 비용과 거래 진행을 비교한다. 새 수치로 모든 종류가 항상 이익이 되는지/항상 손해가 되는지 단정하지 않는다. 시장별 개별 물품 성격은 이 공통 카테고리의 플레이 피드백 이후 확대한다.

생활용품의 낮은 마진은 같은 상태·특성의 정상 기준 가치에 대한 보정이다. 고장품이 더 많고 수리로 회복하는 전자제품의 수리 전 중앙값보다 반드시 낮다는 뜻은 아니다. 가구·악기·부동산의 상태별 잔존율과 각 종류의 수리비가 달라 같은 수리 버튼이라도 손익이 달라진다.

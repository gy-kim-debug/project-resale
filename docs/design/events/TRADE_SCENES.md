# 도트 대화 이벤트 8종 — v1

## 사용자 확정

- 제안한 이벤트들을 먼저 적용한다.
- 이벤트는 상단 도트 캐릭터 연출과 하단 대화로 진행한다. 터치·클릭으로 다음 대사, 결정 지점에는 선택지를 표시한다.
- 긴 메인 스토리는 시작과 엔딩에만 둔다. 아래 사건들은 개별 거래 사건이다.
- 직접 입력 없이 선택지를 사용한다. 실제 행동이 필요한 선택에만 번개 아이콘을 표시한다.

이름표 사건은 기존 ‘구매 전 상태 확인 없음’ 규칙을 바꾸지 않는다. 판매자의 안내는 감정 결과가 아니며 태그의 진위나 숨겨진 실제 가치를 보장하지 않는다. 묶음의 두 번째 물건도 기존 시장의 실제 매물로, 거래가 성사되면 두 매물이 함께 게시판에서 제거된다. 새 아이템을 무한 생성하지 않는다.

## 빈도와 조건

- 거래 전 후보 발생률은 **24%**, 지난 사건 완료 지점에서 **3행동 틱** 이상 경과해야 다시 후보가 된다.
- 무료나눔과 경매 결제에는 일반 구매 전 사건을 넣지 않는다. 경매의 별도 입찰 규칙을 유지한다.
- 발생 가능한 구매 사건 중 아직 보지 않은 종류를 우선한다. 이를 다 본 후에는 재발생 가능하다.
- 행동 후 단골 연락은 이전에 실제로 거래한 판매자의 물건을 보유하고 해당 종류 부탁을 아직 받지 않은 경우, 안정된 별도 판정에서 **18%**.
- 그 연락이 발생하지 않으면 경쟁자 매입 제안을 **12%**로 판정한다. 수락한 부탁 종류를 보유했다면 **35%**로 판정한다.
- 구매 문의 응답·정산이 급한 상황에는 행동 후 새 사건을 겹치지 않는다. 주간 행동을 모두 쓴 뒤에는 새 매입 제안을 만들지 않는다.
- 한 번에 하나의 장면만 표시한다. 도입·엔딩과 일반 거래 사건이 겹치지 않는다.
- 사건용 안정 해시를 사용해 경제 난수를 추가로 소비하지 않는다. 대화를 누르거나 저장을 다시 읽어서 같은 거래 사건을 재추첨하지 않는다. 일반 거래·다음 행동으로 게임 상황 자체가 변하면 후보도 달라질 수 있다.

24%·18%·12%·35%, 할인 비율, 매입 비율은 사용자 확정 밸런스가 아닌 **첫 적용 값**이다. 반복 피로와 수익 영향을 보고 조정한다.

## 행동과 결제

- 구매 버튼을 눌러 사건이 시작된 시점에는 결제·수령·행동 처리를 하지 않는다.
- 읽기·설명 더 듣기·취소·단골 부탁 수락만으로는 행동을 소모하지 않는다.
- 구매·판매를 선택할 때 기존 거래 규칙으로 한 번만 처리한다. 묶음 구매도 1행동.
- 실제 가치·상태·진위·기존 가치 상한을 사건에서 재추첨하거나 덮어쓰지 않는다.
- 지불 금액과 보관함 여유를 최종 선택 때 다시 검사한다. 실패하면 장면과 자산을 그대로 유지하고 토스트를 띄워 다른 선택이나 취소가 가능하다.
- 주간 정산 미납과 기존 엔딩 판정을 계속 적용한다. 특별 매입도 행동이 없으면 실행할 수 없다.
- 거래 결과는 기존 750ms 행동 연출을 사용하고, 사건 대화에는 자동 제한 시간을 두지 않는다.

## 저장·호환

- 사건 종류·대사 위치·대상 매물/문의·합의 금액·후속 구매/판매 명령을 `Game.story`에 저장한다.
- 선택 전 새로고침 시 동일 장면·동일 대사로 이어진다. 거래 완료 후 다시 들어와도 자산을 중복 지급하지 않는다.
- 잘못된 장면 종류, 대사 범위, 거래 대상, 100원 미만 단위, 일치하지 않는 후속 명령을 가져오기 검증에서 거절한다.
- 기존 저장은 도입 없이 이어지고 사건 기능만 활성화한다. 기존 자산·매물 가치·거래 확률·경제 난수는 초기화하지 않는다.
- 대사마다 우편을 보내지 않는다. 기존 시작·시장·특별 제안 우편 필터를 유지한다. 특별 매입 완료 시에만 특별 거래 기록이 추가된다.

## 현재 한계와 후속 후보

- 각 사건은 우선 1개 대사 구성과 선택 분기를 가진다. 나이·성별별 사건 대사 확대는 아직 하지 않았다. 기존 채팅의 성향별 질문·흥정은 유지한다.
- 단골 부탁은 종류 단위의 요청으로, 전용 퀘스트 목록·기한·호감도 수치는 추가하지 않는다.
- 경쟁자의 일괄 제안은 판매 등록하지 않은 가치 100원 이상 물건들을 대상으로 한다. 대상 목록과 합산 금액을 장면에 고정하고 1행동으로 교환한다.
- 사건 고유 금액 효과는 위 표에 한정하며 대박 확률이나 기준 가치 상한을 변경하지 않는다.

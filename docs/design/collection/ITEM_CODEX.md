# 아이템 도감

## 사용자 요청

해금형 아이템 도감에서 품목의 시세와 특징을 확인한다.

## 첫 구현 기본안 — 조정 가능

- 내 정보 → 아이템 도감으로 진입한다. 별도의 하단 탭을 늘리지 않는다.
- 구매·낙찰 결제·무료나눔·수집으로 처음 획득한 품목을 해금한다. 목록 열람/흥정/입찰만으로는 해금하지 않는다. 감정은 해금 조건이 아니다.
- 같은 종류+품목명은 한 항목이며 중복 획득/판매/폐기 후에도 해금 유지. 기존 보유품은 불러올 때 반영하되 이미 팔아 버린 과거 품목은 추정하지 않는다.
- 잠긴 항목은 이름·시세·아이콘·특징을 숨긴다. 종류별 필터와 해금 수/전체 수를 제공한다.
- 해금 항목은 이름·도트 아이콘·종류·출현 시장·참고 시세·거래 특징을 표시한다. 시세는 콘텐츠의 기본 매물 가격대이며, 시장 동향은 별도로 표시한다. 개별 물건의 실제 가치/진위/상태를 보증하는 가격이 아니다. 100원 단위 공통 표시 함수를 사용한다.
- 활성 시장의 모든 품목과 현재 수집/나눔 품목을 콘텐츠에서 구성한다. 같은 품목은 가격대를 합친다. 현재 생성되지 않는 과거 단계별 품목은 획득한 기록이 있을 때만 표시해 달성 불가능한 잠긴 항목을 만들지 않는다. 은퇴한 항공기 시장은 포함하지 않는다.
- 해금은 현재 게임 저장/백업에 포함된다. 새 게임은 초기화한다. 영구 성장/회차 계승은 추가하지 않는다. 도감 열람은 행동·현금 소모 없음.

## 추후 논의

품목별 별도 거래 가격대, 실제 거래 이력 그래프, 진위별 세부 항목, 완성 보상·해금 보너스·영구 계승은 아직 확정하지 않았다.

# 사업: 구매하면 주마다 들어오는 수입

## 사용자 확정

사업/투자 시스템(가칭)은 어떤 것을 사두면 주마다 수입이 들어오는 구조다. 별도 직원·운영·관리 시스템으로 복잡하게 만들지 않는다.

## 개발자 초기 조정안

| 자산           |     구매 금액 |    주간 수입 |
| -------------- | ------------: | -----------: |
| 중고 판매대    |     100,000원 |     20,000원 |
| 자동판매기     |     500,000원 |    100,000원 |
| 온라인 판매점  |   3,000,000원 |    600,000원 |
| 무인 매장      |  30,000,000원 |  6,000,000원 |
| 소형 임대 점포 | 300,000,000원 | 60,000,000원 |

가격/수입/품목은 사용자 확정 수치가 아닌 초기 테스트 설정이다. 종류별 1개만 구매하며 구매는 행동을 소모하지 않는다. 행동이 0회 남아 있어도 정산 시작 전에는 구매할 수 있다. 보유 물품 12칸과 분리한다. 판매·대출·고용·관리비·손실 확률·수동 수금은 이번에 추가하지 않는다.

## 수입과 정산

- 사업 탭의 목록에서 가격과 주간 수입을 보고 구매한다. 보유 상태와 총 주간 수입을 같은 화면에서 확인한다.
- 구매한 주부터 **주간 정산 시작 시** 자동으로 지급한다. 수입을 받은 뒤 원금/이자 납부 가능 여부를 판정하므로 사업 수입으로 이번 주 상환할 수 있다.
- 첫 정산 시작에서 해당 주 수입을 한 번만 지급한다. 화면 재진입/연타/재접속/미리보기/중간 상환으로 다시 받을 수 없다. 미리보기에는 수입 예상액을 표시한다.
- 조기 정산도 동일한 주간 수입 1회를 받는다. 앱을 꺼두거나 글을 읽는 동안 달력이 흐르거나 추가 수입이 발생하지 않는다.
- 주간 수입은 부채 원금이나 원금 상환 실적을 자동으로 바꾸지 않는다. 기존 의무 원금→이자 납부 순서와 주당 20행동은 유지한다.
- 지원 현금 상한을 넘는 부분은 지급하지 않고 실제 받은 금액을 기록한다.

저장에는 보유 사업 ID/구매 주차와 마지막 수입 지급 주차/실제 수령액을 보관한다. 기존 저장에는 보유 사업을 지급하지 않고 빈 목록으로 시작하며 과거 주의 수입을 소급 지급하지 않는다. 가격/수입은 100원 단위다.

하단 탭과 해당 화면 제목은 사용자 요청에 따라 `상점`에서 `사업`으로 변경했다. 활동의 사업 바로가기도 유지한다.

# 게임 설계서 — 주제별 문서 안내

게임 규칙은 항목별 문서로 분리했다. 이 파일은 기존 경로를 유지하는 안내이며, 규칙 본문은 각 문서에서 관리한다.

**[주제별 게임 설계 목차 열기](design/README.md)**

- 기본 진행: `design/core/`
- 생존 지표: `design/survival/`
- 포만감·식사 관련 문서는 폐기 표시를 남겼다. 현재 생존 설계는 `design/survival/`을 따른다.
- 수면: `design/sleep/`
- 수익 경로: `design/income/`
  - 아르바이트: `design/income/part-time/`
  - 무료 나눔: `design/income/giveaways/`
  - 물건 수집: `design/income/scavenging/`
- 판매 경로: `design/trading/`
  - 매각처: `design/trading/outlets/`
  - 장터 판매·네고: `design/trading/marketplace/`

현재까지 결정한 28개 항목은 해당 디렉터리의 개별 문서에 보존했다. 앞으로는 결정한 주제의 문서를 직접 갱신한다.

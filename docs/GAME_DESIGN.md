# 게임 설계서 — 사용자 결정 기록

작성 방식: 사용자가 처음부터 순서대로 결정한다. 개발 파트너는 매번 한 주제의 후보와 차이를 제시하고, 사용자가 선택하거나 직접 제시한 내용만 아래에 기록한다.

이전 문서의 규칙과 목업 화면의 값은 자동으로 이어받지 않는다. [이전 초안](GAME_DESIGN_REFERENCE.md)은 참고용이다. 새 결정에 따른 게임 구현은 별도 작업이며, 현재는 문서를 작성한다.

## 1. 게임 시작 상황

**확정: 완전 무일푼으로 시작한다.**

- 시작 현금: 0원.
- 시작 보유 물품: 없음.
- 첫 돈을 만드는 과정부터 플레이한다.

선택 근거: 사용자가 시작 상황 후보 1번 ‘완전 무일푼’을 선택했다.

## 2. 첫 돈을 마련하는 방법

**확정: 다음 세 가지 방법을 제공한다.**

- 무료 나눔
- 아르바이트
- 물건 수집

선택 근거: 사용자가 세 가지 방법을 직접 지정했다.

## 아직 정하지 않은 내용

각 방법의 구체적인 진행 방식, 보상, 소요 시간, 비용, 위험과 이용 조건은 아직 정하지 않았다. 아르바이트가 선택됐다는 이유로 별도의 직업 상태나 성장 시스템을 추가하지 않는다. 나머지 세부 규칙은 다음 논의에서 결정하며, 후보를 제시했다는 이유만으로 규칙에 포함하지 않는다.

# 게임 설계서 — 사용자 결정 기록

작성 방식: 사용자가 처음부터 순서대로 결정한다. 개발 파트너는 매번 한 주제의 후보와 차이를 제시하고, 사용자가 선택하거나 직접 제시한 내용만 아래에 기록한다.

이전 문서의 규칙과 목업 화면의 값은 자동으로 이어받지 않는다. [이전 초안](GAME_DESIGN_REFERENCE.md)은 참고용이다. 새 결정에 따른 게임 구현은 별도 작업이며, 현재는 문서를 작성한다.

## 1. 게임 시작 상황

**확정: 완전 무일푼으로 시작한다.**

- 시작 현금: 0원.
- 시작 보유 물품: 없음.
- 첫 돈을 만드는 과정부터 플레이한다.

선택 근거: 사용자가 시작 상황 후보 1번 ‘완전 무일푼’을 선택했다.

## 2. 첫 돈을 마련하는 방법

**확정: 다음 세 가지 방법을 제공한다.**

- 무료 나눔
- 아르바이트
- 물건 수집

선택 근거: 사용자가 세 가지 방법을 직접 지정했다.

## 3. 아르바이트 보상 방식

**확정: 확정 보상형으로 진행한다.**

- 정해진 시간을 쓰면 표시된 돈을 받는다.

선택 근거: 사용자가 아르바이트 진행 방식 후보 1번 ‘확정 보상형’을 선택했다.

## 4. 아르바이트 선택 방식

**확정: 고정 일거리 여러 개 중에서 선택한다.**

- 일거리마다 소요 시간과 보수가 다르다.
- 플레이어가 원하는 일거리를 선택한다.

선택 근거: 사용자가 아르바이트 선택 방식 후보 2번 ‘고정 일거리 여러 개’를 선택했다.

## 5. 아르바이트 반복 조건

**확정: 체력·포만감 등 상태가 허용하면 같은 일거리도 연속으로 선택할 수 있다.**

- 별도의 하루 횟수 제한 대신 상태 조건으로 수행 가능 여부를 판단한다.
- 구체적으로 어떤 상태를 확인하고 어느 수치에서 제한하는지는 아직 정하지 않았다.

선택 근거: 사용자가 체력·배고픔 등이 가능하다면 연속 선택할 수 있다고 지정했다.

## 6. 체력과 포만감의 역할

**확정: 체력은 생명력, 포만감은 포만감을 소모하는 행동의 가능 여부를 제한하는 지표로 사용한다.**

- 체력: 다치거나 무리하면 감소하며, 0이 되면 사망한다.
- 포만감: 활동 에너지 역할을 맡으며, 포만감을 소모하는 행동의 가능 여부를 제한한다.
- 무료 급식으로 포만감을 조금 회복할 수 있다. 다른 회복 방법과 구체적인 변화량은 아직 정하지 않았다. 행동 제한 방식은 8절을 따른다.

선택 근거: 사용자가 체력은 후보 2번 ‘생명력’, 배고픔은 후보 1번 ‘활동 에너지’ 역할로 지정했다.

## 7. 포만감 수치의 표시 방향

**확정: 포만도 방식으로 표시한다.**

- 수치가 높을수록 배부른 상태다.
- 포만감을 소모하는 행동을 하면 수치가 줄어든다.
- 수치가 부족하면 포만감을 소모하는 행동이 제한된다.

선택 근거: 사용자가 배고픔 수치 표시 방향 후보 1번 ‘포만도 방식’을 선택했다.

지표 이름은 사용자가 지정한 ‘포만감’을 사용한다. 수치 범위, 초기값, 활동별 소모량과 무료 급식 외 회복 방법은 아직 정하지 않았다.

## 8. 포만감 부족 시 행동 처리

**확정: 필요한 포만감이 부족하면 포만감을 소모하는 행동만 실행할 수 없다.**

- 포만감을 소모하지 않는 행동은 포만감 부족만을 이유로 막지 않는다. 다른 조건 충족 여부는 별개다.
- 식사 등 포만감을 회복하는 행동은 가능하다.
- 부족한 포만감을 체력 소모로 대신하여 강행하는 방식은 사용하지 않는다.

선택 근거: 사용자가 ‘행동 불가’를 선택한 뒤, 포만감이 소모되는 행동만 제한한다고 구체화했다.

## 9. 지표가 0일 때의 처리

| 지표   | 처리                                                                         | 결정 상태                      |
| ------ | ---------------------------------------------------------------------------- | ------------------------------ |
| 포만감 | 포만감을 소모하는 행동 불가. 회복하면 다시 가능하며 식사 등 회복 행동은 가능 | 사용자 확정                    |
| 체력   | 사망                                                                         | 사용자 확정                    |
| 피로도 | 해당 날짜 종료, 다음 날 아침으로 이동                                        | 사용자 제안, 세부 규칙 검토 중 |

**확정: 지표 이름은 ‘피로도’를 유지한다.** ‘기력’으로 변경하지 않는다.

다음 날 아침의 기준 시각과 회복 수치, 잠자리·비용, 포만감 변화, 체력 회복 여부, 채무·판매 대기·이벤트 시간 처리는 아직 정하지 않았다. 무료 완전 회복을 가정하지 않는다. 여러 수치가 동시에 0이 되는 경우의 판정 순서와 행동 보상 지급 시점도 아직 미정이다.

## 10. 무료 급식

**확정: 무료 급식은 항상 이용 가능한 선택지다.**

- 현금을 쓰지 않고 포만감을 회복할 수 있다.
- 한 번 이용할 때의 포만감 회복량은 적다.
- 반복해서 이용하며 시간을 쓰면 포만감을 가득 채울 수 있다.
- 무료 급식만의 낮은 회복 상한을 별도로 두지 않는다.
- 이용 시 시간이 소모된다.
- 포만감이 0이어도 포만감 회복 행동으로 이용할 수 있다.

선택 근거: 사용자가 항상 있는 무료 급식 선택지, 낮은 포만감 회복량과 시간 소모를 지정한 뒤, 회복 방식 후보 1번 ‘한 번의 회복량이 적고 반복하면 가득 채울 수 있음’을 선택했다.

구체적인 회복량과 소요 시간, 다른 지표 변화는 아직 정하지 않았다. 횟수 제한이나 별도 이용 조건을 임의로 추가하지 않는다.

## 11. 게임 진행의 공통 원칙

**확정: 날짜·시간·포만감·체력·피로도를 고려하여 진행한다.**

- 행동이나 진행을 하면 시간이 소모되는 것이 공통 원칙이다.
- 어떤 행동이 각 지표를 얼마나 변화시키는지와 구체적인 시간 비용은 별도로 정한다.

선택 근거: 사용자가 게임 진행 시 고려할 다섯 요소와 행동·진행의 시간 소모 원칙을 직접 지정했다.

## 12. 포만감 소모 방식

**확정: 게임 시간에 따른 기본 소모와 힘든 행동의 추가 소모를 함께 적용한다.**

- 게임 시간이 흐른 만큼 포만감이 기본적으로 소모된다.
- 힘든 행동을 하면 시간에 따른 기본 소모 외에 추가 포만감이 소모된다.
- 기본 소모율, 추가 소모 대상 행동과 소모량은 아직 정하지 않았다.

선택 근거: 사용자가 포만감 소모 방식 후보 3번 ‘혼합형’을 선택했다.

식사·무료 급식 등 회복 행동 중 시간에 따른 기본 소모의 적용 방식과 계산 순서는 아직 정하지 않았다. 해당 행동은 포만감이 부족해도 이용할 수 있어야 한다는 8절의 확정 규칙을 유지한다.

## 아직 정하지 않은 내용

무료 나눔과 물건 수집의 진행 방식·보상, 아르바이트의 구체적인 일거리 목록·보수·소요 시간, 각 방법의 비용·위험·구체적인 상태 조건은 아직 정하지 않았다. 체력·포만감·피로도의 범위·초기값·구체적인 변화량, 피로도 0에서 다음 날로 넘어갈 때의 세부 처리는 미정이다. 아르바이트가 선택됐다는 이유로 별도의 직업 상태나 성장 시스템을 추가하지 않는다. 나머지 세부 규칙은 다음 논의에서 결정하며, 후보를 제시했다는 이유만으로 규칙에 포함하지 않는다.

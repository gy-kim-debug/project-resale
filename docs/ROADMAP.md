# 로드맵

아래 순서는 제안이며 세부 게임 규칙을 확정하지 않는다.

1. **초기 기반 (이번 작업)**: React/TS/Vite, Tailwind, Zustand, 저장 인터페이스, 모바일 게시판·상세 및 탐색, 문서·정적 검증.
2. **최소 거래 루프**: 정보와 위험을 확인하는 선택, 고정 데이터 매입→인벤토리→재판매, 안전한 원화 연산과 순수 함수 테스트. 현금 0원에서의 첫 행동도 함께 설계한다. 가장 먼저 게임의 핵심 재미를 검증한다.
3. **시간·생존·채무**: 시간 단위, 행동 비용, 생존 한계, 이자·반올림·상환 규칙을 결정한 뒤 독립 함수로 구현하고 경계값을 검증한다.
4. **생성·경제**: 시드 난수, 가치·결함·정보 공개, 협상·수리·감정, 시장 변화. 재현 가능한 테스트로 생존 수치와 확률의 독립성을 확인한다.
5. **이벤트·회차**: 조건부/연속 이벤트, 결과 기록, 파산·사망·클리어와 재시작. 계승은 별도 결정한다.
6. **저장·오프라인 강화**: 전체 회차 저장, 버전 마이그레이션, 가져오기·내보내기, PWA 캐시·업데이트·복구 정책.
7. **모바일 출시 준비**: 실제 iOS/Android 기기 검증 후 Capacitor 도입, 네이티브 저장 대체, 접근성·성능·스토어 요구사항 검토.

경제 밸런스, 확률, 이자율, 영구 성장은 플레이 검증과 별도 합의를 거쳐 결정한다.

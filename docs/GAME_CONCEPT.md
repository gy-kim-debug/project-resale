# 중고거래로 100억 갚기

## 확정된 방향

텍스트 기반 중고거래·생존·경제 시뮬레이션·로그라이크. 모바일 웹으로 먼저 개발하고 추후 Capacitor로 iOS와 Android 출시를 고려한다. 초기에는 백엔드 없는 싱글 플레이와 오프라인 실행을 지향한다.

주인공은 현금 0원, 원금 100억 원, 무직으로 시작한다. 저렴한 매입, 감정·수리, 재판매를 통해 생존하며 원금과 발생 이자를 모두 갚으면 클리어한다. 게시판 탐색이 기본이며 행동은 고정된 순서에 묶이지 않는다.

## 핵심 경험

무일푼에서 큰 거래로 성장하고, 정보 수집과 위험 감수 사이에서 선택한다. 희귀품 발견과 손실, 시장 변화와 연속 이벤트를 경험한다. 성공 후에도 손실을 볼 수 있으며 실패 후 새 회차에 도전할 수 있다.

생존 수치는 물품의 실제 가치나 확률적 거래 결과를 직접 보정하지 않는다. 불리한 무작위 결과만 강제하지 않고 위험을 확인할 선택을 제공한다. 특정 중고거래 서비스의 화면을 그대로 복제하지 않는다.

## 이번 구현

초기 화면과 고정 목업 콘텐츠만 제공한다. 실제 거래, 시간 진행, 생존·이자 계산, 랜덤 생성, 결제·인증·네이티브 프로젝트는 구현하지 않는다.

## 미확정

게임 제목 최종안, 세계관 세부 설정, 시작 자금 확보 수단, 난이도와 엔딩 연출은 결정되지 않았다. 무료 나눔 매물은 화면 검증용 예시이며 확정된 공략 수단이 아니다.

# 중고거래로 100억 갚기

> 이전 기획의 참고 자료입니다. 현재 설계는 사용자가 처음부터 결정해 작성하는 [게임 설계서](GAME_DESIGN.md)를 따릅니다. 아래 내용은 새 설계에 자동 반영하지 않습니다.

상세 규칙 논의는 [게임 상세 설계 기준서](GAME_DESIGN.md)에서 진행합니다. 현재는 화면 개발보다 규칙 정의를 먼저 진행합니다.

## 확정된 방향

텍스트 기반 중고거래·생존·경제 시뮬레이션. 모바일 웹으로 먼저 개발하고 추후 Capacitor로 iOS와 Android 출시를 고려한다. 초기에는 백엔드 없는 싱글 플레이와 오프라인 실행을 지향한다.

주인공은 현금 500,000원, 원금 100억 원으로 시작한다. 저렴한 매입, 감정·수리, 재판매를 통해 생존하며 원금과 발생 이자를 모두 갚으면 클리어한다. 주요 플레이는 활동 탭에서 시작하며, 장터·매각처 등 원하는 활동을 선택해 들어간다. 행동은 고정된 순서에 묶이지 않는다. 시간은 행동할 때만 흐르며 글을 읽거나 앱을 꺼두면 멈춘다.

## 핵심 경험

작은 자본에서 큰 거래로 성장하고, 정보 수집과 위험 감수 사이에서 선택한다. 희귀품 발견과 손실, 시장 변화와 연속 이벤트를 경험한다. 성공 후에도 손실을 볼 수 있다. 주간 이자를 납부하지 못하면 게임이 종료된다. 회차, 직업 상태, 회차 간 계승을 게임 구조로 두지 않는다.

생존 수치는 물품의 실제 가치나 확률적 거래 결과를 직접 보정하지 않는다. 불리한 무작위 결과만 강제하지 않고 위험을 확인할 선택을 제공한다. 특정 중고거래 서비스의 화면을 그대로 복제하지 않는다.

## 이번 구현

초기 화면과 고정 목업 콘텐츠만 제공한다. 실제 거래, 시간 진행, 생존·이자 계산, 랜덤 생성, 결제·인증·네이티브 프로젝트는 구현하지 않는다.

## 미확정

게임 제목 최종안, 세계관 세부 설정, 시작 자금 확보 수단, 난이도와 엔딩 연출은 결정되지 않았다. 무료 나눔 매물은 화면 검증용 예시이며 확정된 공략 수단이 아니다.

## 반영한 디자인 방향

어두운 활동 허브에서 ‘골목장터’ 앱과 매각처 활동을 선택해 들어간다. 장터는 밝고 익숙한 중고거래 앱 UI로 대비한다. 공통 상단 헤더에 주간 이자·채무을 고정해 모든 화면에서 확인할 수 있다. 회차·무직 표시는 사용하지 않는다.

하단 탭은 **활동 / 내 정보 / 보관함 / 상점 / 채무** 순서다. 활동은 플레이 진입점, 내 정보는 현금·경과 시간·현재 상태, 보관함은 보유품·관심 매물, 채무는 원금·이자·상환을 담당한다. 상점의 품목과 이용 방식은 아직 미정이며, 장터와 동일시하거나 결제 기능을 가정하지 않는다.

사용자 후속 결정: 모든 생존 수치와 회복 행동을 제거했다. 주간 이자 미납이 실패 조건이며 주당 30행동과 상승하는 주간 이율이 거래의 제약이 된다.

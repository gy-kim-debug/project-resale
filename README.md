# 다시, 장터 — 중고거래로 100억 갚기

모바일 우선 텍스트 경제·생존 게임의 초기 기반입니다. 실제 거래 엔진 없이 고정 목업 매물을 탐색합니다.

## 실행

Node.js 22.12 이상(개발 환경: 24), npm을 사용합니다.

```sh
npm ci
npm run dev
```

커밋된 lockfile을 기준으로 로컬과 CI 모두 `npm ci`를 사용합니다.

```sh
npm run typecheck
npm run lint
npm run build
npm run format:check
npm run preview
```

활동 / 내 정보 / 보관함 / 상점 / 채무의 5개 탭을 제공합니다. 활동에서 장터·무료나눔·아르바이트·물건 수집·매각처·식사·수면·치료로 들어갑니다. 보관함의 물품 상세, 판매 등록·취소, 구매 문의 응답, 매각처 고정 가격 판매까지 목업으로 연결했습니다. 기존 디자인은 유지했습니다.

화면 검토용으로 현금·물품이 메모리에서만 바뀝니다. 시간·생존·확률·이자 계산은 없습니다. 새로고침하면 목업 진행은 초기화되며 **관심 매물만 IndexedDB에 저장**합니다. 유료 거래는 `내 정보 → 화면 검토 도구 → 거래 확인용 예시 불러오기`로 확인할 수 있습니다. 예시 수치와 실제 미정 규칙은 [화면 토대 안내](docs/SCREEN_FOUNDATION.md)를 참고하세요.

## 문서

게임 규칙은 사용자가 후보를 보고 직접 결정합니다. 주제별 설계서에는 직접 선택한 내용만 기록하며, 현재 화면은 그 규칙을 검토하기 위한 목업입니다. 미정 항목은 화면 구현만으로 확정하지 않습니다.

## 검증 결과

TypeScript·ESLint·Prettier·프로덕션 빌드를 통과했습니다. Chromium의 320/375/390/430px에서 필터·상세·관심 저장/복원·하단 메뉴와 가로 넘침을 확인했습니다. IndexedDB 접근 실패 시 안내와 탐색 유지도 확인했습니다. [검증 기록](docs/VALIDATION.md)에 원인 분석과 범위를 정리했습니다. 실제 iOS/Android 기기 확인은 후속 과제입니다.

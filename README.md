# 중고거래로 100억 갚기 (가제)

모바일 웹 싱글 플레이 경제·생존 게임입니다. 현금 500,000원에서 시작해 일하고 물건을 수집·매입·재판매하며 원금 100억 원과 발생한 이자를 갚습니다. 주간 의무 원금 또는 이자 미납은 게임 오버이며 시간은 행동할 때만 흐릅니다. 정식 제목은 아직 확정하지 않았습니다.

## 실행

Node 24 권장, npm을 사용합니다. 커밋된 lockfile을 기준으로 설치합니다.

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
npm run lint
npm run test
npm run format:check
npm run build
npm run preview -- --port 4182
```

`npm run build`는 서비스 워커용 오프라인 앱 파일도 구성합니다. 첫 접속에서 캐시가 완료된 뒤에는 네트워크 없이 다시 열 수 있습니다. 브라우저의 저장·서비스 워커 제한이 있는 환경에서는 이 기능이 제한될 수 있습니다.

## 플레이

- 하단 순서는 **내 정보 / 채무 / 활동 / 보관함 / 상점**. 가운데 원형 활동이 홈입니다.
- 돈 벌기: 무료나눔·아르바이트·물건 수집. 무료나눔 글은 없을 수 있습니다.
- 거래: 장터에서 구매·선택형 네고, 보관함에서 별도 가치 확인·수리·판매 등록. 가치 확인과 수리는 금전 비용만 사용하며 행동은 소모하지 않습니다. 문의는 직접 응답해야 다음 행동으로 넘어갈 수 있습니다.
- 즉시 판매: 모든 보유 품목을 실제 가치의 60%로 판매합니다.
- 진행: 주당 주요 행동 20회. 생존 수치·식사·수면·치료 없음. 상단에 주간 이자·이율·납부 기한을 표시하며 주간 정산 시 납부하지 못하면 게임 오버입니다.
- 채무: 원금 자유 상환·주간 정산 시 의무 원금·이자 납부. 원금은 5만 원부터 매주 2배, 주중 상환액을 인정. 주 0.001%에서 매주 0.002%p 증가, 납부 시 남은 원금으로 계산. 현금 부족은 게임 오버.
- 실제 가치·숨겨진 결함·가품·희귀품, 수리 성공·실패, 시장 변화, 조건부 연속 사건, 경험에 따른 능력치가 적용됩니다. 생존 수치는 가치·거래 확률을 보정하지 않습니다.

진행은 IndexedDB에 자동 저장합니다. 앱을 닫아도 시간은 흐르지 않습니다. `저장 관리`에서 백업 파일을 내려받거나 다른 기기로 옮길 수 있습니다. 사망·완납 후에도 결과를 저장하며, 새 게임은 확인 후 진행을 교체합니다. 서버·계정·결제·기기 간 자동 동기화는 없습니다.

## 검증

핵심 순수 엔진 규칙과 거래·주간 정산·장기 시뮬레이션는 `npm run test`로 검증합니다. UI 검증은 별도 프로덕션 preview 실행 후 아래 명령을 사용합니다.

```sh
python3 scripts/verify-screens.py
```

Python Playwright와 Chromium이 필요합니다. `SCREEN_BASE_URL`, `CHROMIUM_PATH`로 실행 환경을 바꿀 수 있습니다. 검증용 저장 스냅샷은 실제 엔진으로 생성해 커밋 제외 `work/`에만 둡니다. 실제 서비스에는 목업 현금 주입·테스트 도구가 없습니다.

현재 주간 이율은 0.001%부터 매주 0.002%p 증가합니다. 원금은 별도로 상환하며, 이자는 납부 시 남은 원금 기준입니다. 현금 0원 즉시 종료는 사용하지 않습니다.

주간 납부 화면과 미납 종료는 프로덕션 preview 실행 후 `python scripts/verify-economy.py`로 검증합니다.

물품 종류와 단계별 가격표는 [매물 카테고리·가격대](docs/design/items/CATEGORIES_AND_PRICES.md), 실행 설정은 `src/content/market.ts`에서 관리합니다. 가격 상향은 새로 생성하는 매물부터 적용합니다.
